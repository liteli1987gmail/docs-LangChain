title: 连接到自定义模型
sidebarTitle: 自定义模型
---

Playground 允许您使用您自己的自定义模型。您可以部署一个通过 [LangServe](https://github.com/langchain-ai/langserve) 向您的模型 API 暴露模型服务器的开源库。在幕后，Playground 将与您的模型服务器交互以生成响应。

## 部署自定义模型服务器

为了您的方便，我们提供了一个[示例模型服务器](https://github.com/langchain-ai/langsmith-model-server)，您可以将其用作参考。我们强烈建议使用示例模型服务器作为起点。

根据您的模型是指令风格还是聊天风格的模型，您需要分别实现 `custom_model.py` 或 `custom_chat_model.py`。

## 添加可配置字段

用不同参数配置您的模型通常很有用。这些可能包括 temperature、model\_name、max\_tokens 等。

要在 Playground 中使您的模型可配置，您需要向模型服务器添加可配置字段。这些字段可用于从 Playground 更改模型参数。

您可以通过在 `config.py` 文件中实现 `with_configurable_fields` 函数来添加可配置字段。您可以

```python
def with_configurable_fields(self) -> Runnable:
    """公开您希望在 Playground 中可配置的字段。我们将自动将这些暴露给 Playground。
    如果您不想暴露任何字段，可以删除此方法。"""
    return self.configurable_fields(n=ConfigurableField(
        id="n",
        name="Num Characters",
        description="从输入提示词返回的字符数。",
    ))
```

## 在 Playground 中使用模型

一旦您部署了模型服务器，您可以在 Playground 中使用它。进入 Playground 并为聊天风格模型或指令风格模型选择 `ChatCustomModel` 或 `CustomModel` 提供商。

输入 `URL`。Playground 将自动检测可用的端点和可配置字段。然后您可以使用所需的参数调用模型。

![Playground 中的 ChatCustomModel](/langsmith/images/playground-custom-model.png)

如果一切设置正确，您应该在 Playground 中看到模型的响应，以及 `with_configurable_fields` 中指定的可配置字段。

有关更多信息，请参阅[如何存储您的模型配置以供以后使用](/langsmith/managing-model-configurations)。
