---
title: 使用 HTTP 头进行运行时配置
sidebarTitle: 可配置头
---
LangGraph 允许运行时配置动态修改代理行为和权限。当使用 [LangSmith Deployment](/langsmith/deployment-quickstart) 时，您可以在请求体（`config`）或特定请求头中传递此配置。这使您可以根据用户身份或其他请求进行调整。

为了保护隐私，请通过 [`langgraph.json`](/langsmith/application-structure#configuration-file) 文件中的 `http.configurable_headers` 部分配置哪些头被传递到运行时配置。

以下是如何自定义包含和排除的头：

```json
{
  "http": {
    "configurable_headers": {
      "includes": ["x-user-id", "x-organization-id", "my-prefix-*"],
      "excludes": ["authorization", "x-api-key"]
    }
  }
}
```

`includes` 和 `excludes` 列表接受确切的头的名称或使用 `*` 匹配任意数量字符的模式。为了您的安全，不支持其他正则表达式模式。

## 在图中使用

您可以使用任何节点的 `config` 参数访问包含的头。

```python
def my_node(state, config):
  organization_id = config["configurable"].get("x-organization-id")
  ...
```

或从上下文获取（在工具和其他嵌套函数中有用）。

```python
from langgraph.config import get_config

def search_everything(query: str):
  organization_id = get_config()["configurable"].get("x-organization-id")
  ...
```

您甚至可以用它来动态编译图。

```python
# my_graph.py.
import contextlib

@contextlib.asynccontextmanager
async def generate_agent(config):
  organization_id = config["configurable"].get("x-organization-id")
  if organization_id == "org1":
    graph = ...
    yield graph
  else:
    graph = ...
    yield graph

```

```json
{
  "graphs": {"agent": "my_grph.py:generate_agent"}
}
```

### 选择退出可配置头

如果您想选择退出可配置头，只需在 `s` 列表中设置通配符模式：

```json
{
  "http": {
    "configurable_headers": {
      "excludes": ["*"]
    }
  }
}
```

这将排除所有头添加到您的运行配置中。

请注意，排除优先于包含。
