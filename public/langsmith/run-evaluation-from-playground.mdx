LangSmith 允许您直接在 UI 中运行[评估](/langsmith/evaluation-concepts)。[**Playground**](/langsmith/prompt-engineering-concepts#playground) 允许您在一系列输入上测试您的提示词或模型配置，以查看它在不同上下文或场景中的评分情况，而无需编写任何代码。

在运行评估之前，您需要拥有一个[现有的数据集](/langsmith/evaluation-concepts#datasets)。了解如何[从 UI 创建数据集](/langsmith/manage-datasets-in-application#create-a-dataset-and-add-examples)。

要从 Studio 运行评估，请参阅[在 Studio 中对数据集运行实验](/langsmith/observability-studio#run-experiments-over-a-dataset)。如果您更喜欢用代码运行实验，请参阅[使用 SDK 运行评估](/langsmith/evaluate-llm-application)。

![Playground experiment](/langsmith/images/playground-experiment.gif)

<Callout type="info" icon="feather">
**[Polly](/langsmith/polly)** 在 Playground 中可用，可帮助您在运行评估之前优化提示词。
</Callout>

## 在 Playground 中创建实验

1. **点击侧边栏中的 Playground**。
2. **添加提示词**，方法是选择一个现有的已保存提示词或创建一个新的。
3. **从** **Test over dataset** 下拉菜单中选择一个**数据集**

   * 请注意，数据集中的键必须与提示词的输入变量匹配。例如，在上面的视频中，所选数据集的输入具有键"blog"，它与提示词的输入变量正确匹配。
   * Playground 中最多允许 15 个输入变量。

4. **点击** **Start** 或 CMD+Enter **开始实验**。这将对数据集中的所有示例运行提示词，并在数据集详情页中为实验创建一个条目。我们建议在开始实验之前将提示词提交到提示词中心，以便在查看实验时能够轻松引用。
5. **点击** **View full experiment** **查看完整结果**。这将带您到实验详情页面，您可以在其中查看实验结果。

## 向实验添加评估分数

通过添加评估器来针对特定标准评估您的实验。使用 **+Evaluator** 按钮在 Playground 中添加大型语言模型即裁判或自定义代码评估器。

要了解有关通过 UI 添加评估器的更多信息，请访问[如何定义大型语言模型即裁判评估器](/langsmith/llm-as-judge)。
