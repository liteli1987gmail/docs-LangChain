---
title: 如何添加自定义路由
sidebarTitle: 添加自定义路由
---
在将代理部署到 LangSmith Deployment 时，您的服务器自动暴露用于创建运行和线程、与长期内存存储交互、管理可配置助手以及其他核心功能的路由（请参阅[所有默认 API 端点](/langsmith/server-api-ref)）。

您可以通过提供您自己的 app 对象并将其路径传递给 `langgraph.json` 来添加自定义路由（例如，Python 中的 [`Starlette`](https://www.starlette.io/applications/) 应用程序或 TypeScript 中的 [`Hono`](https://hono.dev/) 应用程序）。

定义自定义 app 对象让您可以添加所需的任何路由，因此您可以做任何事情，从添加 `/login` 端点到编写整个全栈 Web 应用程序，所有这些都部署在单个 Agent Server 中。

以下是 Python 和 TypeScript 的示例。

## 创建应用程序

从一个**现有**的 LangSmith 应用程序开始，将以下自定义路由代码添加到您的应用程序文件。如果您从头开始，可以使用 CLI 从模板创建新应用程序。

<Tabs>
    <Tab title="Python">
    ```bash
    langgraph new --template=new-langgraph-project-python my_new_project
    ```

    一旦您有了 LangGraph 项目，添加以下应用程序代码：

    ```python {highlight={4}}
    # ./src/agent/webapp.py
    from fastapi import FastAPI

    app = FastAPI()


    @app.get("/hello")
    def read_root():
        return {"Hello": "World"}
    ```
    </Tab>
    <Tab title="TypeScript">
    ```bash
    yarn create langgraph
    npm install hono
    ```

    一旦您有了 LangGraph 项目，添加以下应用程序代码：

    ```typescript
    // ./src/custom-routes.ts
    import { Hono } from "hono";

    export const app = new Hono()
      .get("/custom/hello", (c) => {
        return c.json({ hello: "world" });
      })
      .post("/custom/webhook", async (c) => {
        const body = await c.req.json();
        return c.json({ received: true, payload: body });
      });
    ```

    `hono` 包必须在您的项目依赖中可用。
    </Tab>
</Tabs>

## 配置 `langgraph.json`

将以下内容添加到您的 `langgraph.json` 配置文件中。确保路径指向上[上一节](#create-app)中创建的应用程序实例。

<Tabs>
    <Tab title="Python">
    ```json
    {
      "dependencies": ["."],
      "graphs": {
        "agent": "./src/agent/graph.py:graph"
      },
      "env": ".env",
      "http": {
        "app": "./src/agent/webapp.py:app"
      }
      // 其他配置选项，如 auth、store 等。
    }
    ```
    </Tab>
    <Tab title="TypeScript">
    ```json
    {
      "node_version": "20",
      "dependencies": ["."],
      "graphs": { "agent": "./src/agent.ts:graph" },
      "http": { "app": "./src/custom-routes.ts:app" },
      "env": ".env"
    }
    ```
    </Tab>
</Tabs>

## 启动服务器

在本地测试服务器：

<Tabs>
    <Tab title="Python">
    ```bash
    langgraph dev --no-browser
    ```
    </Tab>
    <Tab title="TypeScript">
    ```bash
    npx @langchain/langgraph-cli@latest dev --no-browser
    ```
    </Tab>
</Tabs>

如果在浏览器中导航到 `localhost:2024/hello`（`2024` 是默认开发端口），您应该看到 `/hello` 端点返回 JSON 响应。对于 TypeScript 示例，请导航到 `localhost:2024/custom/hello`。

TypeScript `http.app` 配置在本地开发中使用 `langgraph dev` 和使用 `langgraph up` 的 Docker 中都能工作。

<Note>
**遮蔽默认端点**
您在应用程序中创建的路由优先于系统默认值，这意味着您可以遮蔽和重新定义任何默认端点的行为。
</Note>

## 部署

您可以将此应用程序原样部署到 LangSmith 或您的自托管平台。
