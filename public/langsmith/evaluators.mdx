LangSmith 中的[评估器](/langsmith/evaluation-concepts#evaluators)是 workspace 级资源。您可以将单个评估器附加到多个追踪项目和数据集，因此您可以跨您的工作应用一致的评估逻辑，而无需每次重新创建。

## 查看评估器

在 [LangSmith UI](https://smith.langchain.com) 中，选择左侧边栏中的 **Evaluators** 以查看您 workspace 中的所有评估器。

评估器表显示以下列：

| 列 | 描述 |
|--------|-------------|
| Name | 评估器名称 |
| Type | **LLM**、**Code** 或 **Composite score**。复合分数评估器限定在单独的追踪项目和数据集，并且不会在此处显示。 |
| Feedback Key | 评估器产生的反馈键 |
| Resources | 此评估器附加到的追踪项目和数据集 |
| Created By | 创建评估器的 workspace 成员 |
| Updated At | 评估器最后修改的时间 |
| Created At | 评估器创建的时间 |

## 创建评估器

1. 在 [LangSmith UI](https://smith.langchain.com) 中，选择左侧边栏中的 **Evaluators**。
1. 点击 **+ Evaluator** 打开 **Add Evaluator** 面板。
1. 选择以下之一：
   - **从零开始创建**：构建新的 [LLM-as-a-Judge](/langsmith/llm-as-judge)、[Code](/langsmith/online-evaluations-code) 或 [Composite](/langsmith/composite-evaluators-ui) 评估器。
   - **附加现有评估器**：选择您 workspace 中已有的评估器以在其他资源中重复使用。
   - **从模板创建**：从现成的评估器（也称为预构建评估器）开始，用于常见评估模式。模板按以下类别组织：

     | 类别 | 描述 |
     |----------|-------------|
     | Security | 检测泄漏、注入和对抗性输入 |
     | Safety | 评估内容安全性和审核 |
     | Quality | 衡量输出质量和准确性 |
     | Conversation | 评估对话质量和用户体验 |
     | Trajectory | 评估代理工具使用和决策路径 |
     | Image & Voice (Multi-Modal) | 评估图像内容质量和安全性，以及语音和音频交互质量  |

您还可以直接从追踪项目或数据集添加评估器。请参阅[设置 LLM-as-a-judge 在线评估器](/langsmith/online-evaluations-llm-as-judge)和[在实验上自动运行评估器](/langsmith/bind-evaluator-to-dataset)。

## 查看评估器详情

点击表中的任何评估器以打开其详情视图。详情视图有四个选项卡：

- **Overview**：评估器的反馈配置和提示词或代码定义。
- **Traces**：此评估器跨所有附加资源处理的追踪。
- **Logs**：此评估器跨所有附加资源的执行日志。
- **Resources**：此评估器附加到的追踪项目和数据集。

## 编辑评估器

打开评估器并在 **Overview** 选项卡中更新其配置。因为评估器是共享的，更改将应用于它附加到的所有追踪项目和数据集。

## 删除评估器

评估器在附加到追踪项目或数据集时无法删除。要删除评估器，首先通过 **Resources** 选项卡将其从所有资源中移除，然后删除它。
