---
title: 如何重试实验中的失败运行（仅限 Python）
sidebarTitle: 重试实验失败运行（Python）
---

在大型[数据集](/langsmith/evaluation-concepts#datasets)上运行[评估](/langsmith/evaluation-concepts#evaluation-lifecycle)时，您可能会因速率限制、网络问题或其他临时错误而遇到一小部分示例失败。您不必重新运行整个评估，而是可以识别并仅重试失败的示例[实验](/langsmith/evaluation-concepts#experiment)。

本指南展示了一种将重试逻辑构建到您评估工作流程中的方法，并仅重试失败的示例。您可以使用 `error_handling='ignore'` 参数来跳过记录错误的运行，然后在 Python 中自动识别不成功的示例并重新运行它们。


## 步骤 1. 运行初始评估
运行初始评估，忽略错误以防止错误运行被记录：

```python
from langsmith import Client

client = Client()

# Run initial evaluation, ignoring errors
# error_handling='ignore' prevents errored runs from being logged
results = await client.aevaluate(
    target,
    data="dataset",
    evaluators=[your_evaluators],
    error_handling='ignore'
)
```

## 步骤 2. 在失败示例上重试并记录到同一实验

获取所有不成功的示例：
```python
# Identify unsuccessful examples
runs = client.list_runs(project_name=results.experiment_name)
successful_example_ids = [r.reference_example_id for r in runs]
unsuccessful_examples = (e for e in client.list_examples(dataset_name="dataset") if e.id not in successful_example_ids)
```

接下来，重新运行所有失败的示例并将它们记录到同一实验：
```python
# Retry only the failed examples, log
results_retry = await client.aevaluate(
    target,
    unsuccessful_examples,
    evaluators=[your_evaluators],
    experiment=results.experiment_name,
    error_handling='ignore'
)
```
