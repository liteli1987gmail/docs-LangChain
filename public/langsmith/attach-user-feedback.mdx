LangSmith 使将反馈附加到追踪变得容易。此反馈可以来自用户、标注者、自动评估器等，对于监控和评估应用程序至关重要。

## 使用 `create_feedback()` / `createFeedback`

这里我们将介绍如何使用 SDK 记录反馈。

<Info>
**子运行**
您可以将用户反馈附加到追踪的任何子运行，而不仅仅是追踪（根运行）本身。
这对于批评大型语言模型应用程序的特定步骤很有用，例如 RAG 管道的检索步骤或生成步骤。
</Info>

<Tip>
**非阻塞创建（仅限 Python）**
如果将 `trace_id=` 传递给 [`create_feedback()`](https://reference.langchain.com/python/langsmith/client/Client/create_feedback)，Python 客户端将自动在后台创建反馈。
这对于低延迟环境至关重要，您希望确保您的应用程序不会被反馈创建阻塞。
</Tip>

<CodeGroup>

```python Python
from langsmith import trace, traceable, Client

    @traceable
    def foo(x):
        return {"y": x * 2}

    @traceable
    def bar(y):
        return {"z": y - 1}

    client = Client()

    inputs = {"x": 1}
    with trace(name="foobar", inputs=inputs) as root_run:
        result = foo(**inputs)
        result = bar(**result)
        root_run.outputs = result
        trace_id = root_run.id
        child_runs = root_run.child_runs

    # 为追踪（又名根运行）提供反馈
    client.create_feedback(
        key="user_feedback",
        score=1,
        trace_id=trace_id,
        comment="用户说..."
    )

# 为子运行提供反馈
foo_run_id = [run for run in child_runs if run.name == "foo"][0].id
client.create_feedback(
    key="correctness",
    score=0,
    run_id=foo_run_id,
    # trace_id= 是可选的，但建议启用批量和后台反馈摄取。
    trace_id=trace_id,
)
```

```typescript TypeScript
import { Client } from "langsmith";
const client = new Client();

    // ... 运行您的应用程序并获取 run_id...
    // 此信息可以来自面向用户的反馈表单

await client.createFeedback(
    runId,
    "feedback-key",
    {
        score: 1.0,
        comment: "comment",
    }
);
```

</CodeGroup>

您甚至可以使用 [`create_feedback()`](https://reference.langchain.com/python/langsmith/client/Client/create_feedback) / [`createFeedback`](https://reference.langchain.com/javascript/classes/langsmith.client.Client.html#createfeedback) 为进行中的运行记录反馈。请参阅[在追踪函数中访问当前运行（span）](/langsmith/access-current-span)了解如何获取进行中运行的运行 ID。

## 从客户端应用程序收集反馈

如果需要从浏览器或其他客户端环境收集反馈而不暴露您的 API 密钥，请使用**预签名反馈令牌**。这些会生成一个限定范围到特定运行和反馈键的 URL，客户端可以直接调用。

请参阅[使用预签名 URL 收集反馈](/langsmith/presigned-feedback-tokens)获取完整指南。

要了解有关基于各种属性（包括用户反馈）筛选追踪的更多信息，请参阅[筛选追踪](/langsmith/filter-traces-in-application)。
