自托管 LangSmith 通过两个发布渠道发布：一个稳定渠道（客户在生产环境中运行）和一个预览渠道（跟踪下一个主要版本）。

## 发布渠道

### 稳定版

当前普遍可用的大版本。这是我们推荐用于生产的渠道。稳定版每周接收包含关键错误修复和安全补丁的小版本发布。主要版本之间不会在稳定版上添加新功能、数据迁移或基础设施更改。

在任何给定时间，最新的大版本（N）是预览渠道，前一个大版本（N-1）是稳定版。

### 预览版

下一个大版本的开发构建。预览版包括随着合并到 LangSmith SaaS 中的新功能和修复，让您提前了解下一个大版本将包含的内容。预览版本可能包含数据迁移，但永远不会添加或删除服务或引入破坏性更改。

预览版适用于在测试和预发布环境中进行评估。我们不建议在生产环境中运行预览版。

## 发布节奏

| 渠道 | 节奏 |
|---------|---------|
| 预览版 | 与 LangSmith SaaS 发布节奏同步发布 |
| 稳定版 — 新大版本 (`v0.X.0`) | 大约每 6 周（每季度两次） |
| 稳定版 — 小版本 (`v0.X.Y`) | 每周（通常在周五），如有更改则跳过。如有关键客户问题会发布临时版本。 |

## 每个渠道包含的内容

|  | 预览版 | 稳定版小版本 | 下一个大版本 |
|--|:-:|:-:|:-:|
| 新功能 | yes | no | yes |
| 错误修复 | yes | 仅关键 | yes |
| 安全补丁 | yes | yes | yes |
| 数据迁移和回填 | yes | no | yes |
| 新增或删除服务 | no | no | yes |
| 破坏性更改 | no | no | yes |

服务添加、服务删除和破坏性更改仅出现在新大版本中，因此请在进行大版本升级时考虑到这一点。

## 版本号方案

自托管 LangSmith 使用以下方案：

- `v0.X.0` — 大版本（稳定版 GA 发布）
- `v0.X.Y` — 稳定版小版本发布（仅关键修复）
- `v0.X.0-rcN` — 下一个大版本的预览版本（发布候选），其中 `N` 是递增的构建号

## 建议

- **在生产环境中运行稳定版。** 预览版仅用于评估，可能包含仍在验证中的未发布功能。
- **在测试或预发布环境中使用预览版。** 在非生产环境中运行预览版是尽早发现问题并为下一次大版本升级做好准备的最好方式。
- **为大版本升级制定计划。** 数据迁移、服务添加或删除以及破坏性更改仅出现在新大版本中。升级前请查看[自托管变更日志](/langsmith/self-hosted-changelog)并为任何所需的数据或基础设施更改制定计划。
- **保持在支持的版本上。** 我们建议在大版本发布后尽快升级到每个新大版本，以获取我们推荐节奏上的架构改进。

## 当前版本

要检查当前的稳定版和预览版本，请参阅[自托管变更日志](/langsmith/self-hosted-changelog)。
