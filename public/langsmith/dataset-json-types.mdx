title: 数据集预构建 JSON 模式类型
sidebarTitle: 数据集预构建 JSON 模式类型

LangSmith 建议您在数据集模式的输入和输出上设置模式，以确保数据一致性，并确保您的示例处于适合下游处理的正确格式，如运行评估。

为了更好地支持大型语言模型工作流，LangSmith 支持一些不同的预定义预构建类型。这些模式由 LangSmith API 公开托管，可以使用 [JSON Schema 引用](https://json-schema.org/understanding-json-schema/structuring#dollarref) 在您的数据集模式中定义。可用模式表如下所示

| 类型 | JSON Schema 引用链接 | 用途 |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Message | [https://api.smith.langchain.com/public/schemas/v1/message.json](https://api.smith.langchain.com/public/schemas/v1/message.json) | 表示发送给聊天模型的消息，遵循 OpenAI 标准格式。 |
| Tool | [https://api.smith.langchain.com/public/schemas/v1/tooldef.json](https://api.smith.langchain.com/public/schemas/v1/tooldef.json) | 可供聊天模型用于函数调用的工具定义，以 OpenAI JSON Schema 启发的函数格式定义。 |

LangSmith 允许您定义一系列转换，从追踪中收集上述预构建类型并将其添加到您的数据集中。有关可用转换的更多信息，请参阅我们的[参考](/langsmith/dataset-transformations)
