title: 代理身份

代理身份控制代理与应用程序和服务交互时使用谁的[凭据](/langsmith/fleet/workspace-admin)。

<Warning>
一旦设置了代理身份，就无法更改。
</Warning>

## 固定凭据（"Claws"）

无论谁与代理交互，代理始终使用相同的 API 密钥和 OAuth 令牌进行身份验证。

在以下情况下使用固定凭据：

- 代理作为共享服务运行（例如，团队 Slack 机器人或每日简报代理）。
- 您希望为所有用户使用一组已认证账户。
- 代理需要在[渠道](/langsmith/fleet/channels)或[计划](/langsmith/fleet/schedules)上运行，这些需要固定凭据。

使用固定凭据，代理执行的所有操作（发送电子邮件、发布消息、读取日历）都使用代理所有者在设置期间连接的账户。

## 用户凭据（"Assistants"）

代理使用与其交互的用户的 API 密钥和 OAuth 令牌进行身份验证，代表用户行事。

在以下情况下使用用户凭据：

- 每个用户应该通过自己的账户行事（例如，从用户自己的收件箱读取和发送的电子邮件助手）。
- 您需要每个用户的访问控制，以便代理只能看到该用户有权查看的内容。
- 审计跟踪需要反映每个操作由哪个用户执行。

使用用户凭据，每个用户在他们第一次与代理交互时单独进行身份验证。代理在其线程的所有后续操作中使用该用户的令牌。

## 设置代理身份

要为代理设置身份：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，导航到您要编辑的代理。
1. 点击右上角的 <Icon icon="pencil" /> **编辑**。
1. 点击**设置身份**并选择您要使用的身份。
1. 点击**保存**。
