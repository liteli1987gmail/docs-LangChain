可靠的 [_LLM-as-a-judge 评估器_](/langsmith/evaluation-concepts#llm-as-judge) 对于对您的人工智能应用程序（例如提示词、模型、架构更改）做出明智决策至关重要。正确定义评估器提示词可能很困难，但它直接影响您评估的可信度。

本指南描述如何使用人工反馈对齐您的 LLM-as-judge 评估器，以提高评估器质量并帮助您构建可靠的人工智能应用程序。

## 工作原理

LangSmith 的**对齐评估器**功能有一系列步骤来帮助您使用人工专家反馈对齐您的 LLM-as-judge 评估器。您可以使用此功能对齐在[离线评估](/langsmith/evaluation-concepts#offline-evaluations)或[在线评估](/langsmith/evaluation-concepts#online-evaluations)的数据集上运行的评估器。在这两种情况下，步骤都类似：

1. **选择包含应用程序输出的实验或运行**。
2. 将所选实验或运行添加到**标注队列**，人工专家可以在其中标记数据。
3. **针对标记的示例测试您的 LLM-as-judge 评估器提示词**。检查您的评估器结果与标记数据不对齐的情况。这表明您的评估器提示词需要改进的领域。
4. **改进并重复**以提高评估器对齐度。更新您的 LLM-as-judge 评估器提示词并再次测试。

## 前置条件

在开始本指南用于[离线评估](#offline-evaluations)或[在线评估](#online-evaluations)之前，您需要以下内容：

### 离线评估

- 至少有一个[实验](/langsmith/evaluation-concepts#experiment)的[数据集](/langsmith/evaluation-concepts#datasets)。
- 您需要通过 [SDK](/langsmith/manage-datasets-programmatically#create-a-dataset) 或 [UI](/langsmith/manage-datasets-in-application#create-a-dataset-and-add-examples) 上传或创建数据集，并通过 [SDK](/langsmith/evaluate-llm-application#run-the-evaluation) 或 [Playground](/langsmith/run-evaluation-from-playground) 运行实验。

### 在线评估

- 一个已向 LangSmith 发送追踪的应用程序。
- 使用[追踪集成](/langsmith/observability-concepts)之一进行配置以开始。

## 开始使用

您可以在数据集和追踪项目中输入新评估器和现有评估器的对齐流程。

|                                              | 数据集评估器                                                                                                                                                                         | 追踪项目评估器                                                                                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **从头开始创建对齐的评估器** | 1. **数据集和实验**并选择您的数据集<br></br>2. 点击 **+ 评估器** > **从标记数据创建**<br></br>3. 输入描述性反馈键名称（例如 `correctness`、`hallucination`) | 1. **项目**并选择您的项目<br></br>2. 点击 **+ 新建** > **评估器** > **从标记数据创建**<br></br>3. 输入描述性反馈键名称（例如 `correctness`、`hallucination`) |
| **对齐现有评估器**              | 1. **数据集和实验** > 选择您的数据集 > **评估器**标签<br></br>2. 在**使用实验数据对齐评估器**框中，点击**选择实验**                              | 1. **项目** > 选择您的项目 > **评估器**标签<br></br>2. 在**使用实验数据对齐评估器**框中，点击**选择实验**                                         |

## 1. 选择实验或运行

选择一个或多个实验（或运行）发送进行人工标记。这将把运行添加到[标注队列](/langsmith/annotation-queues)。

![添加到评估器队列](/langsmith/images/add-to-evaluator-queue.gif)

要将任何新实验/运行添加到现有标注队列，请前往**评估器**标签，选择您正在对齐的评估器，然后点击**添加到队列**。

<Check>
数据集应该代表您希望在生产中看到的输入和输出。

虽然您不需要覆盖每种可能的场景，但重要的是包含跨越预期用例全范围 examples。例如，如果您正在构建一个回答有关棒球、篮球和橄榄球问题的体育机器人，您的数据集应该至少包含每个运动的一个标记示例。
</Check>

## 2. 标记示例

通过添加反馈分数在标注队列中标记示例。标记示例后，点击**添加到参考数据集**。

<Check>
如果您的实验中有大量示例，您不需要标记每个示例即可开始。我们建议从至少 20 个示例开始，您可以随时添加更多。我们建议您标记的示例是多样的（0 和 1 标签平衡），以确保您构建了一个全面的评估器提示词。
</Check>

## 3. 针对标记的示例测试您的评估器提示词

一旦您有了标记示例，下一步是迭代您的评估器提示词以尽可能模仿标记数据。此迭代在**评估器 Playground** 中完成。

进入评估器 playground：点击评估器队列右上角的**查看评估器**按钮。这将带您到您正在对齐的评估器的详情页面。点击**评估器 Playground**按钮访问 playground。

![评估器 Playground](/langsmith/images/evaluator-pg.gif)

在评估器 playground 中，您可以创建或编辑您的评估器提示词，然后点击**开始对齐**以针对您在步骤 2 中创建的标记示例集运行它。运行评估器后，您将看到其生成的分数与您的人工标签的比较。对齐分数是评估器的判断与人工专家判断一致的示例百分比。

## 4. 重复以提高评估器对齐度

通过更新提示词并再次测试来进行迭代以提高评估器对齐度。

<Check>
默认情况下，您的评估器提示词更改**不会保存**。我们建议您定期保存评估器提示词，特别是在您看到对齐分数提高之后。

评估器 playground 将显示您评估器提示词最近保存版本的对比分数，以便您在迭代提示词时进行比较。
</Check>

提高评估器的对齐分数不是一门精确的科学，但有一些策略有助于提高对齐分数。

### 提高评估器对齐度的技巧

**1. 调查不对齐的示例**

深入研究不对齐的示例并尝试将它们分组为常见失败模式是提高评估器对齐度的良好第一步。

一旦您确定了常见的失败模式，将指令添加到您的评估器提示词中，以便 LLM 知道它们。例如，如果您注意到它不理解特定的缩写，您可以解释"MFA 代表 multi-factor authentication"。或者您可以告诉它"好的响应总是包含至少 3 个可供预订的潜在酒店"，如果它在评估器上下文中对好/坏的理解感到困惑。

**2. 检查 LLM 分数背后的推理**

要了解 LLM 为什么以这种方式对示例评分，您可以为您 的 LLM-as-judge 评估器启用推理。推理有助于理解 LLM 的思维过程，并可以帮助您识别常见的失败模式，将其纳入您的评估器提示词中。

为了在评估器 playground 中看到推理，将鼠标悬停在 LLM 分数上。

![启用推理](/langsmith/images/enable-reasoning.gif)

这将在评估器 playground 中显示 LLM 分数背后的推理。

**3. 添加更多标记示例并验证性能**

为了避免过度拟合标记示例，添加更多标记示例并测试性能很重要，特别是如果您从少量示例开始。
