[llama.cpp python](https://github.com/abetlen/llama-cpp-python) 库是一个简单的 Python 绑定，用于连接 `@ggerganov` 的 [llama.cpp](https://github.com/ggerganov/llama.cpp)。

本包提供：

- 通过 ctypes 接口访问底层 C API
- 高层次 Python API 用于文本补全
  - 类 `OpenAI` API
  - `LangChain` 兼容性
  - `LlamaIndex` 兼容性
- OpenAI 兼容的 Web 服务器
  - 本地 Copilot 替代方案
  - Function Calling 支持
  - Vision API 支持
  - 多模型支持

```python
pip install -qU  llama-cpp-python
```

```python
from langchain_community.embeddings import LlamaCppEmbeddings
```

```python
llama = LlamaCppEmbeddings(model_path="/path/to/model/ggml-model-q4_0.bin")
```

```python
text = "This is a test document."
```

```python
query_result = llama.embed_query(text)
```

```python
doc_result = llama.embed_documents([text])
```
