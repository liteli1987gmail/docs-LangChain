Hacker News（有时缩写为 `HN`）是一个专注于计算机科学和创业的社交新闻网站。它由投资基金和创业孵化器 `Y Combinator` 运营。通常，可以提交的内容被定义为"任何能满足一个人好奇心的事物"。

## Installation and setup

There isn't any special setup for it.

## Document loader

See a [usage example](/oss/python/integrations/document_loaders/hacker_news).

```python
from langchain_community.document_loaders import HNLoader
```
