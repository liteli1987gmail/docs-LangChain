> [Git](https://en.wikipedia.org/wiki/Git) 是一个分布式版本控制系统，用于跟踪任何计算机文件集中的变更，通常用于协调程序员在软件开发过程中协作开发源代码的工作。

## Installation and setup

First, you need to install `GitPython` python package.

<CodeGroup>
```bash pip
pip install GitPython
```

```bash uv
uv add GitPython
```
</CodeGroup>

## Document loader

See a [usage example](/oss/python/integrations/document_loaders/git).

```python
from langchain_community.document_loaders import GitLoader
```
