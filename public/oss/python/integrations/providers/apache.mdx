> [Apache软件基金会（维基百科）](https://en.wikipedia.org/wiki/The_Apache_Software_Foundation)
> 是一个去中心化的开源开发者社区。他们开发的软件按照Apache许可证的条款进行分发，这是一种宽松的开源许可证，用于自由开源软件（FOSS）。Apache项目以协作、基于共识的开发过程和开放、务实的软件许可证为特点，也就是说，它允许免费获得软件的开发者以非自由条款重新分发软件。每个项目由一个自我选择的技术专家团队管理，这些专家都是该项目的活跃贡献者。

## Apache AGE


[Apache AGE](https://age.apache.org/) 是一个 `PostgreSQL` 扩展，提供图数据库功能。`AGE` 是 `A Graph Extension` 的缩写，灵感来源于 Bitnine 对 `PostgreSQL 10` 的分支版本 `AgensGraph`，后者是一个多模态数据库。该项目的目标是创建一种能够同时处理关系型和图模型数据的单一存储，使户能够使用标准 ANSI SQL 以及 `openCypher`（图查询语言）。`Apache AGE` 存储的数据元素包括节点、连接节点的边，以及节点和边的属性。

See more about [integrating with Apache AGE](/oss/python/integrations/graphs/apache_age).

## Apache cassandra

> [Apache Cassandra](https://cassandra.apache.org/) 是一个 NoSQL、基于行的、高可扩展且高可用的数据库。从 5.0 版本开始，该数据库内置向量搜索功能。

See more about [integrating with Apache Cassandra](/oss/python/integrations/providers/cassandra/).

## Apache doris


[Apache Doris](https://doris.apache.org/) 是一个用于实时分析的现代化数据仓库。它可以在大规模实时数据上提供闪电般的快速分析。

通常 `Apache Doris` 被归类为 OLAP，它在 ClickBench——一个面向分析型 DBMS 的基准测试中表现出色。由于它拥有超快的向量化执行引擎，它也可以作为快速的 vectordb 使用。

See more about [integrating with Apache Doris](/oss/python/integrations/providers/apache_doris/).

## Apache kafka

[Apache Kafka](https://github.com/apache/kafka) 是一个用于发布和订阅记录流的分布式消息系统。


## Apache spark


[Apache Spark](https://spark.apache.org/) 是一个用于大规模数据处理的统一分析引擎。它提供 Scala、Java、Python 和 R 的高级 API，以及支持数据分析通用计算图的优化引擎。它还支持丰富的更高级工具，包括用于 SQL 和 DataFrames 的 `Spark SQL`、用于 pandas 工作负载的 `pandas API on Spark`、用于机器学习的 `MLlib`、用于图处理的 `GraphX` 以及用于流处理的 `Structured Streaming`。

See more about [integrating with Apache Spark](/oss/python/integrations/providers/spark).
