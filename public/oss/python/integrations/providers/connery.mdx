>[Connery SDK](https://github.com/connery-io/connery-sdk) 是一个 NPM 包，包含 SDK 和 CLI两部分，专为插件和动作的开发而设计。
>
>CLI 在开发过程中实现了许多自动化操作。SDK 提供了 JavaScript API，用于定义插件和动作，并将其打包成带有标准化 REST API 的插件服务器（API 元数据由元信息自动生成）。插件服务器负责处理授权、输入验证和日志记录。
>您只需专注于动作的业务逻辑。
>
>请参阅 [Connery SDK 文档](https://sdk.connery.io/docs/use-cases/) 中的用例和示例。
