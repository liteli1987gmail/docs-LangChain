[NLP Cloud](https://docs.nlp.cloud.io/#introduction) 是一个人工智能平台，允许你使用最先进的 AI 引擎，甚至可以使用你自己的数据训练你自己的引擎。


## Installation and setup

- Install the `nlpcloud` package.

<CodeGroup>
```bash pip
pip install nlpcloud
```

```bash uv
uv add nlpcloud
```
</CodeGroup>

- Get an NLPCloud api key and set it as an environment variable (`NLPCLOUD_API_KEY`)


## LLM

See a [usage example](/oss/python/integrations/llms/nlpcloud).

```python
from langchain_community.llms import NLPCloud
```

## Text embedding models

See a [usage example](/oss/python/integrations/embeddings/nlp_cloud)

```python
from langchain_community.embeddings import NLPCloudEmbeddings
```
