[Alibaba Cloud Tair](https://www.alibabacloud.com/help/en/tair/latest/what-is-tair) 是一个云原生内存数据库服务，由 `Alibaba Cloud` 开发。它提供丰富的数据模型和企业级能力，支持您的实时在线场景，同时保持与开源 `Redis` 的完全兼容。`Tair` 还引入了基于新型非易失性内存（NVM）存储介质的持久内存优化实例。

## Installation and setup

Install Tair Python SDK:

<CodeGroup>
```bash pip
pip install tair
```

```bash uv
uv add tair
```
</CodeGroup>

## Vector store

```python
from langchain_community.vectorstores import Tair
```

See a [usage example](/oss/python/integrations/vectorstores/tair).
