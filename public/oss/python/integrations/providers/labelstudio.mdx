[Label Studio](https://labelstud.io/guide/get_started) 是一个开源数据标注平台，在为微调大型语言模型（LLM）标注数据方面为 LangChain 提供了灵活性。它还支持通过人工反馈准备自定义训练数据，以及收集和评估响应。

## Installation and setup

See the [Label Studio installation guide](https://labelstud.io/guide/install) for installation options.

We need to install the  `label-studio` and `label-studio-sdk-python` Python packages:

<CodeGroup>
```bash pip
pip install label-studio label-studio-sdk
```

```bash uv
uv add label-studio label-studio-sdk
```
</CodeGroup>


## Callbacks

See a [usage example](/oss/python/integrations/callbacks/labelstudio).

```python
from langchain.callbacks import LabelStudioCallbackHandler
```
