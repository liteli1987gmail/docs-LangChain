[Doctran](https://github.com/psychic-api/doctran) 是一个 Python 包。它使用 LLMs 和开源 NLP 库将原始文本转换为干净的、结构化的、信息密度高的文档，这些文档针对向量空间检索进行了优化。你可以把 `Doctran` 看作一个黑盒，杂乱的字符串进去，干净的、有标签的字符串出来。


## Installation and setup

<CodeGroup>
```bash pip
pip install doctran
```

```bash uv
uv add doctran
```
</CodeGroup>
