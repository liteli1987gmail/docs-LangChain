[KDB.AI](https://kdb.ai) 是一个功能强大的基于知识的 vector database 和搜索引擎，它使您能够使用实时数据，通过提供 advanced search、recommendation 和 personalization，构建可扩展、可靠的 AI 应用程序。


## Installation and setup

Install the Python SDK:

<CodeGroup>
```bash pip
pip install kdbai-client
```

```bash uv
uv add kdbai-client
```
</CodeGroup>


## Vector store

There exists a wrapper around KDB.AI indexes, allowing you to use it as a vectorstore,
whether for semantic search or example selection.

```python
from langchain_community.vectorstores import KDBAI
```
