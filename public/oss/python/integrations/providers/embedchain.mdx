> [Embedchain](https://github.com/embedchain/embedchain) 是一个 RAG 框架，用于创建数据管道。它加载、索引、检索和同步所有数据。
>
> 它可作为[开源包](https://github.com/embedchain/embedchain)使用，也可作为[托管平台解决方案](https://app.embedchain.ai/)。


## Installation and setup

Install the package using pip:

<CodeGroup>
```bash pip
pip install embedchain
```

```bash uv
uv add embedchain
```
</CodeGroup>


## Retriever

See a [usage example](/oss/python/integrations/retrievers/embedchain).

```python
from langchain_community.retrievers import EmbedchainRetriever
```
