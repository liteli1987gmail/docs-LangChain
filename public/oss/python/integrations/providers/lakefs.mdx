lakeFS 在数据湖上提供可扩展的版本控制，并使用类似 Git 的语义来创建和访问这些版本。

## Installation and setup

Get the `ENDPOINT`, `LAKEFS_ACCESS_KEY`, and `LAKEFS_SECRET_KEY`.
You can find installation instructions in the [lakeFS quickstart guide](https://docs.lakefs.io/quickstart/launch.html).


## Document loader

See a [usage example](/oss/python/integrations/document_loaders/lakefs).
