> [pg_embedding](https://github.com/neondatabase/pg_embedding) 是一个用于向量相似性搜索的开源包，基于 `Postgres` 数据库和 `Hierarchical Navigable Small Worlds`（HNSW）算法实现近似最近邻搜索。

## Installation and setup

We need to install several python packages.

<CodeGroup>
```bash pip
pip install psycopg2-binary
```

```bash uv
uv add psycopg2-binary
```
</CodeGroup>

## Vector store

See a [usage example](/oss/python/integrations/vectorstores/pgembedding).

```python
from langchain_community.vectorstores import PGEmbedding
```
