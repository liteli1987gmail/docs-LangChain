[Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/)是一个用于解析HTML和XML文档的Python包（包括格式不规范的标记，即未闭合的标签，因此以其名字命名——tag soup）。它为解析的页面创建parse tree，可用于从HTML中提取数据[3]，这对于web scraping非常有用。

## Installation and setup

<CodeGroup>
```bash pip
pip install beautifulsoup4
```

```bash uv
uv add beautifulsoup4
```
</CodeGroup>

## Document transformer

See a [usage example](/oss/python/integrations/document_transformers/beautiful_soup).

from langchain_community.document_loaders import BeautifulSoupTransformer
