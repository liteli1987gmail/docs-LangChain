[Chaindesk](https://chaindesk.ai) 是一个[开源](https://github.com/gmpetrov/databerry) 文档检索平台，帮助您将个人数据与 Large Language Models 连接起来。


## Installation and setup

We need to sign up for Chaindesk, create a datastore, add some data and get your datastore API endpoint URL.
We need the [API Key](https://docs.chaindesk.ai/api-reference/authentication).

## Retriever

See a [usage example](/oss/python/integrations/retrievers/chaindesk).

from langchain_classic.retrievers import ChaindeskRetriever
