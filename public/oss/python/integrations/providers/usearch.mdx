[USearch](https://unum-cloud.github.io/usearch/) 是一个更小更快的单文件 Vector Search Engine。

>`USearch` 的基础功能与 `FAISS` 相同，如果你曾经研究过近似最近邻搜索（Approximate Nearest Neighbors），界面应该看起来很熟悉。`USearch` 和 `FAISS` 都使用 `HNSW` 算法，但它们在设计理念上存在显著差异。`USearch` 结构紧凑，与 `FAISS` 具有广泛的兼容性，且不会牺牲性能，主要关注用户自定义指标和更少的依赖项。
## Installation and setup

We need to install `usearch` python package.

<CodeGroup>
```bash pip
pip install usearch
```

```bash uv
uv add usearch
```
</CodeGroup>

## Vector store

See a [usage example](/oss/python/integrations/vectorstores/usearch).

```python
from langchain_community.vectorstores import USearch
```
