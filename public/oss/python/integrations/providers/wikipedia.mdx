[维基百科](https://wikipedia.org/)是一个多语言免费在线百科全书，由被称为维基人的志愿者社区通过开放协作编写和维护，并使用名为 MediaWiki 的基于 wiki 的编辑系统。`Wikipedia` 是历史上最大且阅读量最高的参考作品。


## Installation and setup

<CodeGroup>
```bash pip
pip install wikipedia
```

```bash uv
uv add wikipedia
```
</CodeGroup>



## Document loader

See a [usage example](/oss/python/integrations/document_loaders/wikipedia).

```python
from langchain_community.document_loaders import WikipediaLoader
```

## Retriever

See a [usage example](/oss/python/integrations/retrievers/wikipedia).

```python
from langchain_classic.retrievers import WikipediaRetriever
```
