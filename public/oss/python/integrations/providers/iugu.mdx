[Iugu](https://www.iugu.com/) 是一家巴西的服务和软件即服务（SaaS）公司。它为电商网站和移动应用程序提供支付处理软件和应用程序编程接口（API）。


## Installation and setup

The `Iugu API` requires an access token, which can be found inside of the `Iugu` dashboard.
