[Confluence](https://www.atlassian.com/software/confluence) 是一个 Wiki 协作平台，用于保存和整理所有项目相关的资料。`Confluence` 是一个知识库，主要处理内容管理活动。


## Installation and setup

<CodeGroup>
```bash pip
pip install atlassian-python-api
```

```bash uv
uv add atlassian-python-api
```
</CodeGroup>

We need to set up `username/api_key` or `Oauth2 login`.
See [instructions](https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/).


## Document loader

See a [usage example](/oss/python/integrations/document_loaders/confluence).

```python
from langchain_community.document_loaders import ConfluenceLoader
```
