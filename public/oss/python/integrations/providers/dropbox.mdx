> [Dropbox](https://en.wikipedia.org/wiki/Dropbox) 是一个文件托管服务，将传统文件、云端内容和网页快捷方式整合在一个地方。


## Installation and setup

See the detailed [installation guide](/oss/python/integrations/document_loaders/dropbox#prerequisites).

<CodeGroup>
```bash pip
pip install -U dropbox
```

```bash uv
uv add dropbox
```
</CodeGroup>
