>[AwaDB](https://github.com/awa-ai/awadb) 是一个 AI 原生数据库，用于 LLM 应用所使用的 embedding 向量的搜索和存储。

## Installation and setup

```bash
pip install awadb
```

## Vector store

```python
from langchain_community.vectorstores import AwaDB
```

See a [usage example](/oss/python/integrations/vectorstores/awadb).

## Embedding models

```python
from langchain_community.embeddings import AwaEmbeddings
```

See a [usage example](/oss/python/integrations/embeddings/awadb).
