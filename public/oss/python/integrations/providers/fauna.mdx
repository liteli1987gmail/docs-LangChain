Fauna 是一个分布式文档关系型数据库，它结合了文档的灵活性与关系型 ACID 兼容数据库的强大功能，可跨区域、云或全球扩展。


## Installation and setup

We have to get the secret key.
See the detailed [guide](https://docs.fauna.com/fauna/current/learn/security_model/).

We have to install the `fauna` package.

<CodeGroup>
```bash pip
pip install -U fauna
```

```bash uv
uv add fauna
```
</CodeGroup>

## Document loader

See a [usage example](/oss/python/integrations/document_loaders/fauna).

```python
from langchain_community.document_loaders.fauna import FaunaLoader
```
