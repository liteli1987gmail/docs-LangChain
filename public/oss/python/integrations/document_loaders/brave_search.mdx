# Brave Search 翻译

> [Brave Search](https://en.wikipedia.org/wiki/Brave_Search) 是由 Brave Software 开发的搜索引擎。

- **Brave Search** 使用自己的网页索引。截至 2022 年 5 月，它覆盖了超过 100 亿个页面，并用于提供 92% 的搜索结果，不依赖任何第三方。其余部分通过 Bing API 从服务器端检索（或在用户选择的基础上）从 Google 客户端检索。据 Brave 称，该索引被"故意保持比 Google 或 Bing 的索引小"，以帮助避免垃圾邮件和其他低质量内容，其缺点是"Brave Search 在恢复长尾查询方面还不如 Google"。

- **Brave Search Premium**：截至 2023 年 4 月，Brave Search 是一个无广告网站，但它最终将转向包含广告的新模式，Premium 用户将获得无广告体验。默认情况下，用户的 IP 地址等用户数据将不会被收集。数据收集需要用户选择参与，Premium 账户将是必要条件。

## Installation and setup

To get access to the Brave Search API, you need to [create an account and get an API key](https://api.search.brave.com/app/dashboard).

## Example

```python
loader = BraveSearchLoader(
    query="obama middle name", api_key=api_key, search_kwargs={"count": 3}
)
docs = loader.load()
len(docs)
```
