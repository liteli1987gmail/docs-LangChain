TOML 是一种用于配置文件的文件格式。它旨在易于阅读和编写，并且被设计为能够无歧义地映射到字典（data structure）。它的规范是开源的。TOML 已在许多编程语言中实现。TOML 这个名字是"Tom's Obvious, Minimal Language"的缩写，指的是其创建者 Tom Preston-Werner。

If you need to load `Toml` files, use the `TomlLoader`.

```python
from langchain_community.document_loaders import TomlLoader
```

```python
loader = TomlLoader("example_data/fake_rule.toml")
```

```python
rule = loader.load()
```
