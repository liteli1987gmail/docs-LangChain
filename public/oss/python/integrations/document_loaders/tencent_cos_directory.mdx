[腾讯云对象存储（COS）](https://www.tencentcloud.com/products/cos)是一种分布式存储服务，支持您通过 HTTP/HTTPS 协议随时随地存储任意数量的数据。`COS` 对数据结构或格式没有任何限制，也没有存储桶大小限制和分区管理，适用于几乎所有使用场景，例如数据分发、数据处理和数据湖。`COS` 提供 Web 控制台、多语言 SDK 和 API、命令行工具以及图形化工具。它与 Amazon S3 API 良好兼容，让您能够快速使用社区工具和插件。

This covers how to load document objects from a `Tencent COS Directory`.

```python
pip install -qU  cos-python-sdk-v5
```

```python
from langchain_community.document_loaders import TencentCOSDirectoryLoader
from qcloud_cos import CosConfig
```

```python
conf = CosConfig(
    Region="your cos region",
    SecretId="your cos secret_id",
    SecretKey="your cos secret_key",
)
loader = TencentCOSDirectoryLoader(conf=conf, bucket="you_cos_bucket")
```

```python
loader.load()
```

## Specifying a prefix

You can also specify a prefix for more fine-grained control over what files to load.

```python
loader = TencentCOSDirectoryLoader(conf=conf, bucket="you_cos_bucket", prefix="fake")
```

```python
loader.load()
```
