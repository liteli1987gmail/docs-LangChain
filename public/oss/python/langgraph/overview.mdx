LangGraph 是一个低层编排框架和运行时，用于构建、管理和部署长时间运行的、有状态的代理。包括 Klarna、Uber、J.P. Morgan 等在内的塑造代理未来的公司都在信任 LangGraph。

LangGraph 是非常低层的，完全专注于代理**编排**。在使用 LangGraph 之前，我们建议您熟悉一些用于构建代理的组件，从[模型](/oss/python/langchain/models)和[工具](/oss/python/langchain/tools)开始。

我们将在整个文档中经常使用 [LangChain](/oss/python/langchain/overview) 组件来集成模型和工具，但您不需要使用 LangChain 来使用 LangGraph。如果您刚刚开始使用代理或想要更高层的抽象，我们建议您使用 LangChain 的[代理](/oss/python/langchain/agents)，它为常见的大型语言模型和工具调用循环提供预构建架构。

LangGraph 专注于对代理编排重要的底层能力：持久执行、流式处理、人工介入等。

## <Icon icon="download" size={20} /> 安装

<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>




然后，创建一个简单的 hello world 示例：

```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```




<Tip>
使用 [LangSmith](/langsmith/home) 来追踪请求、调试代理行为和评估输出。设置 `LANGSMITH_TRACING=true` 和您的 API 密钥以开始使用。
</Tip>

## 核心优势

LangGraph 为*任何*长时间运行的、有状态的工作流或代理提供低层支持基础设施。LangGraph 不抽象化提示词或架构，并提供以下核心优势：

* [持久执行](/oss/python/langgraph/durable-execution)：构建能够持久应对失败并可以长时间运行的代理，从上次停止的地方恢复。
* [人工介入](/oss/python/langgraph/interrupts)：通过在任何时候检查和修改代理状态来加入人工监督。
* [全面的内存](/oss/python/concepts/memory)：创建有状态的代理，既有用于持续推理的短期工作记忆，也有跨会话的长期记忆。
* [使用 LangSmith 进行调试](/langsmith/home)：通过可视化工具深入了解复杂代理行为，这些工具追踪执行路径、捕获状态转换并提供详细的运行时指标。
* [生产级部署](/langsmith/deployment)：使用可扩展的基础设施自信地部署复杂的代理系统，该基础设施旨在处理有状态的、长时间运行的工作流的独特挑战。
