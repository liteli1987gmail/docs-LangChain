---
title: 安装 LangChain
sidebarTitle: 安装
---

要安装 LangChain 包：

<CodeGroup>
    ```bash pip
    pip install -U langchain
    # 需要 Python 3.10+
    ```

    ```bash uv
    uv add langchain
    # 需要 Python 3.10+
    ```
</CodeGroup>




LangChain 提供了与数百个大型语言模型和数千个其他集成的集成。这些位于独立的 provider 包中。

<CodeGroup>
    ```bash pip
    # 安装 OpenAI 集成
    pip install -U langchain-openai

    # 安装 Anthropic 集成
    pip install -U langchain-anthropic
    ```
    ```bash uv
    # 安装 OpenAI 集成
    uv add langchain-openai

    # 安装 Anthropic 集成
    uv add langchain-anthropic
    ```
</CodeGroup>





<Tip>
请参阅[集成标签页](/oss/python/integrations/providers/overview)获取可用集成的完整列表。
</Tip>

现在您已经安装了 LangChain，您可以通过遵循[快速入门指南](/oss/python/langchain/quickstart)开始使用。
