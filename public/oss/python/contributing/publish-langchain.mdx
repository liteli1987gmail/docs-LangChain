**让你的集成对社区可用。**

<Warning>
**不要向 LangChain 或 Deep Agents 仓库提交集成 PR。**

新集成应作为**独立 PyPI 包**发布到你自己的 GitHub 组织或账户（例如 `langchain-yourservice`），而不是作为 PR 提交到 [`langchain-ai/langchain`](https://github.com/langchain-ai/langchain) 仓库。

主仓库只包含一小部分由 LangChain 团队维护的第一方集成（如 OpenAI、Anthropic 和 Ollama）。
</Warning>

现在你的包已经实现和测试，你可以发布它并添加文档以使其可以被社区发现。

## 发布你的包

<Info>
    本指南假设你已经实现了你的包并为其编写了测试。如果没有，请参阅[实现指南](/oss/python/contributing/implement-langchain)和[测试指南](/oss/python/contributing/standard-tests-langchain)。
</Info>

出于本指南的目的，我们将使用 PyPI 作为包注册表。如果你愿意，可以选择发布到其他注册表；说明会有所不同。

### 设置凭据

首先，确保你有一个 PyPI 账户：

<AccordionGroup>
    <Accordion title="如何创建 PyPI Token" icon="key">
        <Steps>
            <Step title="创建账户">
                转到 [PyPI 网站](https://pypi.org/) 并创建账户
            </Step>

            <Step title="验证邮箱">
                通过 PyPI 发送给你的链接验证你的邮箱地址
            </Step>

            <Step title="启用 2FA">
                转到你的账户设置，点击"生成恢复代码"以启用 2FA。要生成 API token，你**必须**启用 2FA
            </Step>

            <Step title="生成 token">
                转到你的账户设置并[生成一个新的 API token](https://pypi.org/manage/account/token/)
            </Step>
        </Steps>
    </Accordion>
</AccordionGroup>

## 添加文档

要为你包的文档在本网站的[集成选项卡](/oss/python/integrations/providers/overview)下添加，你需要创建相关的文档页面并在 [LangChain docs 仓库](https://github.com/langchain-ai/docs)中开一个 PR。

### 编写文档

根据你构建的集成类型，你需要创建不同类型的文档页面。LangChain 为不同类型的集成提供模板以帮助你入门。

<CardGroup>
    <Card title="聊天模型" icon="message" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/chat/TEMPLATE.mdx" arrow/>
    <Card title="工具/工具包" icon="tool" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/tools/TEMPLATE.mdx" arrow/>
    <Card title="中间件" icon="plug" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/middleware/TEMPLATE.mdx" arrow/>
    <Card title="向量存储" icon="database" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/vectorstores/TEMPLATE.mdx" arrow/>
</CardGroup>

<Tip>
    要参考现有文档，你可以查看[集成列表](/oss/python/integrations/providers/overview)并找到与你类似的集成。

    要查看给定文档页面的原始 markdown，使用页面右上角"Copy page"旁边的下拉按钮，选择"View as Markdown"。
</Tip>

### 向 docs 仓库提交 PR

Fork [LangChain docs 仓库](https://github.com/langchain-ai/docs)（而不是主要的 `langchain` 仓库）到你个人的 GitHub 账户，并在本地克隆它。为你的集成创建一个新分支。复制模板并使用你喜欢的 markdown 文本编辑器进行修改。编写文档时请务必参阅并遵循[文档指南](/oss/python/contributing/documentation)。

<Info>
    本 PR 仅用于**文档**。你的集成包本身应该位于你自己仓库下的仓库中，作为独立包发布到 PyPI。
</Info>

<Warning>
    如果出现以下情况，我们可能会拒绝 PR 或要求修改：
    - CI 检查失败
    - 存在严重的语法错误或拼写错误
    - [Mintlify 组件](/oss/python/contributing/documentation#mintlify-components)使用不正确
    - 页面缺少 [frontmatter](/oss/python/contributing/documentation#page-structure)
    - 缺少[本地化](/oss/python/contributing/documentation#localization)（在适用的情况下）
    - [代码示例](/oss/python/contributing/documentation#in-code-documentation)无法运行或有错误
    - 未达到[质量标准](/oss/python/contributing/documentation#quality-standards)
</Warning>

请耐心等待，因为我们处理大量 PR。我们将尽快审查你的 PR 并提供反馈或合并。**不要反复标记维护者关于你的 PR。**

<Note>
    如果你的 PR 包含 AI 生成的内容，你必须遵循我们的[可接受的 LLM 使用](/oss/python/contributing/overview#acceptable-uses-of-llms)政策。
</Note>
