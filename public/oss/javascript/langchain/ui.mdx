### 连接到您的代理

Agent Chat UI 可以连接到[本地](/oss/javascript/langchain/studio)和[已部署的代理](/oss/javascript/langchain/deploy)。

启动 Agent Chat UI 后，您需要配置它以连接到您的代理：

1. **图表 ID**：输入您的图表名称（在您的 `langgraph.json` 文件的 `graphs` 下找到）
2. **部署 URL**：您的代理服务器的端点（例如，本地开发用 `http://localhost:2024`，或您已部署代理的 URL）
3. **LangSmith API 密钥（可选）**：添加您的 LangSmith API 密钥（如果您使用本地代理服务器则不需要）

配置完成后，Agent Chat UI 将自动获取并显示您代理的任何中断线程。

<Tip>
  Agent Chat UI 开箱即用地支持渲染工具调用和工具结果消息。要自定义显示的消息，请参阅[在聊天中隐藏消息](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat)。
</Tip>
