---

只需不到 10 行代码，即可构建完全自定义的由大型语言模型驱动的代理和应用程序，并集成 [OpenAI、Anthropic、Google 等产品](/oss/javascript/integrations/providers/overview)。
LangChain 提供预构建的代理架构和模型集成，帮助您快速入门并将大型语言模型无缝整合到您的代理和应用程序中。

<Tip>
**LangChain 与 LangGraph 与 Deep Agents 的比较**

从 [Deep Agents](/oss/javascript/deepagents/overview/) 开始，这是一个" batteries-included"的代理，具有自动上下文压缩、虚拟文件系统和子代理生成等功能。Deep Agents 构建在 LangChain [代理](/oss/javascript/langchain/agents/)之上，您也可以直接使用 LangChain。

如果需要结合确定性和代理工作流程的高级需求，请使用 [LangGraph](/oss/javascript/langgraph/overview)，这是我们的底层编排框架。
</Tip>

## <Icon icon="wand" /> 创建一个代理



<CodeGroup>
    ```ts OpenAI
    // 首先安装: npm install langchain zod @langchain/openai
    import { createAgent, tool } from "langchain";
    import * as z from "zod";

    const getWeather = tool(
      (input) => `${input.city} 总是阳光明媚！`,
      {
        name: "get_weather",
        description: "Get the weather for a given city",
        schema: z.object({
          city: z.string().describe("The city to get the weather for"),
        }),
      }
    );

    const agent = createAgent({
      model: "gpt-5.4",
      tools: [getWeather],
    });

    console.log(
      await agent.invoke({
        messages: [{ role: "user", content: "What's the weather in San Francisco?" }],
      })
    );
    ```

<Columns cols={2}>
    <Card title="标准模型接口" icon="refresh" href="/oss/javascript/langchain/models" arrow cta="了解更多">
        不同的提供商在与模型交互方面有独特的 API，包括响应格式。LangChain 标准化了您与模型交互的方式，以便您可以无缝切换提供商并避免锁定。
    </Card>

    <Card title="易于使用、高度灵活的代理" icon="wand" href="/oss/javascript/langchain/agents" arrow cta="了解更多">
        LangChain 的代理抽象设计为易于入门，让您只需不到 10 行代码就能构建一个简单的代理。但它也提供了足够的灵活性，允许您进行您想要的所有上下文工程。
    </Card>

    <Card title="构建在 LangGraph 之上" icon="/images/brand/langgraph-icon.png" href="/oss/javascript/langgraph/overview" arrow cta="了解更多">

    </Card>
