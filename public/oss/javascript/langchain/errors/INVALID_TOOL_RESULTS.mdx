---
title: INVALID_TOOL_RESULTS
---

<Note>
    目前仅在 `langchainjs`（JavaScript/TypeScript）中使用。
</Note>

在工具调用操作期间传递不匹配、不足或过多的 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage) 对象给模型时会发生此错误。

错误源于一个基本要求：带有 `tool_calls` 的 assistant 消息后面必须跟着响应每个 `tool_call_id` 的工具消息。

当模型返回带有工具调用的 [`AIMessage`](https://reference.langchain.com/javascript/langchain-core/messages/AIMessage) 时，您必须为每个工具调用提供恰好一个对应的 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage)，并且 `tool_call_id` 值要匹配。

## 常见原因

* **响应不足**：如果模型请求两次工具执行但您只提供一条响应消息，模型将拒绝不完整的消息链
* **重复响应**：为同一个工具调用 ID 提供多个 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage) 对象会导致拒绝，ID 不匹配也会导致拒绝
* **孤立的工具消息**：发送 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage) 而没有前面包含工具调用的 [`AIMessage`](https://reference.langchain.com/javascript/langchain-core/messages/AIMessage) 违反了协议要求



以下是问题模式的示例：

```javascript
// Model requests two tool calls
responseMessage.tool_calls // Returns 2 calls

// But only one ToolMessage provided
chatHistory.push({
  role: "tool",
  content: toolResponse,
  tool_call_id: responseMessage.tool_calls[0].id
});

await modelWithTools.invoke(chatHistory); // Fails with INVALID_TOOL_RESULTS
```


## 故障排除

要解决此错误：

* **计算匹配对**：确保每个前面的 [`AIMessage`](https://reference.langchain.com/javascript/langchain-core/messages/AIMessage) 中的工具调用都对应一个 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage)
* **验证 ID**：确认每个 `ToolMessage.tool_call_id` 都与实际工具调用标识符匹配
