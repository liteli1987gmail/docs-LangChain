本指南将介绍如何使用 `UpstashRatelimitHandler` 添加基于请求数量或 Token 数量的速率限制。该处理程序使用 [Upstash 的 ratelimit 库](https://github.com/upstash/ratelimit-js/)，该库利用 [Upstash Redis](https://upstash.com/docs/redis/overall/getstarted)。

Upstash Ratelimit 的工作原理是每次调用 `limit` 方法时向 Upstash Redis 发送 HTTP 请求。系统会检查并更新用户的剩余 Token/请求数量。根据剩余 Token，我们可以停止代价高昂的操作（如调用大型语言模型或查询向量存储）的执行：

```tsx
const response = await ratelimit.limit();
if (response.success) {
  execute_costly_operation();
}
```

`UpstashRatelimitHandler` 允许您在几分钟内将这种速率限制逻辑整合到您的链中。

## 设置

首先，您需要访问 [Upstash 控制台](https://console.upstash.com/login) 创建一个 Redis 数据库（[请参阅我们的文档](https://upstash.com/docs/redis/overall/getstarted)）。创建数据库后，您需要设置环境变量：

```
UPSTASH_REDIS_REST_URL="****"
UPSTASH_REDIS_REST_TOKEN="****"
```

接下来，您需要安装 Upstash Ratelimit 和 `@langchain/community`：

<Tip>
有关安装 LangChain 软件包的常规说明，请参阅[此部分](/oss/javascript/langchain/install)。
</Tip>

```bash npm
npm install @upstash/ratelimit @langchain/community @langchain/core
```
现在您可以开始将速率限制添加到您的链中了！

## 按请求速率限制

假设我们希望允许用户每分钟调用我们的链 10 次。实现这一点非常简单：

```tsx
const UPSTASH_REDIS_REST_URL = "****";
const UPSTASH_REDIS_REST_TOKEN = "****";

import {
  UpstashRatelimitHandler,
  UpstashRatelimitError,
} from "@langchain/community/callbacks/handlers/upstash_ratelimit";
import { RunnableLambda } from "@langchain/core/runnables";
import { Ratelimit } from "@upstash/ratelimit";
import { Redis } from "@upstash/redis";

// create ratelimit
// 创建速率限制器
const ratelimit = new Ratelimit({
  redis: new Redis({
    url: UPSTASH_REDIS_REST_URL,
    token: UPSTASH_REDIS_REST_TOKEN,
  }),
  // 10 requests per window, where window size is 60 seconds:
  // 窗口大小为 60 秒，每窗口 10 个请求：
  limiter: Ratelimit.fixedWindow(10, "60 s"),
});

// create handler
// 创建处理程序
const user_id = "user_id"; // should be a method which gets the user id // 这应该是一个获取用户 ID 的方法
const handler = new UpstashRatelimitHandler(user_id, {
  requestRatelimit: ratelimit,
});

// create mock chain
// 创建模拟链
const chain = new RunnableLambda({ func: (str: string): string => str });

try {
  const response = await chain.invoke("hello world", {
    callbacks: [handler],
  });
  console.log(response);
} catch (err) {
  if (err instanceof UpstashRatelimitError) {
    console.log("Handling ratelimit.");
  }
}
```
请注意，我们是将处理程序传递给 `invoke` 方法，而不是在定义链时传递处理程序。

有关 `FixedWindow` 以外的速率限制算法，请参阅 [upstash-ratelimit 文档](https://upstash.com/docs/oss/sdks/ts/ratelimit/algorithms)。

在执行流水线中的任何步骤之前，ratelimit 将检查用户是否已超过请求限制。如果超过，将抛出 `UpstashRatelimitError`。

## 按 Token 速率限制

另一个选项是基于以下条件对链调用进行速率限制：

1. 提示词中的 Token 数量
2. 提示词和大型语言模型完成回复中的 Token 数量

这仅在您的链中有大型语言模型时才有效。另一个要求是您使用的大型语言模型应在其 `LLMOutput` 中返回 Token 使用量。返回的 Token 使用量字典格式取决于大型语言模型。要了解如何根据您的大型语言模型配置处理程序，请参阅下面"配置"部分末尾的内容。

### 工作原理

处理程序将在调用大型语言模型之前获取剩余 Token。如果剩余 Token 大于 0，则调用大型语言模型。否则将抛出 `UpstashRatelimitError`。

大型语言模型调用完成后，Token 使用量信息将用于从用户的剩余 Token 中扣除。在链的这个阶段不会抛出错误。

### 配置

对于第一种配置，只需按如下方式初始化处理程序：

```tsx
const user_id = "user_id"; // should be a method which gets the user id // 这应该是一个获取用户 ID 的方法
const handler = new UpstashRatelimitHandler(user_id, {
  requestRatelimit: ratelimit,
});
```
对于第二种配置，以下是初始化处理程序的方法：

```tsx
const user_id = "user_id"; // should be a method which gets the user id // 这应该是一个获取用户 ID 的方法
const handler = new UpstashRatelimitHandler(user_id, {
  tokenRatelimit: ratelimit,
});
```
您也可以同时使用基于请求和 Token 的速率限制，只需同时传递 `request_ratelimit` 和 `token_ratelimit` 参数即可。

为了让 Token 使用量正常工作，LangChain.js 中的大型语言模型步骤应以以下格式返回 Token 使用量字段：

```json
{
  "tokenUsage": {
    "totalTokens": 123,
    "promptTokens": 456,
    "otherFields: "..."
  },
  "otherFields: "..."
}
```
但是，LangChain.js 中并非所有大型语言模型都符合此格式。如果您的的大型语言模型以不同的键返回相同的值，您可以使用参数 `llmOutputTokenUsageField`、`llmOutputTotalTokenField` 和 `llmOutputPromptTokenField`，并将它们传递给处理程序：

```tsx
const handler = new UpstashRatelimitHandler(
  user_id,
  {
    requestRatelimit: ratelimit
    llmOutputTokenUsageField: "usage",
    llmOutputTotalTokenField: "total",
    llmOutputPromptTokenField: "prompt"
  }
)
```
以下是一个使用大型语言模型的链的示例：

```tsx
const UPSTASH_REDIS_REST_URL = "****";
const UPSTASH_REDIS_REST_TOKEN = "****";
const OPENAI_API_KEY = "****";

import {
  UpstashRatelimitHandler,
  UpstashRatelimitError,
} from "@langchain/community/callbacks/handlers/upstash_ratelimit";
import { RunnableLambda, RunnableSequence } from "@langchain/core/runnables";
import { OpenAI } from "@langchain/openai";
import { Ratelimit } from "@upstash/ratelimit";
import { Redis } from "@upstash/redis";

// create ratelimit
// 创建速率限制器
const ratelimit = new Ratelimit({
  redis: new Redis({
    url: UPSTASH_REDIS_REST_URL,
    token: UPSTASH_REDIS_REST_TOKEN,
  }),
  // 500 tokens per window, where window size is 60 seconds:
  // 窗口大小为 60 秒，每窗口 500 个 Token：
  limiter: Ratelimit.fixedWindow(500, "60 s"),
});

// create handler
// 创建处理程序
const user_id = "user_id"; // should be a method which gets the user id // 这应该是一个获取用户 ID 的方法
const handler = new UpstashRatelimitHandler(user_id, {
  tokenRatelimit: ratelimit,
});

// create mock chain
// 创建模拟链
const asStr = new RunnableLambda({ func: (str: string): string => str });
const model = new OpenAI({
  apiKey: OPENAI_API_KEY,
});
const chain = RunnableSequence.from([asStr, model]);

// invoke chain with handler:
// 使用处理程序调用链：
try {
  const response = await chain.invoke("hello world", {
    callbacks: [handler],
  });
  console.log(response);
} catch (err) {
  if (err instanceof UpstashRatelimitError) {
    console.log("Handling ratelimit.");
  }
}
```
