本指南将引导你完成使用自托管 LangSmith 实例的过程。

<Info>
本指南假设你已经部署了自托管 LangSmith 实例。如果没有，请参阅 [kubernetes 部署指南](/langsmith/kubernetes)。
</Info>

### 配置你要与 LangSmith 一起使用的应用程序

LangSmith 有一个用于与 hub 和 LangSmith 后端交互的单一 API。

1. 部署实例后，你可以通过 `http(s)://<host>` 访问 LangSmith UI。
2. LangSmith API 将在 `http(s)://<host>/api/v1` 提供
3. LangSmith Control Plane 将在 `http(s)://<host>/api-host` 提供

要使用实例的 API，你需要在应用程序中设置以下环境变量：

```bash
LANGSMITH_ENDPOINT=http://<host>/api/v1
LANGSMITH_API_KEY=foo # 如果使用 OAuth，设置为一个合法的 API 密钥
```

你也可以直接在 LangSmith SDK 客户端中配置这些变量：

```python
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```

设置上述内容后，你应该能够运行代码并在你自托管的实例中看到结果。我们建议运行 [*快速入门指南*](https://docs.smith.langchain.com/#quick-start) 来熟悉 LangSmith 的使用方法。

### 自签名证书

如果你为自托管 LangSmith 实例使用自签名证书，这可能会出现问题，因为 Python 有一套自己的可信证书，可能不包含你的自签名证书。要解决此问题，你可能需要使用类似 `truststore` 的东西将系统证书加载到你的 Python 环境中。

你可以这样做：

1. pip install truststore（或者根据你使用的包管理器使用类似的）

然后使用以下代码加载系统证书：

```python
import truststore
truststore.inject_into_ssl()
# 你的代码的其余部分
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```
