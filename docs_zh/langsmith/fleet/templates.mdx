LangSmith Fleet 包含[入门模板](https://www.langchain.com/templates)来帮助您快速创建代理。模板包括常见用例的预定义指令、[工具](/langsmith/fleet/tools)和[渠道](/langsmith/fleet/essentials#channels)（如适用）。您可以按原样使用模板，或作为基线进行自定义。

<Tip>
如果您是 Fleet 新手，请从分步[快速入门](/langsmith/fleet/quickstart)开始，使用模板构建您的第一个代理。
</Tip>

## 功能

模板是针对特定用例预配置的代理。每个模板包括以下组件：

### 预配置工具

模板带有精选的[工具](/langsmith/fleet/essentials#tools)，使代理能够执行特定操作。例如，电子邮件助手模板包括用于读取、发送和组织电子邮件的工具。工具通过 OAuth 身份验证连接到 Gmail、Slack 或 Linear 等外部服务。有关完整列表，请参阅[支持的工具](/langsmith/fleet/tools)。

### 系统指令

每个模板包括一个定义代理行为、个性和能力的_系统提示_（也称为_指令_）。系统提示指导代理如何解释用户请求和使用其可用工具。您可以自定义这些指令以匹配您的特定需求。

### 渠道（可选）

某些模板包括[渠道](/langsmith/fleet/essentials#channels)，允许代理自动响应外部事件。例如，Slack 机器人模板可能包括在 Slack 对话中提及代理时激活的渠道。渠道支持超越基于聊天的交互的主动代理行为。

### 克隆和自定义

模板作为起点，供您克隆以创建自己的代理。当您克隆模板时，您会创建一个独立的副本，可以自定义而不会影响原始模板。您可以修改提示词、添加或删除工具、附加不同的渠道，并切换模型以根据您的需求定制代理。
