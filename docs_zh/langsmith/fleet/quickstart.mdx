在这个快速入门中，您将使用预定义的**电子邮件助手**[模板](/langsmith/fleet/templates)来为您整理和管理收件箱。
- 选择不同的模板。

<Callout icon="message" color="#8B5CF6" iconType="regular">
您将通过聊天与您的代理互动，就像发短信给一个有用的助手一样。
</Callout>

## 开始之前

您需要：
- 一个 LangSmith 账户（[在此注册](https://smith.langchain.com/agents?skipOnboarding=true)）。
- 一个 Gmail 账户。
- 一个 Google 日历。
- 一个 OpenAI 或 Anthropic API 密钥（第 1 步将向您展示如何获取）。

## 1. 获取您的模型 API 密钥

您的代理需要一个 API 密钥来连接到 AI 模型。AI 模型是您的代理理解和响应您的请求的原因。

<Tabs>
  <Tab title="OpenAI (ChatGPT)">
    1. 前往 [platform.openai.com/api-keys](https://platform.openai.com/api-keys)。
    1. 点击**创建新的密钥**。
    1. 给它起个名字，比如"Fleet"。
    1. 复制密钥（它以 `sk-` 开头）。
    1. 将其保存在安全的地方，您在第 2 步需要它。
  </Tab>

  <Tab title="Anthropic (Claude)">
    1. 前往 [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)。
    2. 点击**创建密钥**。
    3. 给它起个名字，比如"Fleet"。
    4. 复制密钥（它以 `sk-ant-` 开头）。
    5. 将其保存在安全的地方，您在第 2 步需要它。
  </Tab>
</Tabs>

<Warning>
两项服务都按使用量收费。
</Warning>

## 2. 将您的 API 密钥添加到 LangSmith

现在您将把您的 API 密钥添加到 LangSmith，以便您的代理可以使用它：

<Steps>
  <Step title="打开设置">
    1. 前往 [smith.langchain.com](https://smith.langchain.com)。
    2. 点击左下角的<Icon icon="settings" /> **设置**图标。
  </Step>

  <Step title="转到密钥">
    点击顶部的**密钥**选项卡。
  </Step>

  <Step title="添加您的密钥">
    1. 点击**添加密钥**。
    2. 对于**密钥**，输入：
       - `OPENAI_API_KEY`（如果使用 OpenAI）
       - `ANTHROPIC_API_KEY`（如果使用 Anthropic）
    3. 对于**值**，粘贴您在第 1 步复制的 API 密钥。
    4. 点击**保存密钥**。
  </Step>
</Steps>

<Callout type="success" icon="check" color="#10B981" iconType="regular">
您的代理现在可以访问 AI 模型来理解和响应您的请求。接下来，您将创建您的代理。
</Callout>

## 3. 创建您的代理

<Steps>
  <Step title="导航到 Fleet">
    1. 在 [LangSmith UI](https://smith.langchain.com) 中，点击左侧导航顶部的<Icon icon="pointer"/> **切换到 Fleet**。
  </Step>

  <Step title="选择一个模板">
    1. 在左侧导航中选择**模板**。
    1. 选择**电子邮件助手**模板。
    1. 点击**使用此模板**。

    <Tip>
    如果您不想从模板开始，您还有两个其他选项。从 **+ 新代理**页面：
    - **聊天**：使用聊天界面描述您的代理，它将帮助您逐步创建。
    - **手动**：选择**手动创建**以在配置页面上没有任何预填响应的情况下构建您的代理。
    </Tip>
  </Step>

  <Step title="授权账户">
    您的代理将要求您连接您的 Google 账户：

    1. 点击**连接**。
    1. 使用您的 Google 账户登录。
    1. 审查权限并点击**允许**。
    1. 您将被重定向回 LangSmith，在那里将为您创建代理。
  </Step>

</Steps>

<Info>
您的代理仅在处理您交给它的任务时访问您的账户。您可以随时在您的 Google 账户设置中撤销访问权限。
</Info>

## 4. 查看代理模板

<Steps>

  <Step title="查看和自定义模板">

    此时，您可以查看电子邮件助手的模板指令。如果需要，您可以调整指令。

    如果进行了任何更改，请点击**保存更改**。
  </Step>

  <Step title="开始测试聊天">
    1. 在配置页面的右侧面板中，选择**测试聊天**选项卡。
    1. 在聊天界面中试用电子邮件助手，例如：

        > _给我收到的需要我审核的电子邮件加上"审核"标签_
  </Step>

  <Step title="代理开始工作">
    您的代理将开始工作，并为每个需要您批准的步骤提供**继续**选项。

    3. 当您测试代理时，可以编辑指令，或添加您可能需要的工具。满意结果后点击**保存更改**。

  </Step>

</Steps>

## 编辑您的代理

您可能需要更新代理的指令或包含更多工具。您可以直接与代理聊天请求更新，或者您可以：

1. 从左侧导航中的**我的代理**中，选择您要编辑的代理。
1. 选择<Icon icon="pencil"/> **编辑代理**。

从代理的编辑页面，您可以：

- 使用 **+ 添加工具**添加工具以连接更多应用和服务，如 Slack、GitHub 或 Linear。
- 使用 **+ 添加子代理**添加更多助手以将复杂任务分解为专业子任务。
- 请求对现有工具进行审查暂停。
- 修改现有工具。
- 探索可以自动启动您的代理的渠道。
