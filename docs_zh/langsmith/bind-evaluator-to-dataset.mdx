LangSmith 支持两种对通过 SDK 创建的实验进行评分的方法：

* **通过编程方式**，在代码中指定评估器（详见[如何评估大型语言模型应用](/langsmith/evaluate-llm-application)）
* 通过在 UI 中**将评估器绑定到数据集**。这将自动对创建的任何新实验运行评估器，以及您通过 SDK 设置的任何评估器。当您迭代应用程序（目标函数）并拥有一组要针对所有实验运行的标准评估器时，这很有用。

## 在数据集上配置评估器

1. 在 [LangSmith UI](https://smith.langchain.com) 中，选择一个数据集。
1. 点击 **Evaluators** 选项卡。
1. 点击 **+ Evaluator** 打开 **Add Evaluator** 面板。
1. 选择以下之一：
   - **从零开始创建**：构建新的[大型语言模型即评判者](/langsmith/llm-as-judge)、[代码](/langsmith/online-evaluations-code)或[复合](/langsmith/composite-evaluators-ui)评估器，或选择 **From labeled data** 创建一个与人工反馈对齐的大型语言模型即评判者评估器[对齐到人工反馈](/langsmith/improve-judge-evaluator-feedback)。
   - **附加现有评估器**：选择工作区中已有的评估器以重用它。
   - **从模板创建**：从现成的评估器开始。

<Note>
当您为数据集配置评估器时，它只会影响配置评估器后创建的实验运行。它不会影响配置评估器之前创建的实验运行的评估。
</Note>

## 大型语言模型即评判者评估器

将评估器绑定到数据集的过程与在 Playground 中配置大型语言模型即评判者评估器的过程非常相似。查看[在 Playground 中配置大型语言模型即评判者评估器的说明。](/langsmith/llm-as-judge?mode=ui)

## 自定义代码评估器

将代码评估器绑定到数据集的过程与在线评估中配置代码评估器的过程非常相似。查看[配置代码评估器](/langsmith/online-evaluations-code)的说明。

在在线评估中配置代码评估器和将代码评估器绑定到数据集之间的唯一区别是，绑定到数据集的自定义代码评估器可以引用作为数据集 `Example` 一部分的输出。

对于绑定到数据集的自定义代码评估器，评估器函数接受两个参数：

* 一个 `Run`（[参考](/langsmith/run-data-format)）。这代表实验中的新运行。例如，如果您通过 SDK 运行实验，这将包含您正在测试的链或模型的输入/输出。
* 一个 `Example`（[参考](/langsmith/example-data-format)）。这代表数据集中链或模型使用的参考示例。Run 和 Example 的 `inputs` 应该相同。如果您的 Example 有参考 `outputs`，则可以使用它来与运行的输出进行比较以进行评分。

以下代码显示了一个简单的评估器函数示例，该函数检查输出是否与参考输出完全相等。

<CodeGroup>

```python Python
import numpy as np

def perform_eval(run, example):
    # run is a Run object
    # example is an Example object
    output = run['outputs']['output']
    ref_output = example['outputs']['outputs']
    output_match = np.array_equal(output, ref_output)

    return { "exact_match": output_match }
```

```javascript JavaScript
function perform_eval(run, example) {
    // run is a Run object
    // example is an Example object
    const output = run.outputs.output;
    const refOutput = example.outputs.outputs;

    // Deep equality check for arrays/objects
    const outputMatch = JSON.stringify(output) === JSON.stringify(refOutput);

    return { "exact_match": outputMatch };
}
```

</CodeGroup>
