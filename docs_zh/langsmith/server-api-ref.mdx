Agent Server API 参考在每个[部署](/langsmith/deployment)的 `/docs` 端点（例如 `http://localhost:8124/docs`）中可用。

在侧栏中的 **Agent Server API** 部分浏览完整 API 参考，或查看以下端点组：

- [Assistants](/langsmith/agent-server-api/assistants) - 图的配置实例
- [Threads](/langsmith/agent-server-api/threads) - 一组运行的累积输出
- [Thread Runs](/langsmith/agent-server-api/thread-runs) - 在线程上调用图/助手
- [Stateless Runs](/langsmith/agent-server-api/stateless-runs) - 无状态持久化的调用
- [Crons](/langsmith/agent-server-api/crons) - 按计划定期运行
- [Store](/langsmith/agent-server-api/store) - 用于长期记忆的持久化键值存储
- [A2A](/langsmith/agent-server-api/a2a) - 代理到代理协议端点
- [MCP](/langsmith/agent-server-api/mcp) - 模型上下文协议端点
- [System](/langsmith/agent-server-api/system) - 健康检查和服务器信息

## 身份验证

对于部署到 LangSmith，需要身份验证。在每个请求中传递 `X-Api-Key` 头到 Agent Server。该头的值应设置为部署 Agent Server 的组织的有效 LangSmith API 密钥。

示例 `curl` 命令：

```shell
curl --request POST \
  --url http://localhost:8124/assistants/search \
  --header 'Content-Type: application/json' \
  --header 'X-Api-Key: LANGSMITH_API_KEY' \
  --data '{
  "metadata": {},
  "limit": 10,
  "offset": 0
}'
```
