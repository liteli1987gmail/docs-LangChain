LangSmith UI 目前不支持从 LangSmith 自托管实例中删除单个组织。但是，这可以通过直接从 ClickHouse 中的所有物化视图（runs_history 视图除外）以及 runs 和 feedbacks 表中删除所有追踪，然后将组织从 PostgreSQL tenants 表中移除来实现。

此命令使用 Organization ID 作为参数。

### 前置条件

确保你已准备好以下工具/项目。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. PostgreSQL 客户端

   * [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

3. PostgreSQL 数据库连接：

   * Host
   * Port
   * Username
     * 如果使用捆绑版本，则是 `postgres`
   * Password
     * 如果使用捆绑版本，则是 `postgres`
   * Database name
     * 如果使用捆绑版本，则是 `postgres`

4. Clickhouse 数据库凭据

   * Host
   * Port
   * Username
     * 如果使用捆绑版本，则是 `default`
   * Password
     * 如果使用捆绑版本，则是 `password`
   * Database name
     * 如果使用捆绑版本，则是 `default`

5. 从你将运行迁移脚本的计算机到 PostgreSQL 数据库的连接。

   * 如果你使用的是捆绑版本，你可能需要将 postgresql 服务端口转发到本地计算机。
   * 运行 `kubectl port-forward svc/langsmith-postgres 5432:5432` 将 postgresql 服务端口转发到本地计算机。

6. 从你将运行迁移脚本的计算机到 Clickhouse 数据库的连接。

   * 如果你使用的是捆绑版本，你可能需要将 clickhouse 服务端口转发到本地计算机。
     * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123` 将 clickhouse 服务端口转发到本地计算机。
   * 如果你使用的是 Clickhouse Cloud，你需要指定 --ssl 标志并使用端口 `8443`

7. 用于删除组织的脚本

   * 下载[删除组织脚本](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/delete_organization_sh)

### 运行单个组织的删除脚本

运行以下命令来执行组织移除脚本：

```bash
sh delete_organization.sh <postgres_url> <clickhouse_url> --organization_id <organization_id>
```

例如，如果你使用带有端口转发的捆绑版本，命令将如下所示：

```bash
sh delete_organization.sh "postgres://postgres:postgres@localhost:5432/postgres" "clickhouse://default:password@localhost:8123/default" --organization_id 4ec70ec7-0808-416a-b836-7100aeec934b
```

如果你访问 LangSmith UI，你应该现在看到组织不再存在。
