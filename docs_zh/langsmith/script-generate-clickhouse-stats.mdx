作为排查 LangSmith 自托管实例问题的一部分，LangChain 团队可能会要求你生成 Clickhouse 统计信息，以帮助我们了解内存和 CPU 消耗以及连接并发情况。

此命令将生成一个可以与 LangChain 团队共享的 CSV 文件。

### 前置条件

确保你已准备好以下工具/项目。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. Clickhouse 数据库凭据

   * Host
   * Port
   * Username
     * 如果使用捆绑版本，则是 `default`
   * Password
     * 如果使用捆绑版本，则是 `password`
   * Database name
     * 如果使用捆绑版本，则是 `default`

3. 从你将运行 `get_clickhouse_stats` 脚本的计算机到 Clickhouse 数据库的连接。

   * 如果你使用的是捆绑版本，你可能需要将 clickhouse 服务端口转发到本地计算机。
   * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123` 将 clickhouse 服务端口转发到本地计算机。

4. 用于生成 ClickHouse 统计的脚本

   * 下载 [ClickHouse 统计脚本](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/get_clickhouse_stats.sh)

### 运行 clickhouse 统计生成脚本

运行以下命令来执行统计生成脚本：

```bash
sh get_clickhouse_stats.sh <clickhouse_url> --output path/to/file.csv
```

例如，如果你使用带有端口转发的捆绑版本，命令将如下所示：

```bash
sh get_clickhouse_stats.sh "clickhouse://default:password@localhost:8123/default" --output clickhouse_stats.csv
```

运行此命令后，你应该会看到创建了一个文件 clickhouse_stats.csv，其中包含 Clickhouse 统计信息。
