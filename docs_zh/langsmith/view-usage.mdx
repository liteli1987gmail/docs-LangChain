LangSmith 根据您的[计划](/langsmith/pricing-plans)和[部署类型](/langsmith/platform-setup)提供多种视图来查看您的[组织](/langsmith/administration-overview)使用情况。本页解释了哪些数据可用、每个指标的含义，以及[自托管](/langsmith/self-hosted)部署有哪些限制。

## 使用情况视图

| 视图 | 在哪里找到 | 谁可以查看 | 计划可用性 |
|------|-----------------|----------------|-------------------|
| [使用情况图](#usage-graph) |**Enterprise**: 设置 > 使用情况 > 使用情况图<br></br>**Self-serve**: 设置 > 计费 > 使用情况图 | 所有组织成员 | 所有计划 |
| [详细使用情况](#granular-usage) | **Enterprise**: 设置 > 使用情况 > 详细使用情况<br></br>**Self-serve**: 设置 > 计费 > 详细使用情况 | 所有组织成员 | 所有计划 |
| [合同消耗](#contract-burndown) | **Enterprise**: 设置 > 使用情况 > 合同使用情况<br></br>**Self-serve**: 设置 > 计费 > 合同使用情况 | 仅组织管理员（`organization:manage`） | 仅 Enterprise |
| [发票](#invoices) | 设置 > 计费 > 发票 | 所有组织成员 | 仅 Self-serve 云 |

## 使用情况图

使用情况图显示您组织的聚合追踪消耗，按工作区细分。它涵盖当前计费周期，不显示支出——要查看支出，请参阅发票。

导航到 **设置** → **计费和使用情况** → **使用情况图**。

### 计费指标

| 指标 | 它计算什么 |
|--------|----------------|
| **LangSmith 追踪（基础费用）** | 计费期间发送到 LangSmith 的每条追踪，无论数据保留层如何。 |
| **LangSmith 追踪（扩展数据保留升级）** | 升级到扩展保留的追踪（默认 400 天，[可为企业客户自定义](/langsmith/data-purging-compliance#customize-extended-retention-policy)）。这些费用在基础费用之外收取。 |
| **LangSmith 部署运行** | 部署的 LangGraph 智能体的端到端调用。请参阅[LangSmith 部署计费](/langsmith/billing#langsmith-deployment-billing)了解定价详情。 |
| **LangSmith Fleet 运行** | [Fleet](/langsmith/fleet) 智能体的端到端调用。云托管和自托管部署分开追踪。 |
| **LangSmith 部署节点执行** | 跨部署智能体的各个 LangGraph 节点执行。部署智能体图中的每个步骤算作一个节点执行。云托管和自托管部署分开追踪。 |

有关追踪保留层的更多详细信息，请参阅[数据保留](/langsmith/administration-overview#data-retention)。

<Note>
使用情况图使用 `tenant_id` 和工作区 ID 作为同义词。
</Note>

## 合同消耗

带有预付承诺的企业客户可以查看其合同已被消耗了多少。

导航到 **设置** → **使用情况配置** → **合同使用情况**。

此视图显示：

- **使用情况摘要**：总使用量、总积分和任何超额使用量。当使用量超过您的总预付承诺时，会产生超额使用量。
- **承诺进度条**：每个承诺的视觉指示器，显示已消耗的百分比以及已使用与剩余的美元金额。合同可以有多个承诺，适用于不同的时间段（例如，多年合同的第 1 年和第 2 年）或不同的产品。
- **月度使用量图表**：条形图，显示合同期内每个月的使用量。
- **产品费率**：您有权获得的产品及其价格的表格。

<Note>
合同消耗需要 [`organization:manage` 权限](/langsmith/organization-workspace-operations)，仅适用于带有预付承诺的企业客户。
</Note>

## 发票

发票仅适用于**自选云计划**。企业云组织有单独的使用情况视图来跟踪支出。

导航到 **设置** → **计费和使用情况** → **发票** 以查看您的使用情况如何转化为支出。显示的第一张发票是您当前月份的发票草稿，反映您目前的累计支出。

## 详细使用情况

详细使用情况为您提供按您选择的维度（工作区、项目、用户或 API 密钥）和您选择的时间范围细分的追踪计数。这对于内部成本回收、识别高使用量团队或审计追踪活动很有用。

导航到 **设置** → **计费和使用情况** → **详细使用情况**，或使用[详细使用情况 API](/langsmith/granular-usage)。

### 这里"追踪"的含义

详细使用情况视图计算**追踪**：根级运行及其所有子跨度计为一个单元。这与[计费](/langsmith/billing)使用的单位相同。它不单独计算各个跨度、令牌或模型调用。

### 记录使用情况的时间

详细使用情况按**插入时间**（追踪被 LangSmith 接收和存储的时间）记录追踪，而不是按它在应用程序中运行的时间。在实践中，这种差异通常可以忽略不计，但具有明显延迟发送的追踪（例如，缓冲的 SDK 上传）可能会出现在比预期更晚的时间桶中。

有关分组选项、时间桶大小和 API 参考，请参阅[详细计费使用情况](/langsmith/granular-usage)。

## 自托管限制

由于计费基础设施的差异，[自托管](/langsmith/self-hosted) LangSmith [部署](/langsmith/deployment)与[云](/langsmith/cloud)相比有一组不同的可用使用情况视图。

| **功能** | **自托管可用性** |
|---------|--------------------------|
| 详细使用情况（追踪归属） | 通过功能标志或版本 ≥ 0.13.12 可用 |
| 使用情况图（聚合追踪） | 在 Helm chart 0.9.5 及更高版本上可用 |
| 合同消耗 | 当 Beacon phone-home 启用时可用 |
| 发票和支付管理 | 不可用（计费在 LangSmith 外部处理） |

### 详细使用情况 on self-hosted

自托管部署可以使用详细使用情况，但需要明确选择加入：

- 在 **LangSmith 0.13.12 及更高版本**上，详细使用情况收集默认启用。
- 在**早期版本**上，通过设置以下两个环境变量来启用它：

    ```env
    DEFAULT_ORG_FEATURE_ENABLE_GRANULAR_USAGE_REPORTING=true
    GRANULAR_USAGE_TABLE_ENABLED=true
    ```

<Warning>
数据收集从启用该功能的那一刻开始。启用之前没有历史使用数据的回填。在选择何时启用此功能时，请相应地进行规划。
</Warning>

### 自托管上的聚合使用情况

使用情况图在运行 Helm chart 0.9.5 或更高版本的自托管部署上可用。LangSmith 自动生成并同步组织使用情况图表，可在 **设置** → **使用情况和计费** → **使用情况图** 下找到：

- **按工作区的使用情况**：每个工作区的追踪计数（根运行）
- **组织使用情况**：整个组织的总追踪计数

图表每 5 分钟刷新一次以包含新工作区，不可编辑。

有关以编程方式访问追踪计数，请参阅[查看整个组织的追踪计数](/langsmith/self-host-organization-charts)。
