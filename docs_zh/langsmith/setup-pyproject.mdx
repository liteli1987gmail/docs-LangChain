应用程序必须使用[配置文件](/langsmith/cli#configuration-file)进行配置，才能部署到 LangSmith（或自托管）。本操作指南讨论了使用 `pyproject.toml` 定义包依赖项进行部署的基本步骤。

本示例基于[此仓库](https://github.com/langchain-ai/langgraph-example-pyproject)，该仓库使用 LangGraph 框架。

最终的仓库结构将如下所示：

```bash
my-app/
├── my_agent # 所有项目代码位于此处
│   ├── utils # 图的工具
│   │   ├── __init__.py
│   │   ├── tools.py # 图的工具
│   │   ├── nodes.py # 图的节点函数
│   │   └── state.py # 图的状态定义
│   ├── __init__.py
│   └── agent.py # 构建图的代码
├── .env # 环境变量
├── langgraph.json  # LangGraph 的配置文件
└── pyproject.toml # 项目的依赖项
```

您还可以使用以下方式设置：

- `requirements.txt`：有关依赖管理，请查看[此操作指南](/langsmith/setup-app-requirements-txt)了解如何使用 `requirements.txt` 进行 LangSmith 设置。
- monorepo：要部署位于 monorepo 中的图，请查看[此仓库](https://github.com/langchain-ai/langgraph-example-monorepo)了解如何操作的示例。

每一步之后，都会提供一个示例文件目录来演示代码的组织方式。

## 指定依赖项

依赖项可以选择在以下文件中指定：`pyproject.toml`、`setup.py` 或 `requirements.txt`。如果未创建这些文件，则可以稍后在[配置文件](#create-the-configuration-file)中指定依赖项。

## 指定环境变量

环境变量可以选择在文件中指定（例如 `.env`）。请参阅[环境变量参考](/langsmith/env-var)为部署配置其他变量。

示例 `.env` 文件：

```
MY_ENV_VAR_1=foo
MY_ENV_VAR_2=bar
FIREWORKS_API_KEY=key
```

示例文件目录：

```bash

├── .env # 包含环境变量的文件
└── pyproject.toml
```

## 定义图

实现您的图。图可以在单个文件或多个文件中定义。请注意每个要包含在应用程序中的 @[CompiledStateGraph] 的变量名。在创建[配置文件](/langsmith/cli#configuration-file)时将使用变量名。

示例 `agent.py` 文件，展示了如何从您定义的其他模块导入（此处未显示模块的代码，请参阅[此仓库](https://github.com/langchain-ai/langgraph-example-pyproject)查看其实现）：

```python
# my_agent/agent.py
from typing import Literal
from typing_extensions import TypedDict

from langgraph.graph import StateGraph, END, START
from my_agent.utils.nodes import call_model, should_continue, tool_node # import nodes
from my_agent.utils.state import AgentState # import state

# Define the runtime context
class GraphContext(TypedDict):
    model_name: Literal["anthropic", "openai"]

workflow = StateGraph(AgentState, context_schema=GraphContext)
workflow.add_node("agent", call_model)
workflow.add_node("action", tool_node)
workflow.add_edge(START, "agent")
workflow.add_conditional_edges(
    "agent",
    should_continue,
    {
        "continue": "action",
        "end": END,
    },
)
workflow.add_edge("action", "agent")

graph = workflow.compile()
```

示例文件目录：

```bash
my-app/
├── my_agent # 所有项目代码位于此处
│   ├── utils # 图的工具
│   │   ├── __init__.py
│   │   ├── tools.py # 图的工具
│   │   ├── nodes.py # 图的节点函数
│   │   └── state.py # 图的状态定义
│   ├── __init__.py
│   └── agent.py # 构建图的代码
├── .env
└── pyproject.toml
```

## 创建配置文件

创建名为 `langgraph.json` 的[配置文件](/langsmith/cli#configuration-file)。请参阅[配置文件参考](/langsmith/cli#configuration-file)获取配置文件中每个键的详细说明。

示例 `langgraph.json` 文件：

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./my_agent/agent.py:graph"
  },
  "env": ".env"
}
```

请注意，`CompiledGraph` 的变量名出现在顶级 `graphs` 键中每个子键值末尾（即 `:<variable_name>`）。

<Warning>
    **配置文件位置**
    配置文件必须放置在与包含编译图和相关依赖项的 Python 文件相同的级别或更高级别的目录中。
</Warning>

示例文件目录：

```bash
my-app/
├── my_agent # 所有项目代码位于此处
│   ├── utils # 图的工具
│   │   ├── __init__.py
│   │   ├── tools.py # 图的工具
│   │   ├── nodes.py # 图的节点函数
│   │   └── state.py # 图的状态定义
│   ├── __init__.py
│   └── agent.py # 构建图的代码
├── .env # 环境变量
├── langgraph.json  # LangGraph 的配置文件
└── pyproject.toml # 项目的依赖项
```
