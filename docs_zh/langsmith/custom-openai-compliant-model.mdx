Playground 允许您使用任何符合 OpenAI API 的模型。您可以通过在 Playground 中设置代理提供商来使用您的模型。

## 部署 OpenAI 兼容模型

许多提供商提供 OpenAI 兼容模型或代理服务。这方面的一些例子包括：

* [LiteLLM Proxy](https://github.com/BerriAI/litellm?tab=readme-ov-file#quick-start-proxy---cli)
* [Ollama](https://ollama.com/)

您可以使用这些提供商来部署您的模型并获取符合 OpenAI API 的 API 端点。

查看完整的[规范](https://platform.openai.com/docs/api-reference/chat)以获取更多信息。

## 在 Playground 中使用模型

一旦您部署了模型服务器，您可以在 [Playground](/langsmith/prompt-engineering-concepts#playground) 中使用它。

要访问 **Prompt Settings** 菜单：

1. 在 **Prompts** 标题下选择模型名称旁边的齿轮 <Icon icon="settings" iconType="solid" /> 图标。
2. 在 **Model Configuration** 选项卡中，在下拉菜单中选择要编辑的模型。
3. 对于 **Provider** 下拉菜单，选择 **OpenAI Compatible Endpoint**。
4. 将您的 OpenAI 兼容端点添加到 **Base URL** 输入框。参见[Base URL 格式](#base-url-format)示例。

有关如何存储您的模型配置的信息，请参阅[配置提示词设置](/langsmith/managing-model-configurations)。

## Base URL 格式

**Base URL** 应指向您的 OpenAI 兼容 API 服务器的根目录。
LangSmith 会自动附加 `/chat/completions`——不要在 Base URL 中包含它。

### 示例 Base URLs

| 提供商 | 示例 Base URL |
|----------|-----------------|
| [Ollama](https://ollama.com/)（本地） | `http://localhost:11434/v1` |
| [LiteLLM Proxy](https://github.com/BerriAI/litellm)（本地） | `http://localhost:4000` |
| [vLLM](https://docs.vllm.ai/)（本地） | `http://localhost:8000/v1` |
| 自托管（远程） | `https://my-model-server.example.com/v1` |

支持自定义路径前缀。如果您的服务器在 `/api/v2/chat/completions` 暴露 completions，请将 Base URL 设置为 `https://my-server.example.com/api/v2`。
