**LangSmith 是一个与框架无关的平台，用于构建、调试和部署 AI 代理和大型语言模型应用程序。** 在一个地方追踪请求、评估输出、测试提示词和管理部署，配合您的代理技术栈。

## 开始使用

<Steps>
    <Step title="创建账户" icon="user-plus">
        在 [smith.langchain.com](https://smith.langchain.com) 注册（无需信用卡）。
        您可以使用 **Google**、**GitHub** 或**邮箱**登录。
    </Step>
    <Step title="创建 API 密钥" icon="key">
        前往您的[设置页面](https://smith.langchain.com/settings) → **API Keys** → **Create API Key**。
        复制密钥并安全保存。
    </Step>
    <Step title="选择您的集成" icon="plug">
        LangSmith 与许多框架和提供商合作。浏览[可用集成](/langsmith/integrations)以连接您的技术栈。
    </Step>
</Steps>

一旦您的账户和 API 密钥准备就绪，请选择快速入门开始使用 LangSmith 构建：
