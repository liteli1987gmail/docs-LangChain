## langsmith-0.15.0-rc.2

- 改进了自动化表中"已启用"列以防止标题被截断。
- 修复了"polly"按钮图标在点击时粘附在光标上的问题。
- 使 MCP 服务器过滤器下拉菜单在 fleet 中可滚动。
- 在评估器的"创建时间"和"更新时间"字段上添加了排序功能。
- 实现了在"polly"中对工作区回退到 LANGSMITH_AUTH_ENDPOINT 的功能。
- 修复了文件创建时清除 fleet 中活动中断状态的问题。
- 为"polly"中的 JWT 注入添加了 URL 允许列表 enforcement。
- 在 fleet 中添加了用户成本表和代理/用户切换功能。
- 添加了新的 fleet-admin:read 权限。
- 通过从会话统计查询中移除不必要的连接来提高加载性能。
- 为前端中的模板/卡片选择添加了分析跟踪。
- 为问题板 UI 添加了时间戳和改进的布局。
- 修复了导致评估器重用 playground 出现故障的错误。
- 为迁移添加了 PostgreSQL mTLS 支持。
- 添加了对具有可组合数据库的 MCP 服务器的支持。
- 通过处理具有多个 SSO 提供商记录的非 SSO 登录增强了安全性。
- 使评估器源运行链接能够抵御无效 ID。
- 添加了评估器详情页 UX 改进。
- 添加了移动端友好的登录和可安装的 PWA 支持。
- 改进了评估器选项卡中的整体 UX，提供了建议评估器的轮播。
- 为敏感数据访问端点启用了审计日志记录。
- 在 Redis 中添加了会话/数据集活动跟踪，以便运行规则到 SmithDB。
- 为 fleet 项目添加了追踪项目和使用量仪表板。
- 在代理构建器部分的导航栏中添加了"手动创建代理"按钮。
- 修复了消息视图中工具调用渲染问题。
- 改进了会话同步性能以防止空闲会话。
- 添加了新的模型支持（Opus 4.7、GLM5 和 minimax 2.5）用于代理评估。
- 改进了前端中评估器的分支和使用 UX。
- 减少了 playground 中不必要的重新渲染以提高性能。
- 使用 ComparisonStoreProvider 启用了"包裹实验快速入门"以解决 UI 错误。
- 引入了更新自托管许可证的新端点。
- 通过性能改进优化了空闲会话处理。
- 为所有剩余的 Go 写端点添加了审计日志记录。
- 通过新的验证机制和 Python 服务路由分离增强了"byoc"支持。

## langsmith-0.14.0

LangSmith Self-Hosted v0.14 带来了 **Polly**（我们的追踪和运行 AI 助手）到自托管，**ABAC 和审计日志** GA（默认启用），并默认启用 **LLM Auth Proxy**，提供 URL 允许列表和更丰富的 JWT 声明。管理员可以获得跨代理构建器、Polly、Insights、Playground 和评估器共享的**统一模型配置**，以及细粒度的**提示词所有者**来控制谁可以提升或删除单个提示词。评估器获得了**多模态支持**，工作区现在可以在追踪项目上设置**成本警报**。Playground 模型支持扩展（通过 Vertex AI 的 Anthropic、自定义 Azure 模型、Bedrock 推理配置文件、Gemini 3.1 Pro、GPT-5.3 / 5.4、Baseten + GLM-5），新的代理工具和触发器适用于 Google Sheets & Docs、Outlook、Teams 和 Salesforce SOQL。在基础设施方面，v0.14 添加了 blob 存储的 **GCS 工作负载身份**支持、**Valkey** 作为 Redis 的直接替代品，以及更安全推广的预升级迁移钩子。

按照[升级说明](/langsmith/self-host-upgrades)获取所有功能。要与 LangChain 支持安排升级时间，请联系 `support@langchain.dev`。

### 破坏性更改

- 修复了 `host-backend` 没有拾取 `commonEnv` 的问题。这可能导致需要移除的重复环境变量。

### 基础设施更改

- 迁移现在作为 `Pre-upgrade` 钩子在镜像版本推出之前运行。这将防止迁移失败时出现问题。
- **GCS 工作负载身份支持** — 使用云原生工作负载身份而不是长期凭据向 GCS blob 存储进行身份验证。
- **Valkey 支持** — Valkey 现在可用作 Redis 的直接替代品。

### 新功能

- **自托管上的 Polly** — 我们的 AI 助手，用于理解追踪、运行和评估器反馈，现在可在自托管中使用。
- **ABAC 和审计日志 GA** — 属性基于访问控制和审计日志默认为自己托管部署启用。
- **LLM Auth Proxy 默认启用** — URL 允许列表阻止凭据转发到非预期主机，JWT 现在携带 `organization_name` 和 `workspace_name` 声明。
- **统一模型配置** — 代理构建器、Polly、Insights、Playground 和评估器现在共享一组模型配置，工作区管理员控制跨所有 AI 功能的模型访问。
- **提示词所有者** — 指定一组具有细粒度权限的特定用户来提升或删除单个提示词，而无需授予更广泛的组织访问权限。
- **多模态评估器** — 直接将附件和 base64 内容（图像、音频、PDF）传递到评估器。
- **追踪项目上的成本警报** — 除了现有的 LangSmith 警报外，还可以在追踪项目级别设置警报。
- **扩展的 playground 模型支持** — 通过 Vertex AI 的 Anthropic、自定义 Azure 模型、Bedrock 推理配置文件和可配置基础 URL、Gemini 3.1 Pro、GPT-5.3 / 5.4（现在默认）和 Baseten + GLM-5。
- **新的代理工具和触发器** — Google Sheets 和 Docs、Outlook 邮件和日历、Microsoft Teams、Salesforce SOQL、带有刷新令牌的 Gmail OAuth v2，以及 Outlook 触发器。
- **Insights 增强** — 计划的 Insights 报告、随时间变化的趋势分类、分析中的完整反馈评论，以及更低的最低作业间隔（6h → 1h）。
- **标注和审查升级** — 每个队列需要审查者、尊重 `reviewer_access_mode` 的成对队列、"分配给我"过滤器、每个标注者的 CSV 导出以及批量表格操作。
- **提示词中心和工具注册表** — 提交标签搜索、模板创建中的模型选择、工作区范围的工具注册表 API 和私有注册表 UI。
- **评估器工作流程改进** — 预构建的 LLM 评估器默认使用严格的结构化输出，评估器支持标签和重用、重试不再丢失分数，以及用于以编程方式运行 playground 实验的新 API。
- **自定义 iframe 输出渲染器** — 在实验和追踪视图中拖动调整大小的 HTML 图表输出。
- **线程和收件箱 UX** — 自动生成的线程标题、重设计的线程中的运行详情、会话级反馈统计、键盘快捷键，以及过滤内部助手线程。

### 管理员更改

- **细粒度使用量报告** — 细粒度可计费使用量 API，允许你获取按工作区、项目、用户或 API 密钥细分的详细追踪使用量数据。
</Update>
