[LangSmith 部署 UI](https://smith.langchain.com) 中的 [Studio](/langsmith/studio) 支持连接两种类型的图：

- 部署在[云端或自托管](#deployed-graphs)上的图。
- 使用 [Agent Server](#local-development-server) 在本地运行的图。

## 已部署的图

Studio 可以从 [LangSmith UI](https://smith.langchain.com) 的 **Deployments** 导航中访问。

对于已[部署](/langsmith/deployment-quickstart)的应用程序，您可以作为该部署的一部分访问 Studio。为此，请在 UI 中导航到该部署并选择 **Studio**。

这将加载连接到您的实时部署的 Studio，允许您创建、读取和更新该部署中的[线程](/oss/langgraph/persistence#threads)、[助手](/langsmith/assistants)和[内存](/oss/concepts/memory)。

## 本地开发服务器

### 前置条件

要使用 Studio 在本地测试您的应用程序：

- 首先按照[本地应用程序快速入门](/langsmith/local-dev-testing)进行操作。
- 如果您不想将数据[追踪](/langsmith/observability-concepts#traces)到 LangSmith，请在应用程序的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。禁用追踪后，数据不会离开您的本地服务器。

### 设置

1. 安装 [LangGraph CLI](/langsmith/cli)：

    <CodeGroup>
    ```bash pip
    pip install -U "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash uv
    uv add "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash npm
    npx @langchain/langgraph-cli dev
    ```
    </CodeGroup>

    <Warning>
    **浏览器兼容性**
    Safari 阻止连接到 `localhost` 的 Studio。要解决此问题，请使用 `--tunnel` 运行命令，通过安全隧道访问 Studio。您需要通过点击 Studio UI 中的 **Connect to a local server** 手动将隧道 URL 添加到允许的来源。请参阅[故障排除指南](/langsmith/troubleshooting-studio#safari-connection-issues)了解步骤。
    </Warning>

    这将启动 Agent Server 在内存中运行。服务器将以观察模式运行，监听代码更改并自动重启。请阅读此[参考](/langsmith/cli#dev)了解启动 API 服务器的所有选项。

    您将看到以下日志：

    ```
    > Ready!
    >
    > - API: [http://localhost:2024](http://localhost:2024/)
    >
    > - Docs: http://localhost:2024/docs
    >
    > - LangSmith Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    ```

    运行后，您将自动被定向到 Studio。

1. 对于正在运行的服务器，使用以下方式之一访问 Dbugger：
    1. 直接导航到以下 URL：`https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`。
    1. 在 UI 中导航到 **Deployments**，点击部署上的 **Studio** 按钮，输入 `http://127.0.0.1:2024` 并点击 **Connect**。

    如果您在不同的主机或端口上运行服务器，请更新 `baseUrl` 以匹配。

### （可选）附加调试器

要进行带有断点和变量检查的分步调试，请运行以下命令：

    <CodeGroup>
    ```bash pip
    # 安装 debugpy 包
    pip install debugpy
    # 启用调试启动服务器
    langgraph dev --debug-port 5678
    ```

    ```bash uv
    # 安装 debugpy 包
    uv add debugpy
    # 启用调试启动服务器
    langgraph dev --debug-port 5678
    ```
    </CodeGroup>

然后附加您喜欢的调试器：

<Tabs>
    <Tab title="VS Code">
    将此配置添加到 `launch.json`：

    ```json
    {
        "name": "Attach to LangGraph",
        "type": "debugpy",
        "request": "attach",
        "connect": {
          "host": "0.0.0.0",
          "port": 5678
        }
    }
    ```
    </Tab>
    <Tab title="PyCharm">
    1. 转到 Run → Edit Configurations
    2. 点击 + 并选择 "Python Debug Server"
    3. 设置 IDE 主机名：`localhost`
    4. 设置端口：`5678`（或上一步中选择的端口号）
    5. 点击 "OK" 并开始调试
    </Tab>
</Tabs>

<Tip>
如需入门问题帮助，请参阅[故障排除指南](/langsmith/troubleshooting-studio)。
</Tip>
