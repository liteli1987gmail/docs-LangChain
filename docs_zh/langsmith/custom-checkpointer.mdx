在将代理部署到 LangSmith 时，服务器提供了一个内置的 Postgres 支持的检查点存储来处理图运行的持久化状态。您可以用自己的 @[BaseCheckpointSaver] 实现替换它，以使用不同的存储后端。

您提供了一个指向异步上下文管理器的路径，它产生一个 `BaseCheckpointSaver` 实例，服务器自动管理其生命周期。

<Warning>
自定义检查点存储处于**alpha**状态。此功能可能在次版本更新中遇到破坏性更改。
</Warning>

<Tip>
要使用 MongoDB 而不是 PostgreSQL 进行检查点存储，请参阅[配置检查点存储后端](/langsmith/configure-checkpointer)。本页用于实现完全自定义的存储后端。
</Tip>

## 定义检查点存储

从一个**现有** LangSmith 应用程序开始，创建一个定义产生自定义检查点存储的异步上下文管理器的文件。如果您正在开始一个新项目，可以使用 CLI 从模板创建应用程序。

```bash
langgraph new --template=new-langgraph-project-python my_new_project
```

异步上下文管理器模式让服务器在应用程序生命周期的正确时间点打开和关闭数据库连接：

```python
# ./src/agent/checkpointer.py
import contextlib

class MyCheckpointer(BaseCheckpointSaver):
    def __init__(self):
        super().__init__()
        # 在这里初始化您的自定义检查点存储
    ...

    @contextlib.asynccontextmanager
    async def aget(self, config: RunnableConfig):
        # 在这里创建连接池并初始化您的检查点存储的自定义逻辑。
        yield


@contextlib.asynccontextmanager
async def generate_checkpointer():
    """产生一个 BaseCheckpointSaver，在服务器运行期间保持打开。"""
    async with AsyncSqliteSaver.from_conn_string("./checkpoints.db") as saver:
        await saver.setup()
        yield saver
```

## 针对一致性套件进行测试

大多数开源检查点存储实现尚未实现 Agent Server 所需的所有操作。在配置检查点存储之前，请针对一致性测试套件进行验证以确保兼容性。

安装包：

```bash
pip install langgraph-checkpoint-conformance
```

注册您的检查点存储并运行验证：

```python
import asyncio

from langgraph.checkpoint.conformance import checkpointer_test, validate


@checkpointer_test(name="MyCheckpointer")
async def my_checkpointer():
    async with MyCheckpointer(...) as saver:
        yield saver


async def main():
    report = await validate(my_checkpointer)
    report.print_report()
    assert report.passed_all_base()


asyncio.run(main())
```

该套件自动检测您的检查点存储实现了哪些扩展功能，并运行适当的测试。您也可以将其作为 pytest 测试运行：

```python
import pytest

from langgraph.checkpoint.conformance import checkpointer_test, validate


@checkpointer_test(name="MyCheckpointer")
async def my_checkpointer():
    async with MyCheckpointer(...) as saver:
        yield saver


@pytest.mark.asyncio
async def test_conformance():
    report = await validate(my_checkpointer)
    report.print_report()
    assert report.passed_all_base()
```

要查看套件验证的完整基本和扩展操作列表，请参阅[功能](#capabilities)部分。

## 配置 `langgraph.json`

将 `checkpointer` 键添加到您的 [`langgraph.json` 配置文件](/langsmith/application-structure#configuration-file-concepts)中。`path` 指向上面[定义的](#define-the-checkpointer)异步上下文管理器。

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent/graph.py:graph"
  },
  "env": ".env",
  "checkpointer": {
    "path": "./src/agent/checkpointer.py:generate_checkpointer"
  }
}
```

## 启动服务器

在本地测试服务器：

```bash
langgraph dev --no-browser
```

服务器日志将确认您的自定义检查点存储处于活跃状态。

## 功能

服务器在启动时检查您的检查点存储的**基本**（必需）和**扩展**（可选）功能。如果缺少扩展功能，服务器要么使用回退，要么禁用相应功能。

### 基本功能（必需）

| 方法 | 描述 |
|---|---|
| `aput` | 存储检查点 |
| `aput_writes` | 存储待处理的写入 |
| `aget_tuple` | 检索检查点 |
| `alist` | 列出检查点 |
| `adelete_thread` | 删除线程 |

### 扩展功能（可选）

| 方法 | 描述 | 如果缺失的回退 |
|---|---|---|
| `adelete_for_runs` | 删除特定运行的检查点 | 多任务策略不可用时回退 |
| `acopy_thread` | 复制线程 | 慢速回退（逐个重新插入检查点） |
| `aprune` | 修剪线程历史 | 线程历史修剪不可用 |
