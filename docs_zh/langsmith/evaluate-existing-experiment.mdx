---

目前仅在 Python SDK 中支持对现有实验进行评估。

运行实验后，您可能想要**添加新的评估指标而无需重新运行您的应用程序**。当您添加了新的评估器或想要将不同的评分标准应用于现有结果时，这非常有用。您可以直接评估现有实验追踪，而不是在所有示例上重新执行目标函数。

要向现有实验添加评估器，请将实验名称或 ID 传递给 `evaluate()` / `aevaluate()` 而不是目标函数。评估器将在原始实验的缓存追踪上运行，访问记录的输入、输出和任何中间步骤。

## 示例


```python
from langsmith import evaluate

def always_half(inputs: dict, outputs: dict) -> float:
    return 0.5

experiment_name = "my-experiment:abc"  # Replace with an actual experiment name or ID

evaluate(experiment_name, evaluators=[always_half])
```
