本文档描述了在内存服务器（`langgraph dev`）和本地 Docker 服务器（`langgraph up`）中数据如何在 LangGraph CLI 和 Agent Server 中处理。它还描述了在与我们托管的 Studio 前端交互时追踪哪些数据。

## CLI

LangGraph **CLI** 是用于构建和运行 LangGraph 应用程序的命令行界面；请参阅 [CLI 指南](/langsmith/cli)了解更多信息。

默认情况下，对大多数 CLI 命令的调用会在调用时记录一个分析事件。这帮助我们更好地优先改进 CLI 体验。每个遥测事件包含调用进程的操作系统、操作系统版本、Python 版本、CLI 版本、命令名称（`dev`、`up`、`run` 等）以及表示是否将标志传递给命令的布尔值。有关更多信息，请参阅[完整分析逻辑](https://github.com/langchain-ai/langgraph/blob/main/libs/cli/langgraph-cli/analytics.py)。

您可以通过设置 `LANGGRAPH_CLI_NO_ANALYTICS=1` 来禁用所有 CLI 遥测。

## Agent Server

[Agent Server](/langsmith/agent-server) 提供了一个持久化执行运行时，依赖于将应用程序状态、长期记忆、线程元数据、助手和类似资源的检查点持久化到本地文件系统或数据库。除非您故意自定义了存储位置，否则此信息要么写入本地磁盘（对于 `langgraph dev`），要么写入 PostgreSQL 数据库（对于 `langgraph up` 和所有部署）。

### LangSmith 追踪

运行 Agent Server 时（无论是内存中还是 Docker 中），可以启用 LangSmith 追踪以促进更快的调试并在生产中提供图状态和大型语言模型提示的可观察性。您可以随时通过在服务器运行时环境中设置 `LANGSMITH_TRACING=false` 来禁用追踪。

<Note>
为了更细粒度的控制，您可以使用[条件追踪](/langsmith/conditional-tracing)根据运行时条件（如客户端需求或数据敏感性）选择性地启用或禁用追踪。
</Note>

<a id="langgraph-dev"></a>
### 内存中开发服务器

`langgraph dev` 作为单个 Python 进程运行[内存中开发服务器](/langsmith/local-dev-testing)，旨在快速开发和测试。它将所有检查点和内存数据保存到当前工作目录中的 `.langgraph_api` 目录中。除 [CLI](#cli) 部分描述的遥测数据外，除非您启用了追踪或您的图代码明确联系外部服务，否则不会有数据离开计算机。

<a id="langgraph-up"></a>
### 独立服务器

`langgraph up` 将您的本地包构建成 Docker 镜像，并将服务器作为[数据平面](/langsmith/self-hosted)运行，由三个容器组成：API 服务器、PostgreSQL 容器和 Redis 容器。所有持久化数据（检查点、助手等）都存储在 PostgreSQL 数据库中。Redis 用作 pubsub 连接，用于实时流式传输事件。您可以通过设置有效的 `LANGGRAPH_AES_KEY` 环境变量来加密保存到数据库之前的所有检查点。您还可以在 `langgraph.json` 中为检查点和跨线程记忆指定 [TTL](/langsmith/configure-ttl) 来控制数据存储时间。所有持久化的线程、记忆和其他数据都可以通过相关 API 端点删除。

额外的 API 调用用于确认服务器具有有效许可证，并追踪已执行的运行和任务数量。API 服务器定期验证提供的许可证密钥（或 API 密钥）。

如果您禁用了[追踪](#langsmith-tracing)，除非您的图代码明确联系外部服务，否则不会将任何用户数据持久化到外部。

## Studio

[Studio](/langsmith/studio) 是用于与 Agent Server 交互的图形界面。它不会持久化任何私人数据（您发送到服务器的数据不会发送到 LangSmith）。虽然 Studio 界面在 [smith.langchain.com](https://smith.langchain.com) 上提供服务，但它在您的浏览器中运行并直接连接到您的本地 Agent Server，因此无需将数据发送到 LangSmith。

如果您已登录，LangSmith 会收集一些使用情况分析来帮助改进调试用户体验。这包括：

* 页面访问和导航模式
* 用户操作（按钮点击）
* 浏览器类型和版本
* 屏幕分辨率和视口大小

重要的是，不会收集任何应用程序数据或代码（或其他敏感配置详细信息）。所有这些都存储在 Agent Server 的持久化层中。当匿名使用 Studio 时，不需要创建帐户，也不会收集使用情况分析。

## 快速参考

总之，您可以通过关闭 CLI 分析和禁用追踪来选择退出服务器端遥测。

| 变量 | 用途 | 默认值 |
| ------------------------------ | ------------------------- | -------------------------------- |
| `LANGGRAPH_CLI_NO_ANALYTICS=1` | 禁用 CLI 分析 | 分析已启用 |
| `LANGSMITH_API_KEY` | 启用 LangSmith 追踪 | 追踪已禁用 |
| `LANGSMITH_TRACING=false` | 禁用 LangSmith 追踪 | 取决于环境 |
