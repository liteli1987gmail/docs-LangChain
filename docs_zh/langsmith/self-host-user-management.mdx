<Note>
本指南假设你已经阅读了[管理员指南](/langsmith/administration-overview)和[组织设置指南](/langsmith/set-up-hierarchy#set-up-an-organization)。

LangSmith 使用功能标志为用户管理提供额外的自定义功能。

## 功能

### 组织的工作区级别邀请

LangSmith 中的默认行为要求用户成为组织管理员才能邀请新用户加入组织。对于希望将此责任委托给工作区管理员的自托管客户，可以设置一个功能标志，使工作区管理员也能够**在工作区级别**邀请新用户加入组织以及他们的特定工作区。

一旦通过以下配置选项启用此功能，工作区管理员可以在 **设置** > **工作区** 下的 **工作区成员** 选项卡中添加新用户。在工作区级别邀请时支持以下两种情况，而组织级别的邀请功能与以前相同。

1. 邀请**尚未**在组织中处于活动状态的用户：这会将用户作为待处理添加到组织和你特定的工作区
2. 邀请**已经**在组织中处于活动状态的用户：将用户直接作为活跃成员添加到工作区（无待处理状态）。

管理员可以同时为两种情况邀请用户。

#### 配置

<CodeGroup>

```yaml Helm
config:
  workspaceScopeOrgInvitesEnabled: true
```

```bash Docker
# 在你的 .env 文件中
WORKSPACE_SCOPE_ORG_INVITES_ENABLED="true"
```

</CodeGroup>

### SSO 新成员登录流程

从 helm **v0.11.10** 开始，使用 OAuth SSO 的自托管部署将不再需要手动在 LangSmith 设置中添加成员才能加入。部署将有一个**默认**组织，新用户将在首次登录 LangSmith 时自动添加到该组织。

对于你的**默认**组织，你可以设置分配给新成员的个工作区和工作区角色。对于**非默认**组织，邀请流程保持不变。
用户加入组织后，对其工作区或角色的任何更改（超出默认组织设置）必须通过 LangSmith 设置（如前所述）或通过 SCIM 管理。
<Note>
默认情况下，所有新用户都以**工作区编辑者**角色添加到组织的最初配置的工作区（默认为**工作区 1**）。
</Note>
![更新 SSO 成员设置](/langsmith/images/sso-member-settings-update.png)

<Note>
要更改你的默认组织，请使用组织选择下拉菜单中的**设置默认组织**。（源组织和目标组织都需要组织管理员权限。）
</Note>


### SSO 组同步

<Note>
自托管上的 SSO 组同步需要 LangSmith chart 版本 **0.15.0-rc.3**（应用程序版本 **0.15.2rc1**）或更高版本。
</Note>

[SSO 组同步](/langsmith/user-management#sso-groups-sync-alternative) 从 OIDC ID 令牌中读取组成员身份，并使用 [SCIM 命名约定](/langsmith/user-management#group-naming-convention) 分配组织和工作区角色。对于其 IdP 可以在 OIDC 令牌中包含组但无法轻松运行 SCIM 配置的自托管组织来说，它是 [SCIM](/langsmith/user-management#set-up-scim-for-your-organization) 的更简单替代方案。

有关 IdP 端配置（声明、范围），请参阅 [OIDC SSO 设置指南中的 SSO 组同步部分](/langsmith/self-host-sso#sso-groups-sync)。有关设置参考和行为，请参阅[主要 SSO 组同步文档](/langsmith/user-management#sso-groups-sync-alternative)。

### 禁用组织创建

默认情况下，任何用户都可以在 LangSmith 中创建组织。对于自托管客户，管理员可能希望在设置初始组织后限制此能力。此功能标志允许管理员禁用用户创建新组织的能力。

#### 配置

<Note>
对于使用[基本 auth](/langsmith/self-host-basic-auth) 或 [SSO](/langsmith/self-host-sso) 的组织，`userOrgCreationDisabled` 功能标志默认为 `true`。
</Note>
<CodeGroup>

```yaml Helm
config:
  userOrgCreationDisabled: true
```

```bash Docker
# 在你的 .env 文件中
FF_ORG_CREATION_DISABLED="true"
```

</CodeGroup>

### 禁用个人组织

默认情况下，任何登录 LangSmith 的用户都会为其创建一个个人组织。对于自托管客户，管理员可能希望限制此能力。此功能标志允许管理员禁用用户创建个人组织的能力。

#### 配置

<Note>
对于使用[基本 auth](/langsmith/self-host-basic-auth) 或 [SSO](/langsmith/self-host-sso) 的组织，`personalOrgsDisabled` 功能标志默认为 `true`。
</Note>

<CodeGroup>

```yaml Helm
config:
  personalOrgsDisabled: true
```

```bash Docker
# 在你的 .env 文件中
FF_PERSONAL_ORGS_DISABLED="true"
```

</CodeGroup>

### 禁用个人访问令牌创建

<Note>
此功能需要 Helm chart 版本 0.13.12（应用程序版本 0.13.12）或更高版本。
</Note>

默认情况下，用户可以在任何组织中创建个人访问令牌（PAT）。对于自托管客户，管理员可能希望在整个实例中全局禁用 PAT 创建。此环境变量允许管理员阻止用户在实例的任何组织中创建新的 PAT。

要改为禁用单个组织的 PAT 创建，请参阅[每个组织 API 选项](/langsmith/manage-organization-by-api#security-settings)。

#### 配置

<CodeGroup>

```yaml Helm
commonEnv:
  - name: PAT_CREATION_DISABLED
    value: "true"
```

```bash Docker
# 在你的 .env 文件中
PAT_CREATION_DISABLED="true"
```

</CodeGroup>
