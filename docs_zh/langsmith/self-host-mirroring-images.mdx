默认情况下，LangSmith 会从我们的公共 Docker 注册表中拉取镜像。但是，如果你在没有互联网访问的环境中运行 LangSmith，或者希望使用私有 Docker 注册表，你可以将镜像镜像到你自己的注册表，然后配置 LangSmith 安装以使用这些镜像。

## 要求

* 访问你的 Kubernetes 集群/机器可以访问的 Docker 注册表的认证访问权限。
* 在本地机器或可以访问 Docker 注册表的机器上安装 Docker。
* 一个可以运行 LangSmith 的 Kubernetes 集群。

## 镜像镜像

为了方便起见，我们提供了一个为你镜像镜像的脚本。你可以在 [LangSmith Helm Chart 仓库](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/mirror_langsmith_images.sh) 中找到该脚本。

要使用该脚本，你需要使用以下命令运行该脚本，指定你的注册表和平台：

```bash
bash mirror_images.sh <your-registry> [<platform>]
```

其中 `<your-registry>` 是你的 Docker 注册表的 URL（例如 `myregistry.com`），`<platform>` 是你使用的平台（例如 `linux/amd64`、`linux/arm64` 等）。如果你不指定平台，它将默认为 `linux/amd64`。

例如，如果你的注册表是 `myregistry.com`，你的平台是 `linux/arm64`，并且你想使用最新版本的镜像，你需要运行：

```bash
bash mirror_langsmith_images.sh --registry myregistry --platform linux/arm64 --version 0.10.66
```

请注意，此脚本将假定你已安装 Docker 并已向注册表进行身份验证。它还将把镜像推送到指定注册表，仓库/标签与原始镜像相同。

或者，你可以手动拉取、镜像和推送镜像。你需要在 LangSmith Helm Chart 的 `values.yaml` 文件中找到需要镜像的镜像。这些可以在此处找到：[LangSmith Helm Chart values.yaml](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/values.yaml#L14)

以下是如何使用 Docker 镜像镜像的示例：

```bash
# 从公共注册表拉取镜像
docker pull langchain/langsmith-backend:latest
docker tag langchain/langsmith-backend:latest <your-registry>/langsmith-backend:latest
docker push <your-registry>/langsmith-backend:latest
```

你需要为每个要镜像的镜像重复此操作。

## 配置

镜像镜像后，你需要配置 LangSmith 安装以使用镜像的镜像。你可以通过修改 LangSmith Helm Chart 安装的 `values.yaml` 文件来执行此操作。将标签替换为你要使用的版本，例如，在撰写本文时的最新版本 `0.10.66`。

```yaml
images:
  imagePullSecrets: [] # 如果需要，在此添加你的镜像拉取密钥
  registry: "" # 如果使用我们的脚本将所有镜像镜像到同一注册表，请将其设置为你的注册表 URL。然后你可以从下面的镜像中移除仓库前缀。
  aceBackendImage:
    repository: "(your-registry)/langchain/langsmith-ace-backend"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  backendImage:
    repository: "(your-registry)/langchain/langsmith-backend"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  frontendImage:
    repository: "(your-registry)/langchain/langsmith-frontend"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  hostBackendImage:
    repository: "(your-registry)/langchain/hosted-langserve-backend"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  operatorImage:
    repository: "(your-registry)/langchain/langgraph-operator"
    pullPolicy: IfNotPresent
    tag: "6cc83a8"
  platformBackendImage:
    repository: "(your-registry)/langchain/langsmith-go-backend"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  playgroundImage:
    repository: "(your-registry)/langchain/langsmith-playground"
    pullPolicy: IfNotPresent
    tag: "0.10.66"
  postgresImage:
    repository: "(your-registry)/postgres"
    pullPolicy: IfNotPresent
    tag: "14.7"
  redisImage:
    repository: "(your-registry)/redis"
    pullPolicy: IfNotPresent
    tag: "7"
  clickhouseImage:
    repository: "(your-registry)/clickhouse/clickhouse-server"
    pullPolicy: Always
    tag: "24.8"
```

## Fleet 和 Insights 的其他镜像

如果你使用 Fleet 或 Insights，LangGraph 操作员会为每个部署动态创建 Redis 和 PostgreSQL (pgvector) pod。这些 pod 使用在操作员模板中定义的镜像，需要单独配置。

你必须镜像这些额外的镜像：
- `docker.io/redis:7`
- `docker.io/pgvector/pgvector:pg15`

然后在你的 `values.yaml` 中覆盖操作员模板以使用你的镜像：

```yaml
operator:
  templates:
    redis: |
      apiVersion: apps/v1
      kind: Deployment
      metadata:
        name: ${service_name}
        namespace: ${namespace}
      spec:
        replicas: 1
        selector:
          matchLabels:
            app: ${service_name}
        template:
          metadata:
            labels:
              app: ${service_name}
          spec:
            enableServiceLinks: false
            containers:
            - name: redis
              image: (your-registry)/redis:7
              ports:
              - containerPort: 6379
                name: redis
              livenessProbe:
                exec:
                  command:
                  - redis-cli
                  - ping
                initialDelaySeconds: 30
                periodSeconds: 10
              readinessProbe:
                tcpSocket:
                  port: 6379
                initialDelaySeconds: 10
                periodSeconds: 5
    db: |
      apiVersion: apps/v1
      kind: StatefulSet
      metadata:
        name: ${service_name}
      spec:
        serviceName: ${service_name}
        selector:
          matchLabels:
            app: ${service_name}
        persistentVolumeClaimRetentionPolicy:
          whenDeleted: Delete
          whenScaled: Retain
        template:
          metadata:
            labels:
              app: ${service_name}
          spec:
            containers:
            - name: postgres
              image: (your-registry)/pgvector/pgvector:pg15
              ports:
              - containerPort: 5432
              command: ["docker-entrypoint.sh"]
              args:
                - postgres
                - -c
                - max_connections=${max_connections}
              env:
              - name: PGDATA
                value: /var/lib/postgresql/data/pgdata
              volumeMounts:
              - name: postgres-data
                mountPath: /var/lib/postgresql/data
            enableServiceLinks: false
        volumeClaimTemplates:
        - metadata:
            name: postgres-data
          spec:
            accessModes: ["ReadWriteOnce"]
            resources:
              requests:
                storage: "${storage_gi}Gi"
```

将 `(your-registry)` 替换为你的注册表 URL。模板变量（`${service_name}`、`${namespace}`、`${max_connections}`、`${storage_gi}`）在运行时由操作员替换，必须保持原样。

配置后，你需要更新 LangSmith 安装。你可以按照我们的升级指南操作：[升级 LangSmith](/langsmith/self-host-upgrades)。如果升级成功，你的 LangSmith 实例现在应该使用来自 Docker 注册表的镜像。
