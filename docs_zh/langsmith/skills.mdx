代理技能是捆绑指令和可选辅助脚本的可重用按需功能。本页面总结了您可以添加到兼容编码代理的 LangSmith 定向技能，以查询追踪、生成数据集和定义评估器。要直接从终端使用相同的 LangSmith 数据，请使用 [LangSmith CLI](/langsmith/langsmith-cli)。

<Note>
这些技能遵循代理技能规范，并在 [`langsmith-skills` GitHub 仓库](https://github.com/langchain-ai/langsmith-skills)中维护。您可以将 `SKILL.md` 和任何引用的 `scripts/` 复制到您代理的技能目录中。下面的安装程序只安装 LangSmith 技能（追踪、数据集、评估器）。
</Note>

## 快速安装

使用 `npx skills` 仅安装 LangSmith 技能（追踪、数据集、评估器）：

<CodeGroup>
```bash 本地（当前项目）
npx skills add langchain-ai/langsmith-skills --skill '*' --yes
```

```bash 全局（所有项目）
npx skills add langchain-ai/langsmith-skills --skill '*' --yes --global
```

```bash 链接到特定代理（例如 Claude Code）
npx skills add langchain-ai/langsmith-skills --agent claude-code --skill '*' --yes --global
```
</CodeGroup>

<Tip>
要更新，请重新运行命令。如果目标技能文件夹已存在，请先删除它们（例如 `rm -rf ~/.claude/skills/langsmith-*`）。
</Tip>

## 配置环境

安装技能后，设置所有 LangSmith 技能、辅助脚本和 [LangSmith CLI](/langsmith/langsmith-cli) 使用的环境变量：

```bash
export LANGSMITH_API_KEY=<your-key>
# 可选的默认值
export LANGSMITH_PROJECT=<default-project>
# 高级：仅适用于多工作区或某些自托管设置
# export LANGSMITH_WORKSPACE_ID=<workspace-id>
```

## 这些技能涵盖的内容

- [追踪](/langsmith/observability-concepts#traces)：向应用程序添加追踪；列出、过滤、检查和导出追踪以进行调试和分析。
- [数据集](/langsmith/evaluation-concepts#datasets)：将追踪转换为评估数据集（final_response、single_step、trajectory、RAG），并可选择上传到 LangSmith。
- [评估器](/langsmith/evaluation-concepts#evaluators)：定义代码或 LLM 即评估器，并将其附加到数据集（离线）或项目（在线）。

每个技能目录都附带一个 `SKILL.md` 以及可选的 `scripts/` 辅助脚本，您可以运行或调整这些脚本。这些技能设计为插入兼容的编码代理（例如 Claude Code 或 DeepAgents CLI），如果您更喜欢不连接完整代理，也可以直接重用辅助脚本。对于较重的查询、导出或自动化，您可以将这些技能与 [LangSmith CLI](/langsmith/langsmith-cli) 配对，以从您的终端对相同的项目、数据集和评估器进行脚本编写。

## 手动安装

克隆仓库并运行安装脚本以获取更多选项：

```bash
git clone https://github.com/langchain-ai/langsmith-skills.git
cd langsmith-skills

# 为当前目录中的 Claude Code 安装（默认）
./install.sh

# 全局为 Claude Code 安装
./install.sh --global

# 为当前目录中的 DeepAgents CLI 安装
./install.sh --deepagents

# 全局为 DeepAgents CLI 安装（包含代理角色）
./install.sh --deepagents --global

# 仅安装 LangSmith 技能（任何目标）
./install.sh --langsmith
```

如果您更喜欢只复制特定技能，请将所需的目录从 `config/skills/` 复制到您代理的技能文件夹中。

包含的 LangSmith 技能：
- langsmith-trace — 追踪（查询/导出）
- langsmith-dataset — 数据集（生成/上传）
- langsmith-evaluator — 评估器（创建/附加）
