LangSmith Deployment 是一个专为代理工作负载构建的工作流编排运行时。它提供代理在生产规模中可靠运行所需的托管基础设施，支持从本地开发到部署的完整生命周期。LangSmith Deployment 与框架无关：您可以部署使用 LangGraph 或[其他框架](/langsmith/deploy-other-frameworks)构建的代理。

<Note>
LangSmith Deployment 需要 [Plus 计划或更高版本](https://www.langchain.com/pricing)。[获取演示](https://www.langchain.com/contact-sales)了解更多关于 BYOC 部署和高级支持选项的信息。
</Note>

## 能力





### Studio

[Studio](/langsmith/studio) 连接到任何 Agent Server（本地或已部署），并为您提供用于开发和调试代理的交互环境。可视化执行图、在任何检查点检查状态、单步运行运行、在执行过程中修改状态，以及分支以探索替代路径。

### 代理组合

代理不会孤立地运行。[RemoteGraph](/langsmith/use-remote-graph) 让任何代理使用与本地相同的接口调用其他已部署的代理：研究代理委托给不同部署上的搜索代理，路由代理将任务分发给专门的子代理。代理不需要知道它们是在调用本地还是远程的东西。

对 [MCP](/langsmith/server-mcp) 和 [A2A](/langsmith/server-a2a) 的原生支持意味着您已部署的代理可以与更广泛的生态系统一起暴露和使用工具接口以及代理到代理协议。

### 部署选项

- **[云](/langsmith/deploy-to-cloud)**：全托管。从 git 仓库推送或使用 [`langgraph deploy`](/langsmith/cli#deploy)。
- **[混合](/langsmith/deploy-with-control-plane)**：在您的云中运行，由 LangSmith[控制平面](/langsmith/control-plane)管理。
- **[自托管](/langsmith/self-hosted)**：在您自己的基础设施中完全自管理。

相同的运行时，相同的 API。改变的是谁管理基础设施。请参阅[平台设置](/langsmith/platform-setup)进行比较。
