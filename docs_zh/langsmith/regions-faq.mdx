## 法律和合规

#### *LangSmith（包括其 EU 实例）遵守哪些隐私和数据保护框架？*

LangSmith 遵守适用于 LangSmith 服务的一般数据保护条例（GDPR）和其他法律法规。我们还获得了 SOC 2 Type 2 认证并符合 HIPAA 标准。您可以在 [trust.langchain.com](https://trust.langchain.com) 请求了解更多关于我们安全策略和状态的信息。如果您想与我们签署数据处理附录（DPA），请通过 [support.langchain.com](https://support.langchain.com) 联系支持。请注意，我们仅与企业计划上的客户签订业务关联协议（BAA）。

#### *我的公司不在欧盟，我仍然可以在那里托管我的数据吗？*

是的，您可以独立于您的位置在 EU 实例中托管您的 LangSmith 数据。

#### *你们在欧盟有我们可以签约的法律实体吗？*

目前我们没有用于客户签约的欧盟法律实体。

#### *如果我选择欧盟区域，是否适用不同的法律条款？*

欧盟和美国地区的条款相同。

## 功能

#### *如何使用 EU 实例？*

请遵循[账户和 API 密钥设置指南](/langsmith/create-account-api-key)创建一个账户和一个 API 密钥（请确保在下拉菜单中将区域更改为 EU）

#### *美国和欧盟云托管 LangSmith 之间是否有任何功能差异？*

根据功能的不同，每个区域的发布可能会有小幅延迟。除此之外，它们的功能是等效的——在美国支持的所有功能在欧盟也支持，反之亦然。

#### *一个组织可以在不同区域拥有工作区吗？*

LangSmith 目前不支持此功能，但如果您有兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持并分享您的用例。

#### *我可以连接欧盟组织与美国组织并共享账单吗？*

LangSmith 目前不支持此功能，但如果您有兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持并分享您的用例。

#### *什么数据会存储在我选择的区域中？*

请参阅[云架构参考](/langsmith/cloud#cloud-architecture-and-scalability)了解详情。

#### *如何查看我的组织的区域？*

检查您的 URL - [https://eu.smith.langchain.com](https://eu.smith.langchain.com) 上的任何组织都在 GCP 上的 EU。[https://smith.langchain.com](https://smith.langchain.com) 上的组织在 GCP 上的美国，[https://aws.smith.langchain.com](https://aws.smith.langchain.com) 上的组织在 AWS 上的美国。

#### *我可以把我的组织从美国迁移到欧盟，反之亦然吗？*

我们目前不支持区域之间的迁移，但如果您有兴趣此功能，请通过 [support.langchain.com](https://support.langchain.com) 联系支持。

## 计划与定价

#### *EU 区域在所有 LangSmith 计划上都可用吗？*

是的，您可以在所有计划（包括免费计划）上注册 EU 区域。

#### *EU 区域的定价与美国区域不同吗？*

不，EU 和美国区域的定价相同。

#### *如果我使用 EU 区域，用于支付的货币是什么？*

所有 LangSmith 计划均以美元支付。
