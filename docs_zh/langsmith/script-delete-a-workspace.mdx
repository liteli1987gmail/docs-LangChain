<Note>
在 **LangSmith Self-Hosted v0.10 中原生支持**删除工作区。查看[删除工作区说明](/langsmith/set-up-hierarchy#delete-a-workspace)。

请按照以下指南操作 v0.10 之前的 Self-Hosted 版本。
</Note>

LangSmith UI 目前不支持从组织中删除单个工作区。但是，这可以通过直接从 ClickHouse 中的所有物化视图（runs_history 视图除外）以及 runs 和 feedbacks 表中删除所有追踪，然后将工作区从 PostgreSQL tenants 表中移除来实现。

此命令使用 Workspace ID 作为参数。

### 前置条件

确保你已准备好以下工具/项目。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. PostgreSQL 客户端

   * [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

3. PostgreSQL 数据库连接：

   * Host
   * Port
   * Username
     * 如果使用捆绑版本，则是 `postgres`
   * Password
     * 如果使用捆绑版本，则是 `postgres`
   * Database name
     * 如果使用捆绑版本，则是 `postgres`

4. Clickhouse 数据库凭据

   * Host
   * Port
   * Username
     * 如果使用捆绑版本，则是 `default`
   * Password
     * 如果使用捆绑版本，则是 `password`
   * Database name
     * 如果使用捆绑版本，则是 `default`

5. 从你将运行迁移脚本的计算机到 PostgreSQL 数据库的连接。

   * 如果你使用的是捆绑版本，你可能需要将 postgresql 服务端口转发到本地计算机。
   * 运行 `kubectl port-forward svc/langsmith-postgres 5432:5432` 将 postgresql 服务端口转发到本地计算机。

6. 从你将运行迁移脚本的计算机到 Clickhouse 数据库的连接。

   * 如果你使用的是捆绑版本，你可能需要将 clickhouse 服务端口转发到本地计算机。
     * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123` 将 clickhouse 服务端口转发到本地计算机。
   * 如果你使用的是 Clickhouse Cloud，你需要指定 --ssl 标志并使用端口 `8443`

7. 用于删除工作区的脚本

   * 下载[工作区脚本](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/delete_workspace.sh)

### 运行单个工作区的删除脚本

运行以下命令来执行工作区移除脚本：

```bash
sh delete_workspace.sh <postgres_url> <clickhouse_url> --workspace_id <workspace_id>
```

例如，如果你使用带有端口转发的捆绑版本，命令将如下所示：

```bash
sh delete_workspace.sh "postgres://postgres:postgres@localhost:5432/postgres" "clickhouse://default:password@localhost:8123/default" --workspace_id 4ec70ec7-0808-416a-b836-7100aeec934b
```

如果你访问 LangSmith UI，你现在应该看到工作区已被删除。
