本页面描述设置和管理您的 LangSmith [_组织_](/langsmith/administration-overview#organizations)和[_工作区_](/langsmith/administration-overview#workspaces)：

- [设置组织](#set-up-an-organization)：创建和管理组织以进行团队协作，包括用户管理和角色分配。
- [设置工作区](#set-up-a-workspace)：设置和配置工作区以组织您的 LangSmith 资源、管理工作区成员以及配置团队协作设置。
- [设置应用程序](#set-up-applications)：在工作区内设置应用程序以进一步组织 LangSmith 资源，并利用 ABAC 权限。

<Check>
在阅读此设置页面之前，您可能会发现参考 [LangSmith 资源层级概述](/langsmith/administration-overview)很有帮助。

## 设置组织

<Note>
如果您有兴趣以编程方式管理您的组织和工作区，请参阅[使用 API 管理组织](/langsmith/manage-organization-by-api)。
</Note>

### 创建组织

当您首次登录 [UI](https://smith.langchain.com) 时，LangSmith 会自动为您创建一个个人组织。如果您想与他人协作，可以创建一个单独的组织并邀请您的团队成员加入。

1. 点击左下角的个人资料图标打开**组织**抽屉
1. 选择菜单顶部的组织个人资料下拉菜单。
1. 点击**+ 创建组织**。

共享组织在可以使用之前需要信用卡。您需要[设置账单](/langsmith/billing#set-up-billing-for-your-account)才能继续。

### 管理工作区和导航工作区

一旦您订阅了允许组织中多个用户的[计划](/langsmith/pricing-plans)，您就可以设置[工作区](/langsmith/administration-overview#workspaces)以更有效地协作并在不同用户组之间隔离 LangSmith 资源。要在工作区之间导航并访问每个工作区内的资源（追踪项目、标注队列等），请从 [LangSmith UI](https://smith.langchain.com) 左下角的选取器中选择所需的工作区。

### 管理人员

在[设置页面](https://smith.langchain.com/settings)的**成员和角色**选项卡中管理共享组织的成员资格。在这里您可以：

- 邀请新用户加入您的组织，选择工作区成员资格和（如果[RBAC](/langsmith/rbac)启用）工作区角色。
- 编辑用户的组织角色。
- 从您的组织中移除用户。

[Enterprise 计划](/langsmith/pricing-plans)上的组织可以在**角色**选项卡中设置自定义工作区角色。有关更多详细信息，请参阅[访问控制设置指南](/langsmith/user-management)。

#### 组织角色

组织作用域角色用于确定对组织设置的访问权限。选择的角色也会影响工作区成员资格：

- **组织管理员**授予管理所有组织配置、用户、账单和工作区的完全访问权限。任何组织管理员对组织中的所有工作区具有 `Admin` 访问权限。
- **组织用户**可以读取组织信息，但无法在组织级别执行任何写操作。您可以将组织用户添加到部分工作区并按常规分配工作区角色（如果[RBAC](/langsmith/rbac)启用），这些角色指定工作区级别的权限。

<Info>
[组织用户](/langsmith/rbac#organization-user)和[组织查看者](/langsmith/rbac#organization-viewer)角色仅在 [Plus 和 Enterprise 计划](https://langchain.com/pricing)的组织中可用。在开发者组织（单个工作区）中，所有用户默认分配[组织管理员](/langsmith/rbac#organization-admin)角色。自定义组织作用域角色不可用。
</Info>

有关与每个角色关联的权限的完整列表，请参阅[管理概述](/langsmith/administration-overview#organization-roles)页面。

## 设置工作区

当您首次登录时，LangSmith 会在您的个人组织中为您创建一个默认的[工作区](/langsmith/administration-overview#workspaces)。您可以使用工作区在不同团队或业务单元之间分离资源，以在它们之间建立清晰的信任边界。在每个工作区内，[基于角色的访问控制 (RBAC)](/langsmith/rbac) 管理权限和访问级别，这确保用户只能访问其角色所需的资源和设置。大多数 LangSmith 活动发生在工作区的上下文中，每个工作区都有自己的设置和访问控制。

有关为您的团队选择正确的工作区组织模型的指导（每团队一个工作区、每工作区多个团队或每团队多个工作区），请参阅[工作负载隔离](/langsmith/workload-isolation)。

### 创建工作区

要创建新工作区，请在共享组织的[**设置**页面](https://smith.langchain.com/settings)的**工作区**选项卡中点击**添加工作区**。

创建工作区后，您可以通过在**设置**页面上选择该工作区来管理其成员和其他配置。

<Note>
不同的计划对组织中可以创建的工作区数量有不同的限制。有关更多信息，请参阅[定价页面](https://www.langchain.com/pricing-langsmith)。
</Note>

### 管理人员

<Info>
只有[工作区管理员](/langsmith/rbac#workspace-admin)可以管理工作区成员资格，并且如果 RBAC 启用，可以更改用户的工作区角色。
</Info>

对于已是组织成员的用户，工作区管理员可以在[**工作区设置**页面](https://smith.langchain.com/settings/workspaces)的**工作区成员**选项卡中将其添加到工作区。当用户被邀请加入组织时，也可以直接邀请到一个或多个工作区。

### 配置工作区设置

工作区配置存在于[**工作区设置**页面](https://smith.langchain.com/settings/workspaces)选项卡中。选择要配置的工作区，然后选择所需的配置子选项卡。
配置选项包括：

- **工作区成员**
- **API 密钥**
- **密钥**
- **反馈配置**
- **模型**
- **规则**
- **共享 URL**

### 删除工作区

<Warning>
删除工作区将永久删除该工作区及其所有相关数据。此操作无法撤消。
</Warning>

您可以通过 [LangSmith UI](https://smith.langchain.com) 或[API](https://api.smith.langchain.com/redoc?#tag/workspaces/operation/delete_workspace_api_v1_workspaces__workspace_id__delete)删除工作区。您必须是工作区管理员才能删除工作区。

在 LangSmith UI 中：

1. 导航到**设置**。
1. 选择要删除的工作区。
1. 点击屏幕右上角的删除图标 <Icon icon="trash" iconType="solid"/>。

## 设置应用程序

您可以在工作区内创建应用程序以进一步组织资源，例如追踪项目和数据集。一个工作区可以拥有零个或多个应用程序。

您可以通过从 LangSmith UI 主页选择**所有应用程序**来查看工作区内的所有资源。您可以通过在**设置**页面的**资源标签**下将资源添加到**应用程序**标签来将资源标记到多个应用程序。
