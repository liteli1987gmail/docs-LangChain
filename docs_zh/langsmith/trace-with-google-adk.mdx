## 配置追踪

要追踪 ADK 智能体，请使用 LangSmith SDK 中的 `configure_google_adk()`。在创建任何 ADK 智能体之前，在应用程序开始时调用此函数一次：

```python
from langsmith.integrations.google_adk import configure_google_adk

configure_google_adk(
    project_name="my-adk-project",  # Optional: defaults to LANGSMITH_PROJECT env var
)
```

该函数接受以下可选参数：

- `project_name`：要发送追踪的 LangSmith 项目。默认为 `LANGSMITH_PROJECT` 环境变量。
- `name`：根追踪的名称。默认为 `"google_adk.session"`。
- `metadata`：键值对字典，用于附加上下文。
- `tags`：用于对追踪进行分类的字符串列表。

## 在 LangSmith 中查看追踪

运行应用程序后，您可以在 [LangSmith UI](https://smith.langchain.com) 中查看包含以下内容的追踪：

- **智能体调用**：通过您的 ADK 智能体的完整流程
- **工具调用**：智能体进行的单独函数调用
- **大型语言模型交互**：来自 Gemini 模型的请求和响应
- **多智能体工作流**：来自顺序和并行智能体组合的追踪

## 自定义元数据和标签

在配置追踪时添加元数据和标签，以对追踪进行分类和筛选：

```python
from langsmith.integrations.google_adk import configure_google_adk

configure_google_adk(
    project_name="production-agents",
    metadata={
        "environment": "production",
        "team": "ml-platform",
    },
    tags=["adk", "weather", "v2"],
)
```
