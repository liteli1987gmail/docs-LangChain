LangSmith 将数据集中的示例存储如下：

| 字段名称          | 类型     | 描述                                                                                                       |
| ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| **id**              | UUID     | 示例的唯一标识符。                                                                                |
| **name**            | string   | 示例的名称。                                                                                          |
| **created\_at**     | datetime | 创建此示例的时间                                                                                 |
| **modified\_at**    | datetime | 最后修改此示例的时间                                                                           |
| **inputs**          | object   | 示例输入的映射。                                                                                  |
| **outputs**         | object   | 运行生成的输出映射或集合。                                                                     |
| **dataset\_id**     | UUID     | 示例所属的数据集                                                                                |
| **source\_run\_id** | UUID     | 如果此示例是从 LangSmith [`Run`](/langsmith/run-data-format) 创建的，则为所述运行的 ID |
| **metadata**        | object   | 可存储在示例上的额外用户或 SDK 定义信息的映射。                            |

要了解有关评估中示例的更多信息，请阅读我们关于[评估 LLM 应用程序](/langsmith/evaluate-llm-application)的操作指南。
