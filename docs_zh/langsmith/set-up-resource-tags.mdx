<Info>
资源标签适用于 [Plus 和 Enterprise 计划](/langsmith/pricing-plans)。
</Info>

虽然[工作区](/langsmith/administration-overview#workspaces)帮助分离信任边界和访问控制，但标签帮助您在工作区内组织资源。标签是您可以附加到资源的键值对。

<Note>
**不要与提交标签混淆**：资源标签是用于组织和过滤工作区资源（项目、数据集、提示词等）的键值对。[提交标签](/langsmith/manage-prompts#commit-tags)是引用提示词提交历史中特定版本的标签。虽然两种类型的标签可以使用相似的术语（如 `prod` 或 `staging`），但资源标签帮助您*组织工作区中的资源*，而提交标签控制代码中使用的提示词的*哪个版本*。
</Note>

<Check>
在深入了解此内容之前，强烈建议您阅读[组织和工作区概念指南](/langsmith/administration-overview)。
</Check>

## 创建标签

<Note>
要创建资源标签，您必须拥有 [`workspaces:manage` 权限](/langsmith/organization-workspace-operations)（默认授予[工作区管理员](/langsmith/rbac#workspace-admin)角色）。编辑者可以为其有更新访问权限的资源应用**应用程序**标签，但创建标签键或应用其他标签类型需要此权限。有关将标签应用到资源的更多信息，请参阅工作区操作[标签部分](/langsmith/organization-workspace-operations#tags)。
</Note>

要创建标签：

1. 导航到工作区**设置**页面，点击左侧边栏中的**资源标签**。
1. 在这里，您可以找到按键分组的现有标签值。LangSmith 默认创建**应用程序**和**环境**键。您可以使用**应用程序**键来过滤 UI 中显示的资源。
1. 在页面顶部选择 <Icon icon="tag" /> **新标签**。系统会提示您输入标签的键和值。请注意，您可以使用现有键或创建新键。

## 为资源分配标签

在与创建新标签相同的侧面板中，您也可以为标签分配资源。在**分配资源**部分搜索相应的资源，选择您想要标记的资源。

<Note>
您只能使用资源标签标记工作区作用域的资源。这包括追踪项目、标注队列、部署、实验、数据集和提示词。
</Note>

要从资源取消分配标签，请点击标签面板和资源标签面板中标签旁边的 <Icon icon="trash" /> 垃圾桶图标。

## 删除标签

您可以从[**设置**页面 > **资源标签**页面](https://smith.langchain.com/settings/workspaces/resource_tags)删除标签的键或值。要删除键，请点击键旁边的 <Icon icon="trash" /> 垃圾桶图标。要删除值，请点击值旁边的 <Icon icon="trash" /> 垃圾桶图标。

如果您删除一个键，LangSmith 将删除与该键关联的所有值。当您删除一个值时，您将失去该值与资源之间的所有关联。
