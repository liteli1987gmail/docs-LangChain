LangSmith Deployment 支持部署一个 [LangGraph](/oss/python/langgraph/overview) _图_。然而，图的 _节点_ 的实现可以包含任意代码。这意味着任何框架都可以在节点内实现并部署在 LangSmith Deployment 上。这让你可以在不使用额外 LangGraph OSS API 的情况下实现核心应用逻辑，同时仍使用 LangSmith 进行[部署](/langsmith/deployment)、扩展和[可观测性](/langsmith/observability)。更多详细信息，请参阅[将任何框架与 LangSmith Deployment 结合使用](/langsmith/application-structure#use-any-framework-with-langsmith-deployment)。
