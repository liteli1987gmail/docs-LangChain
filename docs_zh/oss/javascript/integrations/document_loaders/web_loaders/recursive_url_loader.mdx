在从网站加载内容时，我们可能需要处理加载页面上的所有 URL。

例如，让我们查看 LangChain.js 介绍文档。

这有许多我们可能想要批量加载、分割和稍后检索的有趣子页面。

挑战在于遍历子页面树并组装列表！

我们使用 `RecursiveUrlLoader` 来完成此操作。

这还为我们提供了排除某些子页面、自定义提取器等的灵活性。

## 设置

要访问 `RecursiveUrlLoader` 文档加载器，您需要安装 `@langchain/community` 集成以及 [`jsdom`](https://www.npmjs.com/package/jsdom) 包。

## 实例化

现在我们可以实例化我们的模型对象并加载文档：

```typescript
import { RecursiveUrlLoader } from "@langchain/community/document_loaders/web/recursive_url"
import { compile } from "html-to-text";

const compiledConvert = compile({ wordwrap: 130 }); // 返回 (text: string) => string;

const loader = new RecursiveUrlLoader("https://langchain.com/",  {
  extractor: compiledConvert,
  maxDepth: 1,
  excludeDirs: ["/docs/api/"],
})
```

## 选项

```typescript
interface Options {
  excludeDirs?: string[]; // 要排除的网页目录。
  extractor?: (text: string) => string; // 从网页提取文档文本的函数，默认返回页面本身。建议使用 html-to-text 等工具来提取文本。默认情况下，它只返回页面本身。
  maxDepth?: number; // 爬行的最大深度。默认设置为 2。如果您需要爬行整个网站，请将其设置为一个足够大的数字即可完成工作。
  timeout?: number; // 每个请求的超时时间，单位为秒。默认设置为 10000（10 秒）。
  preventOutside?: boolean; // 是否防止在根 URL 外部爬行。默认设置为 true。
  callerOptions?: AsyncCallerConstructorParams; // 调用 AsyncCaller 的选项，例如设置最大并发数（默认为 64）
}
```

但是，由于很难执行完美的过滤，您可能仍会在结果中看到一些不相关的结果。如果需要，您可以自己对返回的文档执行过滤。大多数时候，返回的结果已经足够好了。
