---
title: "Notion Markdown 导出集成"
description: "使用 LangChain JavaScript 与 Notion Markdown 导出文档加载器集成。"
---

本示例介绍如何从 Notion 仪表板导出的 Notion 页面加载数据。

首先，按照 [官方 Notion 导出说明](https://www.notion.so/help/export-your-content) 将您的 Notion 页面导出为 **Markdown 和 CSV**。请确保选择 `包含子页面` 和 `为子页面创建文件夹`。

然后，解压下载的文件并将解压后的文件夹移到您的仓库中。它应该包含您页面的 markdown 文件。

一旦文件夹在您的仓库中，只需运行下面的示例：

```typescript
import { NotionLoader } from "@langchain/community/document_loaders/fs/notion";

export const run = async () => {
  /** 提供您的 Notion 文件夹的目录路径 */
  const directoryPath = "Notion_DB";
  const loader = new NotionLoader(directoryPath);
  const docs = await loader.load();
  console.log({ docs });
};
```
