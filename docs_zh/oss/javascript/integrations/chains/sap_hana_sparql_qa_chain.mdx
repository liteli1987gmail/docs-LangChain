## 设置和安装

要使用此功能，请安装 `@sap/hana-langchain` 包及其对等依赖项：

```bash
npm install @sap/hana-langchain @langchain/core@latest @langchain/classic@latest langchain@latest
```

创建到 SAP HANA Cloud 实例的连接。

```typescript
import * as dotenv from 'dotenv';
// Load environment variables if needed
// 如有需要，加载环境变量
dotenv.config();

import hanaClient from "@sap/hana-client";

const connectionParams = {
  host: process.env.HANA_DB_ADDRESS,
  port: process.env.HANA_DB_PORT,
  user: process.env.HANA_DB_USER,
  password: process.env.HANA_DB_PASSWORD,
};
const client = hanaClient.createConnection(connectionParams);

// connect to hanaDB
// 连接到 hanaDB
await new Promise<void>((resolve, reject) => {
  client.connect((err: Error) => {
    // Use arrow function here
    // 在这里使用箭头函数
    if (err) {
      reject(err);
    } else {
      console.log("Connected to SAP HANA successfully.");
      resolve();
    }
  });
});
```

`HanaSparqlQAChain` 将以下内容整合在一起：

1. **模式感知的 SPARQL 生成**
2. **针对 SAP HANA 的查询执行**
3. **自然语言答案格式化**

## 初始化

* 一个**大型语言模型**用于生成和解释查询
* 一个 **`HanaRdfGraph`**（包含连接、`graph_uri` 和本体）

请按照以下步骤了解如何创建 `HanaRdfGraph` 实例：[HanaRdfGraph](/oss/integrations/graphs/sap_hana_rdf_graph)

导入 `HanaSparqlQAChain`

```typescript
import { HanaSparqlQAChain } from "@sap/hana-langchain";
const qaChain = HanaSparqlQAChain.fromLLM({ llm, graph, allowDangerousRequests: true, verbose: true });
```

## 流水线概述

1. SPARQL 生成
   - 使用 SPARQL 生成提示词
   - 输入：`schema`（来自 `graph.getSchema()` 的 Turtle）、`prompt`（用户问题）
2. 查询后处理
   - 从模型输出中提取 SPARQL
   - 如果缺少则注入 `FROM <graph_uri>`
   - 确保常用前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）
3. 执行
   - `graph.query(generatedSparql)`
4. 答案 formulation
   - 使用包含输入的 QA 提示词：`context`（结果）、`prompt`（原始问题）

## 提示词模板

### "SPARQL 生成"提示词

`sparqlGenerationPrompt` 用于指导大型语言模型根据用户问题和提供的模式生成 SPARQL 查询。

### 回答提示词

`qaPrompt` 指示大型语言模型仅基于数据库结果创建自然语言答案。
默认提示词可以在这里找到：[`prompts.ts`](https://github.com/SAP/langchainjs-integration-for-sap-hana-cloud/blob/main/src/chains/graph_qa/prompts.ts)

## 自定义提示词

您可以在初始化时覆盖默认值：

```typescript
const qaChain = HanaSparqlQAChain.fromLLM({
  llm,
  graph,
  allowDangerousRequests: true,
  verbose: true,
  sparqlGenerationPrompt: YOUR_SPARQL_PROMPT,
  qaPrompt: YOUR_QA_PROMPT,
});
```

> - `sparql_generation_prompt` 必须包含输入变量：`["schema", "prompt"]`
> - `qa_prompt` 必须包含输入变量：`["context", "prompt"]`

## 示例：基于"电影"知识图的问答

**前提条件**：
您必须拥有一个启用了**三元组存储**功能的 SAP HANA Cloud 实例。
有关详细说明，请参阅：[启用三元组存储](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/enable-triple-store/)<br />
加载 `kgdocu_movies` 示例数据。请参阅[知识图示例](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/knowledge-graph-example)。

下面我们将：

1. 实例化指向"电影"数据图的 `HanaRdfGraph`
2. 使用大型语言模型驱动的 `HanaSparqlQAChain` 将其包装
3. 提出自然语言问题并打印链的响应

这展示了大型语言模型如何在底层生成 SPARQL，对其执行 SAP HANA 查询，并返回人类可读的答案。

```typescript
// Serialise the graph schema (optional)
// 序列化图模式（可选）

// 我们使用 N3 Writer 将其序列化为 Turtle 格式以供显示
const schemaStore = graph.getSchema();

  prefixes: {
    rdf: "http://www.w3.org/1999/02/22-rdf-syntax-ns#",

    console.log("Graph Schema in Turtle format:\n", result);
```

## 底层发生了什么？

1. **SPARQL 生成**
   链使用您的 Turtle 格式本体（`graph.getSchema()`）和用户的问题调用大型语言模型，使用 `SPARQL_GENERATION_SELECT_PROMPT`。然后大型语言模型发出针对您的模式量身定制的有效 `SELECT` 查询。
2. **预处理和执行**
   * **提取和清理**：从大型语言模型的响应中提取原始 SPARQL 文本。
   * **注入图上下文**：如果缺少则添加 `FROM <graph_uri>`，并确保声明常用前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）。
   * **在 HANA 上运行**：通过 `HanaRdfGraph.query()` 对命名图执行最终查询。
3. **答案 formulation**
   返回的 CSV（或 Turtle）结果再次输入到大型语言模型——这次使用 `SPARQL_QA_PROMPT`。大型语言模型根据检索到的数据生成简洁、人类可读的答案，不会产生幻觉。
