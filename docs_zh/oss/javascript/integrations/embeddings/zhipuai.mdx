该 `ZhipuAI嵌入` 类使用 ZhipuAI API 为给定文本生成嵌入.

## 设置

您需要 注册 for an ZhipuAI API key and 将其设置为环境变量 named `ZHIPUAI_API_KEY`.

https://open.bigmodel.cn

Then, you'll need to install the [`@langchain/community`](https://www.npmjs.com/package/@langchain/community) package:

<Tip>
请参阅 [this section for general instructions on installing LangChain 包s](/oss/langchain/install).
</Tip>

```bash npm
npm install @langchain/community @langchain/core jsonwebtoken
```

## 使用方法

```typescript
import { ZhipuAIEmbeddings } from "@langchain/community/embeddings/zhipuai";

const model = new ZhipuAIEmbeddings({});
const res = await model.embedQuery(
  "What would be a good company name a company that makes colorful socks?"
);
console.log({ res });
```
