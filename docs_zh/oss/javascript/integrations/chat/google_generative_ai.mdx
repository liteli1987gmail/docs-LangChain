## 设置

您可以通过 `@langchain/google-genai` 集成包中的 `ChatGoogleGenerativeAI` 类访问 Google 的 `gemini` 和 `gemini-vision` 模型，以及 LangChain 中的其他生成模型。


<Tip>
您也可以通过 LangChain VertexAI 和 VertexAI-web 集成访问 Google 的 `gemini` 系列模型。请参阅 [Vertex AI 集成文档](/oss/integrations/chat/google_vertex_ai)。
</Tip>

### 凭据

在此处获取 API 密钥：[https://ai.google.dev/tutorials/setup](https://ai.google.dev/tutorials/setup)

然后设置 `GOOGLE_API_KEY` 环境变量：

```bash
export GOOGLE_API_KEY="your-api-key"
```

如果您想获取模型调用的自动追踪，还可以通过取消注释来设置您的 [LangSmith](/langsmith/home) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化

现在我们可以实例化我们的模型对象并生成聊天补全：

```typescript
import { ChatGoogleGenerativeAI } from "@langchain/google-genai"

const llm = new ChatGoogleGenerativeAI({
    model: "gemini-2.5-pro",
    temperature: 0,
    maxRetries: 2,
    // other params... // 其他参数...
})
```

## 安全设置

Gemini 模型有默认的安全设置，可以被覆盖。如果您从模型收到大量"安全警告"，可以尝试调整模型的安全设置属性。例如，要关闭危险内容的安全阻止，您可以按照以下方式导入 `@google/generative-ai` 包中的枚举，然后构建您的 LLM：

```typescript
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import { HarmBlockThreshold, HarmCategory } from "@google/generative-ai";

const llmWithSafetySettings = new ChatGoogleGenerativeAI({
  model: "gemini-2.5-pro",
  temperature: 0,
  safetySettings: [
    {
      category: HarmCategory.HARM_CATEGORY_HARASSMENT,
      threshold: HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
    },
  ],
  // other params... // 其他参数...
});
```

## 工具调用

使用 Google AI 进行工具调用与[其他模型的工具调用](/oss/langchain/tools)基本相同，但对 schema 有一些限制。

Google AI API 不允许工具 schema 包含具有未知属性的对象。例如，以下 Zod schema 将抛出错误：

`const invalidSchema = z.object({ properties: z.record(z.unknown()) });`

和

`const invalidSchema2 = z.record(z.unknown());`

相反，您应该显式定义对象字段的属性。以下是示例：

```typescript
import { tool } from "@langchain/core/tools";
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import * as z from "zod";

// Define your tool // 定义您的工具
const fakeBrowserTool = tool((_) => {
  return "The search result is xyz..." // 搜索结果是 xyz...
}, {
  name: "browser_tool",
  description: "Useful for when you need to find something on the web or summarize a webpage.", // 当您需要在网络上查找内容或总结网页时很有用。
  schema: z.object({
    url: z.string().describe("The URL of the webpage to search."), // 要搜索的网页 URL。
    query: z.string().optional().describe("An optional search query to use."), // 要使用的可选搜索查询。
  }),
})

const llmWithTool = new ChatGoogleGenerativeAI({
  model: "gemini-pro",
}).bindTools([fakeBrowserTool]) // Bind your tools to the model // 将您的工具绑定到模型

const toolRes = await llmWithTool.invoke([
  [
    "human",
    "Search the web and tell me what the weather will be like tonight in new york. use a popular weather website", // 在网络上搜索并告诉我今晚纽约的天气。使用一个流行的天气网站。
  ],
]);

console.log(toolRes.tool_calls);
```

```text
[
  {
    name: 'browser_tool',
    args: {
      url: 'https://www.weather.com',
      query: 'weather tonight in new york'
    },
    type: 'tool_call'
  }
]
```

const searchRetrievalTool: GoogleSearchRetrievalTool = {
  googleSearchRetrieval: {
    dynamicRetrievalConfig: {
      mode: DynamicRetrievalMode.MODE_DYNAMIC,
      dynamicThreshold: 0.7, // default is 0.7 // 默认为 0.7

const searchRetrievalModel = new ChatGoogleGenerativeAI({
  model: "gemini-2.5-pro",

### 代码执行

Google Generative AI 还支持代码执行。使用内置的 `CodeExecutionTool`，您可以让模型生成代码、执行代码，并在最终补全中使用结果：

```typescript
import { CodeExecutionTool } from "@google/generative-ai";
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";

const codeExecutionTool: CodeExecutionTool = {
  codeExecution: {}, // Simply pass an empty object to enable it. // 只需传递一个空对象即可启用它。
};
const codeExecutionModel = new ChatGoogleGenerativeAI({
  model: "gemini-2.5-pro",
  temperature: 0,
  maxRetries: 0,
}).bindTools([codeExecutionTool]);

const codeExecutionResult = await codeExecutionModel.invoke("Use code execution to find the sum of the first and last 3 numbers in the following list: [1, 2, 3, 72638, 8, 727, 4, 5, 6]"); // 使用代码执行找出以下列表中前 3 个和后 3 个数字的和：[1, 2, 3, 72638, 8, 727, 4, 5, 6]

console.dir(codeExecutionResult.content, { depth: null });
```

## 上下文缓存

上下文缓存允许您将某些内容传递给模型一次，缓存输入 Token，然后在后续请求中引用缓存的 Token 以降低成本。您可以使用 `GoogleAICacheManager` 类创建一个 `CachedContent` 对象，然后使用 `enableCachedContent()` 方法将 `CachedContent` 对象传递给您的 `ChatGoogleGenerativeAIModel`。

```typescript
import { ChatGoogleGenerativeAI } from "@langchain/google-genai";
import {
  GoogleAICacheManager,
  GoogleAIFileManager,
} from "@google/generative-ai/server";

const fileManager = new GoogleAIFileManager(process.env.GOOGLE_API_KEY);
const cacheManager = new GoogleAICacheManager(process.env.GOOGLE_API_KEY);

// uploads file for caching // 上传文件以进行缓存
const pathToVideoFile = "/path/to/video/file";
const displayName = "example-video";
const fileResult = await fileManager.uploadFile(pathToVideoFile, {
    displayName,
    mimeType: "video/mp4",
});

// creates cached content AFTER uploading is finished // 上传完成后创建缓存内容
const cachedContent = await cacheManager.create({
    model: "models/gemini-2.5-flash",
    displayName: displayName,
    systemInstruction: "You are an expert video analyzer, and your job is to answer " +
      "the user's query based on the video file you have access to.", // 您是一位专业的视频分析专家，您的工作是根据您可以访问的视频文件回答用户的查询。
    contents: [
        {
            role: "user",
            parts: [
                {
                    fileData: {
                        mimeType: fileResult.file.mimeType,
                        fileUri: fileResult.file.uri,
                    },
                },
            ],
        },
    ],
    ttlSeconds: 300,
});

// passes cached video to model // 将缓存的视频传递给模型
const model = new ChatGoogleGenerativeAI({});
model.useCachedContent(cachedContent);

// invokes model with cached video // 使用缓存的视频调用模型
await model.invoke("Summarize the video"); // 总结这个视频
```

**注意**

- 上下文缓存的最小输入 Token 数为 32,768，最大值与给定模型的最大值相同。

## Gemini 提示词常见问题

截至本文档撰写之日（2023/12/12），Gemini 对其接受的提示词类型和结构有一些限制。具体来说：

1. 当提供多模态（图像）输入时，您最多只能发送 1 条"human"（用户）类型消息。您不能传递多条消息（尽管单条用户消息可以有多个内容条目）
2. 系统消息不被原生支持，如果存在，将与第一条用户消息合并。
3. 对于常规聊天对话，消息必须遵循 human/ai/human/ai 交替模式。您不能连续提供 2 条 AI 或用户消息。
4. 如果消息违反 LLM 的安全检查，可能会被阻止。在这种情况下，模型将返回空响应。
