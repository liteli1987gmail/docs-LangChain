[Ollama](https://ollama.ai/) 允许您本地运行开源大型语言模型（LLM），如 Llama 3.1。

Ollama 将模型权重、配置和数据打包成一个包，由 Modelfile 定义。它优化了设置和配置细节，包括 GPU 使用。

本指南将帮助您开始使用 `ChatOllama` [聊天模型](/oss/langchain/models)。有关所有 `ChatOllama` 功能和配置的详细文档，请前往 [API 参考](https://reference.langchain.com/javascript/langchain-ollama/ChatOllama)。

## 实例化

现在我们可以实例化我们的模型对象并生成聊天补全：

```typescript
import { ChatOllama } from "@langchain/ollama"

const llm = new ChatOllama({
    model: "llama3",
    temperature: 0,
    maxRetries: 2,
    // other params... // 其他参数...
})
```

## 工具

Ollama 现在为[其可用模型的子集](https://ollama.com/search?c=tools)提供原生工具调用支持。下面的示例演示了如何从 Ollama 模型调用工具。

```typescript
import { tool } from "@langchain/core/tools";
import { ChatOllama } from "@langchain/ollama";
import * as z from "zod";

const weatherTool = tool((_) => "Da weather is weatherin", {
  name: "get_current_weather",
  description: "Get the current weather in a given location", // 获取给定位置的当前天气
  schema: z.object({
    location: z.string().describe("The city and state, e.g. San Francisco, CA"), // 城市和州，例如 San Francisco, CA
  }),
});

// Define the model // 定义模型
const llmForTool = new ChatOllama({
  model: "llama3-groq-tool-use",
});

// Bind the tool to the model // 将工具绑定到模型
const llmWithTools = llmForTool.bindTools([weatherTool]);

const resultFromTool = await llmWithTools.invoke(
  "What's the weather like today in San Francisco? Ensure you use the 'get_current_weather' tool." // 今天旧金山的天气怎么样？确保使用 'get_current_weather' 工具。
);

console.log(resultFromTool);
```

## 结构化输出

Ollama 原生支持所有模型的[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)，允许您通过调用 `.withStructuredOutput()` 强制模型返回特定格式。

```typescript
import { ChatOllama } from "@langchain/ollama";
import { z } from "zod";

// Define the schema // 定义 schema
const Country = z.object({
  name: z.string(),
  capital: z.string(),
  languages: z.array(z.string()),
});

// Define the model // 定义模型
const llm = new ChatOllama({
  model: "llama3.1",
  temperature: 0,
});

// Pass the schema to enforce a specific output format // 传递 schema 以强制执行特定输出格式
const structuredLlm = llm.withStructuredOutput(Country);

const result = await structuredLlm.invoke("Tell me about Canada."); // 告诉我关于加拿大的一切。
console.log(result);
```

```output
{
  name: 'Canada',
  capital: 'Ottawa',
  languages: [ 'English', 'French' ]
}
```

如果您更喜欢通过工具调用使用结构化输出，请传递 `method: "functionCalling"` 选项：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { z } from "zod";

// Define the schema // 定义 schema
const Sentence = z.object({
  nouns: z.array(z.string()),
});

// Define the model // 定义模型
const llm = new ChatOllama({
  model: "llama3.1",
  temperature: 0,
});

// Use structured output via tool calling // 通过工具调用使用结构化输出
const structuredLlm = llm.withStructuredOutput(Sentence, { method: "functionCalling" });

const result = await structuredLlm.invoke("Extract all nouns: A cat named Luna who is 5 years old and loves playing with yarn. She has grey fur"); // 提取所有名词：一只名叫 Luna 的猫，5 岁，喜欢玩毛线。她有灰色的毛。
console.log(result);
```

```output
{ nouns: [ 'cat', 'Luna', 'years', 'yarn', 'fur' ] }
```

## 多模态模型

Ollama 在 0.1.15 及以上版本中支持开源多模态模型，如 [LLaVA](https://ollama.ai/library/llava)。
您可以将图像作为消息 `content` 字段的一部分传递给[支持多模态](/oss/langchain/messages#multimodal)的模型，如下所示：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage } from "@langchain/core/messages";
import * as fs from "node:fs/promises";

const imageData = await fs.readFile("../../../../../examples/hotdog.jpg");
const llmForMultiModal = new ChatOllama({
  model: "llava",
  baseUrl: "http://127.0.0.1:11434",
});
const multiModalRes = await llmForMultiModal.invoke([
  new HumanMessage({
    content: [
      {
        type: "text",
        text: "What is in this image?", // 这张图片里有什么？
      },
      {
        type: "image_url",
        image_url: `data:image/jpeg;base64,${imageData.toString("base64")}`,
      },
    ],
  }),
]);
console.log(multiModalRes);
```
