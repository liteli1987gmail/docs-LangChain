<Warning>
**LangChain Ollama 集成包已正式支持工具调用。[查看 Ollama 工具调用文档](/oss/integrations/chat/ollama#tools)。**

</Warning>

LangChain 提供了一个实验性包装器，围绕通过 [Ollama](https://github.com/jmorganca/ollama) 本地运行的开源模型，使其具有与 OpenAI Functions 相同的 API。

请注意，更强大、更有能力的模型在使用复杂 schema 和/或多个函数时表现更好。下面的示例使用 [Mistral](https://ollama.ai/library/mistral)。

<Warning>
**这是一个实验性包装器，试图为不支持原生工具调用的模型添加工具调用支持。请谨慎使用。**

</Warning>

## 设置

按照[这些说明](https://github.com/jmorganca/ollama)设置和运行本地 Ollama 实例。

## 初始化模型

您可以像初始化标准 `ChatOllama` 实例一样初始化此包装器：

```typescript
import { OllamaFunctions } from "@langchain/community/experimental/chat_models/ollama_functions";

const model = new OllamaFunctions({
  temperature: 0.1,
  model: "mistral",
});
```

## 传入函数

您现在可以像使用 OpenAI 一样传入函数：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage } from "@langchain/core/messages";

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "get_current_weather",
      description: "Get the current weather in a given location", // 获取给定位置的当前天气
      parameters: {
        type: "object",
        properties: {
          location: {
            type: "string",
            description: "The city and state, e.g. San Francisco, CA", // 城市和州，例如 San Francisco, CA
          },
          unit: { type: "string", enum: ["celsius", "fahrenheit"] },
        },
        required: ["location"],
      },
    },
  ])
  .withConfig({
    // You can set the `tool_choice` arg to force the model to use a function // 您可以设置 `tool_choice` 参数来强制模型使用函数
    tool_choice: "get_current_weather",
  });

const response = await model.invoke([
  new HumanMessage({
    content: "What's the weather in Boston?", // 波士顿的天气怎么样？
  }),
]);

console.log(response);

/*
  AIMessage {
    content: '',
    additional_kwargs: {
      function_call: {
        name: 'get_current_weather',
        arguments: '{"location":"Boston, MA","unit":"fahrenheit"}'
      }
    }
  }
*/
```

## 用于提取

```typescript
import * as z from "zod";

import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";
import { JsonOutputFunctionsParser } from "@langchain/core/output_parsers/openai_functions";

const EXTRACTION_TEMPLATE = `Extract and save the relevant entities mentioned in the following passage together with their properties.
// 提取并保存以下段落中提到的相关实体及其属性。

Passage: // 段落：
{input}
`;

const prompt = PromptTemplate.fromTemplate(EXTRACTION_TEMPLATE);

// Use Zod for easier schema declaration // 使用 Zod 以便更容易地声明 schema
const schema = z.object({
  people: z.array(
    z.object({
      name: z.string().describe("The name of a person"), // 人的名字
      height: z.number().describe("The person's height"), // 这个人的身高
      hairColor: z.optional(z.string()).describe("The person's hair color"), // 这个人的头发颜色
    })
  ),
});

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "information_extraction",
      description: "Extracts the relevant information from the passage.", // 从段落中提取相关信息。
      schema,
    },
  ])
  .withConfig({
    tool_choice: "information_extraction",
  });

// Use a JsonOutputFunctionsParser to get the parsed JSON response directly. // 使用 JsonOutputFunctionsParser 直接获取解析后的 JSON 响应。
const chain = prompt.pipe(model).pipe(new JsonOutputFunctionsParser());

const response = await chain.invoke({
  input:
    "Alex is 5 feet tall. Claudia is 1 foot taller than Alex and jumps higher than him. Claudia has orange hair and Alex is blonde.", // Alex 身高 5 英尺。Claudia 比 Alex 高 1 英尺，跳得也比他高。Claudia 有橙色的头发，Alex 是金发。
});

console.log(JSON.stringify(response, null, 2));

/*
{
  "people": [
    {
      "name": "Alex",
      "height": 5,
      "hairColor": "blonde"
    },
    {
      "name": "Claudia",
      "height": {
        "$num": 1,
        "add": [
          {
            "name": "Alex",
            "prop": "height"
          }
        ]
      },
      "hairColor": "orange"
    }
  ]
}
*/
```

## 自定义

在幕后，这使用 Ollama 的 JSON 模式将输出约束为 JSON，然后将工具 schema 作为 JSON schema 传递到提示词中。

因为不同的模型有不同的优势，传入您自己的系统提示词可能会有帮助。以下是示例：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

// Custom system prompt to format tools. You must encourage the model
// to wrap output in a JSON object with "tool" and "tool_input" properties.
// 自定义系统提示词以格式化工具。您必须鼓励模型将输出包装在具有 "tool" 和 "tool_input" 属性的 JSON 对象中。
const toolSystemPromptTemplate = `You have access to the following tools:

{tools}

To use a tool, respond with a JSON object with the following structure:
{{
  "tool": <name of the called tool>,
  "tool_input": <parameters for the tool matching the above JSON schema>
}}`;

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "get_current_weather",
      description: "Get the current weather in a given location", // 获取给定位置的当前天气
      parameters: {
        type: "object",
        properties: {
          location: {
            type: "string",
            description: "The city and state, e.g. San Francisco, CA", // 城市和州，例如 San Francisco, CA
          },
          unit: { type: "string", enum: ["celsius", "fahrenheit"] },
        },
        required: ["location"],
      },
    },
  ])
  .withConfig({
    // You can set the `tool_choice` arg to force the model to use a function // 您可以设置 `tool_choice` 参数来强制模型使用函数
    tool_choice: "get_current_weather",
  });

const response = await model.invoke([
  new SystemMessage(toolSystemPromptTemplate),
  new HumanMessage({
    content: "What's the weather in Boston?", // 波士顿的天气怎么样？
  }),
]);

console.log(response);

/*
  AIMessage {
    content: '',
    additional_kwargs: {
      function_call: {
        name: 'get_current_weather',
        arguments: '{"location":"Boston, MA","unit":"fahrenheit"}'
      }
    }
  }
*/
```
