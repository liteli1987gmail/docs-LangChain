## 设置

1. [创建一个 Prem AI 账户并获取您的 API 密钥](https://studio.premai.io/sign-up)。
2. 导出或内联设置您的 API 密钥。ChatPrem 类默认为 `process.env.PREM_API_KEY`。

```bash
export PREM_API_KEY=your-api-key
```

您可以按如下方式使用 Prem AI 提供的模型：

<Tip>
有关安装 LangChain 包的常规说明，请参阅[此部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```

```typescript
import { ChatPrem } from "@langchain/community/chat_models/premai";
import { HumanMessage } from "@langchain/core/messages";

const model = new ChatPrem({
  // In Node.js defaults to process.env.PREM_API_KEY // 在 Node.js 中默认为 process.env.PREM_API_KEY
  apiKey: "YOUR-API-KEY",
  // In Node.js defaults to process.env.PREM_PROJECT_ID // 在 Node.js 中默认为 process.env.PREM_PROJECT_ID
  project_id: "YOUR-PROJECT-ID",
});

console.log(await model.invoke([new HumanMessage("Hello there!")])); // 您好！
```
