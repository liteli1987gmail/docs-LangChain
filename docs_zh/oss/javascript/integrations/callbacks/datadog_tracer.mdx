<Warning>
大型语言模型可观测性处于公开测试阶段，其接口可能会发生变化。
</Warning>

通过 [Datadog 大型语言模型可观测性](https://docs.datadoghq.com/llm_observability/)，您可以监控、排错和评估大型语言模型驱动的应用程序（如聊天机器人）。您可以调查问题的根本原因、监控操作性能，并评估大型语言模型应用程序的质量、隐私和安全性。

这是一个实验性的社区实现，Datadog 官方不提供支持。它基于 [Datadog 大型语言模型可观测性接口](https://docs.datadoghq.com/llm_observability/api)。

## 设置

<Tip>
有关安装 LangChain 软件包的常规说明，请参阅[此部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```

## 使用方法

```typescript
import { OpenAI } from "@langchain/openai";
import { DatadogLLMObsTracer } from "@langchain/community/experimental/callbacks/handlers/datadog";

// This example demonstrates how to use the DatadogLLMObsTracer with the OpenAI model.
// 此示例演示如何将 DatadogLLMObsTracer 与 OpenAI 模型一起使用。
// It will produce a "llm" span with the input and output of the model inside the meta field.
export const run = async () => {
  const model = new OpenAI({
    model: "gpt-4",
    temperature: 0.7,
    maxTokens: 1000,
    maxRetries: 5,
  });

  const res = await model.invoke(
    "Question: What would be a good company name a company that makes colorful socks?\nAnswer:",
    {
      callbacks: [
        new DatadogLLMObsTracer({
          mlApp: "my-ml-app",
        }),
      ],
    }
  );

  console.log({ res });
};
```
