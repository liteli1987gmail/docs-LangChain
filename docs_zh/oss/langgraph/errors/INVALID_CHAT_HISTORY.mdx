title: INVALID_CHAT_HISTORY
---

:::python
当预构建的 @[`create_agent`] 中的 `call_model` 图节点收到格式错误的邮件列表时，会引发此错误。具体来说，当存在带有 `tool_calls`（大型语言模型请求调用工具）但没有相应的 @[`ToolMessage`]（工具调用结果返回给大型语言模型）的 `AIMessages` 时，格式是错误的。
:::

:::js
当预构建的 @[`createAgent`] 中的 `callModel` 图节点收到格式错误的邮件列表时，会引发此错误。具体来说，当存在带有 `tool_calls`（大型语言模型请求调用工具）但没有相应的 @[`ToolMessage`]（工具调用结果返回给大型语言模型）的 `AIMessage` 时，格式是错误的。
:::

您看到此错误的原因可能有几个：

:::python
1. 在调用图时手动传递了格式错误的邮件列表，例如 `graph.invoke({'messages': [AIMessage(..., tool_calls=[...])]})`
2. 图在从 `tools` 节点接收更新之前被中断了（即 @[`ToolMessage`] 列表）
    并且您使用不是 None 或 ToolMessage 的输入调用了它，
    例如 `graph.invoke({'messages': [HumanMessage(...)]}, config)`。
    此中断可能通过以下方式触发：
        * 您在 `create_agent` 中手动设置了 `interrupt_before = ['tools']`
    * 某个工具抛出了未被 @[`ToolNode`]（`"tools"`）处理的错误
:::

:::js
1. 在调用图时手动传递了格式错误的邮件列表，例如 `graph.invoke({messages: [new AIMessage({..., tool_calls: [...]})]})`
2. 图在从 `tools` 节点接收更新之前被中断了（即 @[`ToolMessage`] 列表）
    并且您使用不是 null 或 ToolMessage 的输入调用了它，
    例如 `graph.invoke({messages: [new HumanMessage(...)]}, config)`。
    此中断可能通过以下方式触发：
    * 您在 `createAgent` 中手动设置了 `interruptBefore: ['tools']`
    * 某个工具抛出了未被 @[`ToolNode`]（`"tools"`）处理的错误
:::

## 故障排除

要解决此问题，您可以执行以下操作之一：

1. 不要使用格式错误的邮件列表调用图
2. 如果是中断（手动或由于错误），您可以：

:::python
* 提供与现有工具调用匹配的 @[`ToolMessage`] 对象，并调用 `graph.invoke({'messages': [ToolMessage(...)]})`。
  **注意**：这会将消息追加到历史记录中并从 START 节点运行图。
  * 手动更新状态并从中断处恢复图：
    1. 使用 `graph.get_state(config)` 从图状态中获取最新消息列表
    2. 修改消息列表以从 AIMessages 中删除未回答的工具调用

或添加与未回答工具调用匹配的 `tool_call_ids` 的 @[`ToolMessage`] 对象 3. 使用修改后的消息列表调用 `graph.update_state(config, {'messages': ...})` 4. 恢复图，例如调用 `graph.invoke(None, config)`
:::

:::js
* 提供与现有工具调用匹配的 `ToolMessage` 对象，并调用 `graph.invoke({messages: [new ToolMessage(...)]})`。
  **注意**：这会将消息追加到历史记录中并从 START 节点运行图。
  * 手动更新状态并从中断处恢复图：
    1. 使用 `graph.getState(config)` 从图状态中获取最新消息列表
    2. 修改消息列表以从 AIMessages 中删除未回答的工具调用

或添加与未回答工具调用匹配的 `toolCallId` 的 `ToolMessage` 对象 3. 使用修改后的消息列表调用 `graph.updateState(config, {messages: ...})` 4. 恢复图，例如调用 `graph.invoke(null, config)`
::
