长期记忆让你的代理能够在不同的对话和会话中存储和调用信息。
与仅限于单个线程的[短期记忆](/oss/langchain/short-term-memory)不同，长期记忆跨线程持久化，可以随时被调用。

长期记忆建立在 [LangGraph 存储](/oss/langgraph/persistence#memory-store) 之上，后者将数据保存为按命名空间和键组织的 JSON 文档。

</Tip>

## 记忆存储

LangGraph 将长期记忆存储为[存储](/oss/langgraph/persistence#memory-store)中的 JSON 文档。

每个记忆都按自定义的 `namespace`（类似于文件夹）和不同的 `key`（类似于文件名）组织。命名空间通常包括用户或组织 ID 或其他标签，以便更容易组织信息。

这种结构支持记忆的层级组织。然后通过内容过滤器支持跨命名空间搜索。
