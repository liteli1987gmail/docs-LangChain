title: 版本控制
---

我们的 OSS 版本号遵循格式：`MAJOR.MINOR.PATCH`，遵循[语义化版本控制](https://semver.org/)。

- **Major（主版本）**：需要进行代码更改的破坏性 API 更新。
- **Minor（次要版本）**：保持向后兼容性的新功能和改进。
- **Patch（补丁版本）**：错误修复和小的改进。

例如：

- `1.0.0`：第一个具有生产就绪 API 的稳定版本
- `1.1.0`：以向后兼容方式添加的新功能
- `1.0.1`：向后兼容的错误修复

## API 稳定性

我们按以下方式传达 API 的稳定性：

### 稳定 API

所有没有特殊前缀的 API 都被视为稳定的，可用于生产。我们维护稳定功能的向后兼容性，并且仅在主版本中引入破坏性更改。

### Beta API

标记为 `beta` 的 API 功能完整，但可能会根据用户反馈进行小的更改。它们可以安全地用于生产，但可能在未来版本中需要小的调整。

### Alpha API

标记为 `alpha` 的 API 是实验性的，可能会有重大变化。在生产环境中使用这些 API 时应谨慎。

### 已弃用的 API

标记为 `deprecated` 的 API 将在未来主版本中移除。在可能的情况下，我们会指定预期的移除版本。要处理弃用：

1. 切换到推荐的替代 API
2. 遵循迁移指南（与主版本一起发布）
3. 在可用时使用自动化迁移工具

### 内部 API

某些 API 通过几种方式明确标记为"内部"：

- 某些文档提到内部内容并如此说明。如果文档说某个内容是内部的，它可能会更改。
- 函数、方法和其他以单下划线（**\_`**）为前缀的对象。这是表示某些内容是私有的标准 Python 约定；如果任何方法以单个 **`_`** 开头，它就是一个内部 API。
  - **例外：** 某些方法以 `_` 为前缀，但不包含实现。这些方法*旨在*被提供实现的子类覆盖。这样的方法通常是 LangChain **公共 API** 的一部分。

## 发布周期

<AccordionGroup>
    <Accordion title="主版本发布">
        主版本发布（例如 `1.0.0` → `2.0.0`）可能包括：

        - 破坏性 API 更改
        - 移除已弃用的功能
        - 重大架构改进

        我们提供：

        - 详细的迁移指南
        - 可行时的自动化迁移工具
        - 之前主版本的扩展支持期限
    </Accordion>

    <Accordion title="次要版本发布">
        次要版本发布（例如 `1.0.0` → `1.1.0`）包括：

        - 新功能和新能力
        - 性能改进
        - 新的可选参数
        - 向后兼容的增强
    </Accordion>

    <Accordion title="补丁版本发布">
        补丁版本发布（例如 `1.0.0` → `1.0.1`）包括：

        - 错误修复
        - 安全更新
        - 文档改进
        - 不更改 API 的性能优化
    </Accordion>

</AccordionGroup>

## 版本支持政策

- **最新主版本**：全力支持，活跃开发（ACTIVE 状态）
- **之前的主版本**：在下一个主版本发布后 12 个月内提供安全更新和关键错误修复（MAINTENANCE 状态）
- **更旧的版本**：仅社区支持

### 长期支持（LTS）版本

LangChain 和 LangGraph 1.0 都已被指定为 LTS 版本：

- 1.0 版本将保持在 ACTIVE 状态，直到 2.0 版本发布
- 2.0 版本发布后，1.0 版本将进入 MAINTENANCE 模式至少 1 年
- LTS 版本遵循语义化版本控制（semver），允许在次要版本之间安全升级
- 旧版本（LangChain 0.3 和 LangGraph 0.4）处于 MAINTENANCE 模式直至 2026 年 12 月

### 1.0 前的包

:::python
**Deep Agents**（`deepagents`）是一个处于活跃开发中的 1.0 前包。作为一个快速发展的包，API 可能在次要版本之间更改，但我们尽可能减少破坏性更改。Deep Agents 在达到 1.0 版本后将采用与 LangChain 和 LangGraph 相同的 LTS 政策。
:::

有关发布状态和支持时间线的详细信息，请参阅[发布政策](/oss/release-policy)。

## 升级

:::python

<CodeGroup>

```bash LangChain
# 升级到最新版本
pip install -U langchain-core langchain

# 升级到特定版本
pip install langchain-core==1.0.0
```

```bash LangGraph
# 升级到最新版本
pip install -U langgraph

# 升级到特定版本
pip install langgraph==1.0.0
```

```bash Deep Agents
# 升级到最新版本
pip install -U deepagents

# 升级到特定版本
pip install deepagents==0.1.0
```

</CodeGroup>
:::

:::js

<CodeGroup>

```bash LangChain
# 升级到最新版本
npm update langchain @langchain/core

npm install langchain@1.0.0 @langchain/core@1.0.0
```

```bash LangGraph
# 升级到最新版本

npm install @langchain/langgraph@1.0.0
```

</CodeGroup>
:::

## 预发布版本

我们偶尔会发布 alpha 和 beta 版本以供早期测试：

- **Alpha**（例如 `1.0.0a1`）：早期预览，预计会有重大变化
- **Beta**（例如 `1.0.0b1`）：功能完整，可能有小的更改
- **发布候选**（例如 `1.0.0rc1`）：稳定版本发布前的最终测试
