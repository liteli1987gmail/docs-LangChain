## 代理框架（如 LangChain）

代理框架提供抽象层，使在使用大型语言模型构建时更容易上手。

[LangChain](/oss/langchain/overview) 是一个提供结构化内容块、代理循环和中间件等抽象的代理框架。

LangChain 的抽象设计为易于上手，同时仍提供高级用例所需的灵活性。

虽然 LangChain 构建在 [LangGraph](/oss/langgraph/overview) 之上，但你不需要了解 LangGraph 也能使用 LangChain。

代理框架的其他示例包括 [Vercel 的 AI SDK](https://ai-sdk.dev/docs/introduction)、[CrewAI](https://www.crewai.com/)、[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)、[Google ADK](https://google.github.io/adk-docs/)、[LlamaIndex](https://www.llamaindex.ai/) 等等。

### 何时使用 LangChain

在以下情况下使用 LangChain：

- 你想快速构建代理和自主应用。
- 你需要模型、工具和代理循环的标准抽象。
- 你想要一个易于使用但仍提供灵活性的框架。
- 你正在构建没有复杂编排需求的简单代理应用。

## 代理运行时（如 LangGraph）

代理运行时提供用于在生产环境中运行代理的工具。
支持的工具可能包括：

- **持久执行**：代理在故障中持久化，可以长时间运行，并从中断处恢复。
- **流式处理**：支持流式工作流和响应。
- **人在环中（Human-in-the-loop）**：通过检查和修改代理状态纳入人工监督。
- **持久化**：用于状态管理的线程级和跨线程持久化。
- **低级控制**：直接控制代理编排，不使用高级抽象。

[LangGraph](/oss/langgraph/overview) 是一个低级编排框架和运行时，用于构建、管理和部署长时间运行的有状态代理。

代理框架通常更高级，并在代理运行时上运行。
例如，LangChain 1.0 构建在 LangGraph 之上。

代理运行时的其他示例包括 [Temporal](https://temporal.io/)、[Inngest](https://www.inngest.com/) 和其他持久执行引擎。

### 何时使用 LangGraph

在以下情况下使用 LangGraph：

- 你需要对代理编排进行细粒度、低级别的控制。
- 你需要长时间运行的有状态代理的持久执行。
- 你在构建结合确定性和代理步骤的复杂工作流。
- 你需要用于代理部署的生产级基础设施。

## 代理工具（如 Deep Agents SDK）

代理工具是固执己见的、包含电池的框架，内置了用于构建复杂长时间运行代理的工具和能力。
支持的工具可能包括：

- **规划能力**：使用待办事项列表跟踪多个任务。
- **任务委托**：委托工作并使用子代理保持上下文清晰。
- **文件系统**：在不同可插拔存储后端上读取和写入访问。
- **Token 管理**：对话历史摘要和大型工具结果驱逐。

[Deep Agents SDK](/oss/deepagents/overview) 构建在 LangGraph 之上，添加了规划能力、用于上下文管理的文件系统、生成子代理的能力等等。
Deep Agents 专为需要规划和分解的复杂多步骤任务而设计。

示例任务包括处理搜索结果、脚本和其他状态中的产物。

代理工具的其他示例包括 [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview)、[Manus](https://manus.im/) 和其他编码 CLI。

### 何时使用 Deep Agents SDK

在以下情况下使用 [Deep Agents SDK](/oss/deepagents/overview)：

- 你正在构建长时间运行的代理。
- 你正在构建需要处理复杂多步骤任务的代理。
- 你想使用预定义工具，例如文件系统操作、bash 执行和自动上下文工程。
- 你想使用预定义提示词和子代理。

## 功能比较

虽然你可以用 LangChain、LangGraph 和 Deep Agents 完成类似的任务，但它们之间的集成级别不同：

| ------- | --------- | ----------- | ----------- |

| 长期记忆 | [长期记忆](/oss/langchain/long-term-memory) | [长期记忆](/oss/langgraph/add-memory#add-long-term-memory) | [长期记忆](/oss/deepagents/memory) |
| 技能（Skills） | [多代理技能](/oss/langchain/multi-agent/skills) | - | [技能](/oss/deepagents/skills) |
