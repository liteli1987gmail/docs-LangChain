# Hugging Face Sentence Transformers

You're sharing information about the **Hugging Face sentence-transformers** library. Here's a summary:

## Overview

- **sentence-transformers** is a Python framework for generating state-of-the-art embeddings for:
  - Sentences
  - Text
  - Images

## `HuggingFaceInstructEmbeddings`

The `HuggingFaceInstructEmbeddings` class in LangChain uses **instruct embedding models** from Hugging Face.

### Example Usage:

```python
from langchain_community.embeddings import HuggingFaceInstructEmbeddings

# Initialize with default model
embeddings = HuggingFaceInstructEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)

# Or use an instruct model
embeddings = HuggingFaceInstructEmbeddings(
    model_name="hkunlp/instructor-large",
    instruction="Represent the document for retrieval:"
)
```

### Key Features:

| Feature | Description |
|---------|-------------|
| **Instruction Prefix** | Allows specifying how embeddings should be generated |
| **Multiple Models** | Supports various sentence-transformer models |
| **Local Deployment** | Can run models locally without API calls |
