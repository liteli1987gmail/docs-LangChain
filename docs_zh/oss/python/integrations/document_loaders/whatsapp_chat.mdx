WhatsApp（也称为`WhatsApp Messenger`）是一款免费、跨平台、集中式的即时通讯（IM）和互联网协议语音（VoIP）服务。它允许用户发送文本和语音消息，进行语音和视频通话，以及分享图片、文档、用户位置和其他内容。

This notebook covers how to load data from the `WhatsApp Chats` into a format that can be ingested into LangChain.

```python
from langchain_community.document_loaders import WhatsAppChatLoader
```

```python
loader = WhatsAppChatLoader("example_data/whatsapp_chat.txt")
```

```python
loader.load()
```
