[Google Cloud Text-to-Speech](https://cloud.google.com/text-to-speech) 使开发者能够合成听起来自然的语音，拥有 100 多种声音，支持多种语言和变体。它应用了 DeepMind 在 WaveNet 方面的开创性研究和 Google 强大的神经网络，以提供尽可能高的保真度。

它支持多种语言，包括英语、德语、波兰语、西班牙语、意大利语、法语、葡萄牙语和印地语。

This notebook shows how to interact with the `Google Cloud Text-to-Speech API` to achieve speech synthesis capabilities.

First, you need to set up an Google Cloud project. You can follow the [Google Cloud Text-to-Speech setup instructions](https://cloud.google.com/text-to-speech/docs/before-you-begin).
