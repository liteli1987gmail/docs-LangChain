Browserless是一项允许你在云端运行无头Chrome实例的服务。这是一种大规模运行浏览器自动化的绝佳方式，无需担心管理自己的基础设施。

## Installation and setup

Get the API key from the [Browserless pricing page](https://www.browserless.io/pricing/).


## Document loader

See a [usage example](/oss/integrations/document_loaders/browserless).

```python
from langchain_community.document_loaders import BrowserlessLoader
```
