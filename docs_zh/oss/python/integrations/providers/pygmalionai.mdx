[PygmalionAI](https://pygmalion.chat/) 是一家通过为 [Aphrodite Engine](https://github.com/PygmalionAI/aphrodite-engine) 提供推理端点服务来支持开源模型的公司。


## Installation and setup


<CodeGroup>
```bash pip
pip install aphrodite-engine
```

```bash uv
uv add aphrodite-engine
```
</CodeGroup>

## LLMs

See a [usage example](/oss/integrations/llms/aphrodite).

```python
from langchain_community.llms import Aphrodite
```
