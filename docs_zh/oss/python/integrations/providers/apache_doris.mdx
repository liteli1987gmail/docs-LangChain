[Apache Doris](https://doris.apache.org/) 是一个用于实时分析的现代化数据仓库。
It delivers lightning-fast analytics on real-time data at scale.

通常 Apache Doris 被归类为 OLAP（联机分析处理），并展现出卓越的性能，在 [ClickBench — a Benchmark For Analytical DBMS](https://benchmark.clickhouse.com/) 中。由于它拥有超快的向量化执行引擎，它也可以作为快速的 vectordb 使用。

## Installation and setup

<CodeGroup>
```bash pip
pip install pymysql
```

```bash uv
uv add pymysql
```
</CodeGroup>
