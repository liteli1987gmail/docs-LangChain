01.AI，由李开复博士创立，是全球AI 2.0前沿的公司。他们提供尖端的大语言模型，包括Yi系列，参数从60亿到数千亿不等。01.AI还提供多模态模型、开放API平台，以及开源选项如Yi-34B/9B/6B和Yi-VL。

## Installation and setup

Register and get an API key from either the [China site](https://platform.lingyiwanwu.com/apikeys) or the [global site](https://platform.01.ai/apikeys).

## LLMs

See a [usage example](/oss/integrations/llms/yi).

```python
from langchain_community.llms import YiLLM
```
