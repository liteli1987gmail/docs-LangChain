>[Streamlit](https://streamlit.io/) 是更快地构建和共享数据应用的方式。
>`Streamlit` 将数据脚本在几分钟内转换为可共享的 web 应用。全部使用纯 Python。无需前端经验。
>查看更多示例，请访问 [streamlit.io/generative-ai](https://streamlit.io/generative-ai)。

## Installation and setup

We need to install the  `streamlit` Python package:

<CodeGroup>
```bash pip
pip install streamlit
```

```bash uv
uv add streamlit
```
</CodeGroup>


## Callbacks

See a [usage example](/oss/integrations/callbacks/streamlit).

```python
from langchain_community.callbacks import StreamlitCallbackHandler
```
