[Twitter](https://twitter.com/) 是一个在线社交媒体和社交网络服务。


## Installation and setup

<CodeGroup>
```bash pip
pip install tweepy
```

```bash uv
uv add tweepy
```
</CodeGroup>

We must initialize the loader with the `Twitter API` token, and we need to set up the Twitter `username`.


## Document loader

See a [usage example](/oss/integrations/document_loaders/twitter).

```python
from langchain_community.document_loaders import TwitterTweetLoader
```
