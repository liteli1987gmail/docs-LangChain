> [E2B](https://e2b.dev/) 提供开源的安全沙箱，
> 用于 AI 生成代码的执行。更多内容请参阅 [e2b GitHub 仓库](https://github.com/e2b-dev)。

## Installation and setup

You have to install a python package:

<CodeGroup>
```bash pip
pip install e2b_code_interpreter
```

```bash uv
uv add e2b_code_interpreter
```
</CodeGroup>

## Tool

See a [usage example](/oss/integrations/tools/e2b_data_analysis).

```python
from langchain_community.tools import E2BDataAnalysisTool
```
