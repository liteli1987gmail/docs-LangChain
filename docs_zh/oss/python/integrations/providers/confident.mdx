[Confident AI](https://confident-ai.com)是`DeepEval`的创造者。

[DeepEval](https://github.com/confident-ai/deepeval)是一个用于对LLM进行单元测试的包。
使用`DeepEval`，每个人都可以通过更快的迭代来构建稳健的语言模型，
同时使用单元测试和集成测试。`DeepEval`在迭代的每一步都提供支持，
从合成数据创建到测试。

## Installation and setup

You need to get the [DeepEval API credentials](https://app.confident-ai.com).

You need to install the `DeepEval` Python package:

<CodeGroup>
```bash pip
pip install deepeval
```

```bash uv
uv add deepeval
```
</CodeGroup>

## Callbacks

See an [example](/oss/integrations/callbacks/confident).

```python
from langchain.callbacks.confident_callback import DeepEvalCallbackHandler
```
