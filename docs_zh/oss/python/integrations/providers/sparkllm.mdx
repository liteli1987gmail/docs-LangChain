[SparkLLM](https://xinghuo.xfyun.cn/spark)是科大讯飞自主研发的大规模认知模型。
It has cross-domain knowledge and language understanding ability by learning a large amount of texts, codes and images.
It can understand and perform tasks based on natural dialogue.

## Chat models

See a [usage example](/oss/integrations/chat/sparkllm).

```python
from langchain_community.chat_models import ChatSparkLLM
```

## LLMs

See a [usage example](/oss/integrations/llms/sparkllm).

```python
from langchain_community.llms import SparkLLM
```

## Embedding models

See a [usage example](/oss/integrations/embeddings/sparkllm)

```python
from langchain_community.embeddings import SparkLLMTextEmbeddings
```
