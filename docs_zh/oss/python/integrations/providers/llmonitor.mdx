[LLMonitor](https://llmonitor.com?utm_source=langchain&utm_medium=py&utm_campaign=docs) 是一个开源的可观测性平台，提供成本和用量分析、用户追踪、 tracing 和评估工具。

## Installation and setup

Create an account on [llmonitor.com](https://llmonitor.com?utm_source=langchain&utm_medium=py&utm_campaign=docs), then copy your new app's `tracking id`.

Once you have it, set it as an environment variable by running:

```bash
export LLMONITOR_APP_ID="..."
```


## Callbacks

See a [usage example](/oss/integrations/callbacks/llmonitor).

```python
from langchain.callbacks import LLMonitorCallbackHandler
```
