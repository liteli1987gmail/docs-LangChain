> [ArangoDB](https://github.com/arangodb/arangodb) 是一个可扩展的图数据库系统，能够从关联数据中更快地获取价值。原生的图结构、内置的搜索引擎以及对 JSON 的支持，都通过一种统一的查询语言来实现。ArangoDB 可在本地部署、云端运行——随时随地。

## Installation and setup

Install the [ArangoDB Python Driver](https://github.com/ArangoDB-Community/python-arango) package with

<CodeGroup>
```bash pip
pip install python-arango
```

```bash uv
uv add python-arango
```
</CodeGroup>

## Graph QA chain

Connect your `ArangoDB` Database with a chat model to get insights on your data.

See the [ArangoDB notebook example](/oss/integrations/graphs/arangodb).

```python
from arango import ArangoClient

from langchain_community.graphs import ArangoGraph
from langchain_classic.chains import ArangoGraphQAChain
```
