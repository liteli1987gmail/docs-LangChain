>[Ontotext GraphDB](https://graphdb.ontotext.com/) 是一个符合 RDF 和 SPARQL 标准的图数据库和知识发现工具。

## Dependencies

Install the [rdflib](https://github.com/RDFLib/rdflib) package with

<CodeGroup>
```bash pip
pip install rdflib==7.0.0
```

```bash uv
uv add "rdflib==7.0.0"
```
</CodeGroup>

## Graph QA chain

Connect your GraphDB Database with a chat model to get insights on your data.

See the [Ontotext GraphDB notebook example](/oss/integrations/graphs/ontotext).

```python
from langchain_community.graphs import OntotextGraphDBGraph
from langchain_classic.chains import OntotextGraphDBQAChain
```
