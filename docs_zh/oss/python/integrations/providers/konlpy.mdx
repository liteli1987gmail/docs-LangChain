[KoNLPy](https://konlpy.org/) 是一个用于韩语自然语言处理 (NLP) 的 Python 包。


## Installation and setup

You need to install the `konlpy` python package.

<CodeGroup>
```bash pip
pip install konlpy
```

```bash uv
uv add konlpy
```
</CodeGroup>

## Text splitter


```python
from langchain_text_splitters import KonlpyTextSplitter
```
