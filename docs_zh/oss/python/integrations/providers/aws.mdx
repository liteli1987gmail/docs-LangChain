## Chat models

### Bedrock chat

>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项完全托管服务，通过单一 API 提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等领先 AI 公司的高性能基础模型 (FM)，并配备构建生成式 AI 应用程序所需的全套功能，包括安全性、隐私性和负责任的 AI。使用 `Amazon Bedrock`，您可以轻松试验和评估顶级 FM 以满足您的用例需求，使用微调和 `Retrieval Augmented Generation` (`RAG`) 等技术利用您自己的数据私下进行自定义，并构建可以使用您的企业系统和大数据源执行任务的代理。由于 `Amazon Bedrock` 是无服务器的，您无需管理任何基础设施，并且可以使用您已熟悉的 AWS 服务安全地将生成式 AI 功能集成和部署到您的应用程序中。

See a [usage example](/oss/integrations/chat/bedrock).

### Bedrock converse

### Amazon API Gateway

[Amazon API Gateway](https://aws.amazon.com/api-gateway/) 是一项完全托管的服务，可以轻松帮助开发者创建、发布、维护、监控和保护任意规模的 API。API 作为应用程序访问后端服务的"前门"，可以获取数据、业务逻辑或功能。使用 `API Gateway`，您可以创建 RESTful APIs 和 WebSocket APIs，实现实时双向通信应用程序。`API Gateway` 支持容器化和无服务器工作负载，以及 Web 应用程序。

`API Gateway` 负责处理接收和处理多达数十万个并发 API 调用所涉及的所有任务，包括流量管理、CORS 支持、授权和访问控制、节流、监控和 API 版本管理。`API Gateway` 没有最低费用或启动成本。您只需为收到的 API 调用和传出的数据量付费，通过 `API Gateway` 分层定价模型，随着 API 使用量增长，您可以降低费用。

See a [usage example](/oss/integrations/llms/amazon_api_gateway).

## Memory

### Amazon Bedrock AgentCore Memory

[Amazon Bedrock AgentCore Memory](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 提供 LangGraph 代理的托管持久化，支持跨会话的对话历史和状态管理，具有自动扩缩和高可用性。

<CodeGroup>
    ```bash pip
    pip install langgraph-checkpoint-aws
    ```

    ```bash uv
    uv add langgraph-checkpoint-aws
    ```
</CodeGroup>

```python
from langgraph_checkpoint_aws import AgentCoreMemorySaver

# Create checkpointer
checkpointer = AgentCoreMemorySaver(
    memory_id="your-memory-id",
    region_name="us-west-2"
)

# Use with LangGraph
graph = workflow.compile(checkpointer=checkpointer)

# Invoke with thread_id and actor_id for conversation persistence
config = {
    "configurable": {
        "thread_id": "user-123",
        "actor_id": "my-agent"  # Required for AgentCore
    }
}
result = graph.invoke({"messages": []}, config)
```

Key features:
- Managed infrastructure with no database setup required
- Automatic scaling and high availability
- Multi-agent support via `actor_id` isolation
- Encryption at rest and in transit

### Amazon Bedrock AgentCore Memory Store

> [Amazon Bedrock AgentCore Memory Store](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 提供
> 长期记忆和语义搜索功能，用于 LangGraph agents，支持跨会话存储和检索用户偏好、事实及提取的记忆。

```python
from langgraph_checkpoint_aws import AgentCoreMemoryStore

# Initialize store for long-term memories
store = AgentCoreMemoryStore(memory_id="your-memory-id", region_name="us-west-2")

# Use in a pre-model hook to save and retrieve memories
def pre_model_hook(state, config, *, store):
    actor_id = config["configurable"]["actor_id"]
    thread_id = config["configurable"]["thread_id"]
    namespace = (actor_id, thread_id)

    # Save a message
    store.put(namespace, str(uuid.uuid4()), {"message": msg})

    # Search for relevant memories
    results = store.search(("preferences", actor_id), query="user preferences", limit=5)
    return {"model_input_messages": state["messages"]}
```

## Runtime

### Amazon Bedrock AgentCore Runtime

>[Amazon Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html) 为 LangGraph 智能体提供托管的无服务器执行环境，具备内置可观测性、自动扩展能力，以及与其他 AgentCore 服务的无缝集成。

<CodeGroup>
    ```bash pip
    pip install bedrock-agentcore
    ```

    ```bash uv
    uv add bedrock-agentcore
    ```
</CodeGroup>

```python
from bedrock_agentcore.runtime import BedrockAgentCoreApp

app = BedrockAgentCoreApp()

@app.entrypoint
def agent_invocation(payload, context):
    result = graph.invoke({"messages": [{"role": "user", "content": payload["prompt"]}]})
    return {"result": result["messages"][-1].content}

app.run()
```

Deploy using the AgentCore CLI:

```bash
# Configure your agent
agentcore configure

# Deploy to AgentCore Runtime
agentcore launch -e your_agent.py
```
