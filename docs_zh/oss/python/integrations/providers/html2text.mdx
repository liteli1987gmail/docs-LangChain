html2text 是一个 Python 包，可以将 HTML 页面转换为简洁易读的纯 ASCII 文本。

The ASCII also happens to be a valid `Markdown` (a text-to-HTML format).

## Installation and setup

<CodeGroup>
```bash pip
pip install html2text
```

```bash uv
uv add html2text
```
</CodeGroup>

## Document transformer

See a [usage example](/oss/integrations/document_transformers/html2text).

```python
from langchain_community.document_loaders import Html2TextTransformer
```
