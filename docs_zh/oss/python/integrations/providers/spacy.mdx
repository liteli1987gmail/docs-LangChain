[spaCy](https://spacy.io/) 是一个用于高级自然语言处理的开源软件库，由 Python 和 Cython 编程语言编写。

## Installation and setup


<CodeGroup>
```bash pip
pip install spacy
```

```bash uv
uv add spacy
```
</CodeGroup>



## Text splitter

```python
from langchain_text_splitters import SpacyTextSplitter
```

## Text embedding models

See a [usage example](/oss/integrations/embeddings/spacy_embedding)

```python
from langchain_community.embeddings.spacy_embeddings import SpacyEmbeddings
```
