>[LiteLLM](https://github.com/BerriAI/litellm) 是一个库，可简化对 Anthropic、Azure、Huggingface、Replicate 等服务的调用。

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-litellm
```

```bash uv
uv add langchain-litellm
```
</CodeGroup>

## Chat models
```python
from langchain_litellm import ChatLiteLLM
```
```python
from langchain_litellm import ChatLiteLLMRouter
```
See more detail in the [LiteLLM chat guide](/oss/integrations/chat/litellm).
