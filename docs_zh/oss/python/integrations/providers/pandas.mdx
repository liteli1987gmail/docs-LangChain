[pandas](https://pandas.pydata.org) 是一个快速、强大、灵活且易于使用的开源数据分析和处理工具，
built on top of the `Python` programming language.

## Installation and setup

Install the `pandas` package using `pip`:

<CodeGroup>
```bash pip
pip install pandas
```

```bash uv
uv add pandas
```
</CodeGroup>


## Document loader

See a [usage example](/oss/integrations/document_loaders/pandas_dataframe).

```python
from langchain_community.document_loaders import DataFrameLoader
```
