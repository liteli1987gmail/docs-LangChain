## Installation and setup

We need to install the  `trubrics` Python package:

<CodeGroup>
```bash pip
pip install trubrics
```

```bash uv
uv add trubrics
```
</CodeGroup>

See a [usage example](/oss/integrations/callbacks/trubrics).

from langchain.callbacks import TrubricsCallbackHandler
