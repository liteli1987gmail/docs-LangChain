Kùzu 是一个可嵌入、可扩展、极速的图数据库。它采用宽松的 MIT 许可证授权，你可以在 GitHub 上查看其源代码。

# Kùzu 的主要特性：

- **性能与可扩展性**：采用现代、最先进的图连接算法。
- **易用性**：非常容易设置和开始使用，因为采用嵌入式架构，无需服务器。
- **互操作性**：可以方便地扫描和复制来自外部列式格式、CSV、JSON 和关系数据库的数据。
- **结构化属性图模型**：实现属性图模型，并添加了额外的结构。
- **Cypher 支持**：支持使用 Cypher（一种声明式查询语言）方便地查询图。


> 开始使用 Kùzu，请访问其[文档](https://docs.kuzudb.com/)。


## Installation and setup

Install the Python SDK as follows:

<CodeGroup>
```bash pip
pip install -U langchain-kuzu
```

```bash uv
uv add langchain-kuzu
```
</CodeGroup>
