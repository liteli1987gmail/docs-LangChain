Mistral AI 是一个提供其强大开源模型托管服务的平台。


## Installation and setup

A valid [API key](https://console.mistral.ai/users/api-keys/) is needed to communicate with the API.

You will also need the `langchain-mistralai` package:

<CodeGroup>
```bash pip
pip install langchain-mistralai
```

```bash uv
uv add langchain-mistralai
```
</CodeGroup>

## Chat models

### ChatMistralAI

See a [usage example](/oss/integrations/chat/mistralai).

```python
from langchain_mistralai.chat_models import ChatMistralAI
```

## Embedding models

### MistralAIEmbeddings

See a [usage example](/oss/integrations/embeddings/mistralai).
