[百川智能](https://www.baichuan-ai.com/)是一家处于AGI时代的中国初创公司，致力于解决人类基本需求：效率、健康和幸福。


## Installation and setup

Register and get an API key from the [Baichuan platform](https://platform.baichuan-ai.com/).

## LLMs

See a [usage example](/oss/integrations/llms/baichuan).

```python
from langchain_community.llms import BaichuanLLM
```

## Chat models

See a [usage example](/oss/integrations/chat/baichuan).

```python
from langchain_community.chat_models import ChatBaichuan
```

## Embedding models

See a [usage example](/oss/integrations/embeddings/baichuan).

```python
from langchain_community.embeddings import BaichuanTextEmbeddings
```
