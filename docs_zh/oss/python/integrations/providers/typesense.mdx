> [Typesense](https://typesense.org) 是一个开源的内存搜索引擎，你可以自行
> [托管](https://typesense.org/docs/guide/install-typesense.html#option-2-local-machine-self-hosting)，也可以在 [Typesense Cloud](https://cloud.typesense.org/) 上运行。
> `Typesense` 通过将整个索引存储在 RAM 中（同时在磁盘上备份）来注重性能，
> 并通过简化可用选项和设置良好的默认值来提供开箱即用的开发者体验。

## Installation and setup


<CodeGroup>
```bash pip
pip install typesense openapi-schema-pydantic
```

```bash uv
uv add typesense openapi-schema-pydantic
```
</CodeGroup>
