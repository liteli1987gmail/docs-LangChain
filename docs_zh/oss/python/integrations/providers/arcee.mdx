[Arcee](https://www.arcee.ai/about/about-us) 使能够开发和发展我们所称的 SLM——小型化、专业化、安全且可扩展的语言模型。通过提供 SLM Adaptation System 和无缝、安全的集成，`Arcee` 使企业能够充分发挥领域适配语言模型的全部潜力，推动运营领域的变革性创新。


## Installation and setup

Get your `Arcee API` key.


## LLMs

See a [usage example](/oss/integrations/llms/arcee).

```python
from langchain_community.llms import Arcee
```

## Retrievers

See a [usage example](/oss/integrations/retrievers/arcee).

```python
from langchain_community.retrievers import ArceeRetriever
```
