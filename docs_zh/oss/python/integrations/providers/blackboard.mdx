>[Blackboard Learn](https://en.wikipedia.org/wiki/Blackboard_Learn)（前身为 `Blackboard Learning Management System`）是由Blackboard Inc.开发的基于Web的虚拟学习环境和学习管理系统。该软件具有课程管理、可定制的开放架构和可扩展设计，可与学生信息系统和身份验证协议集成。它可以安装在本地服务器上、由 `Blackboard ASP Solutions` 托管，或作为托管在Amazon Web Services上的Software as a Service提供。其主要目的包括为传统面对面授课的课程添加在线元素，以及开发几乎没有或没有面对面会议的完全在线课程。

## Installation and setup

There isn't any special setup for it.
