> [Meilisearch](https://meilisearch.com) 是一个开源的、闪电般快速的、高度相关的搜索引擎。
> 它提供了出色的默认配置，帮助开发者构建快速的搜索体验。
>
> 你可以[自行托管 Meilisearch](https://www.meilisearch.com/docs/learn/getting_started/installation#local-installation)，或使用 [Meilisearch Cloud](https://www.meilisearch.com/pricing) 运行。
>
> Meilisearch v1.3 支持向量搜索。

## Installation and setup

See a [usage example](/oss/integrations/vectorstores/meilisearch) for detail configuration instructions.


We need to install `meilisearch` python package.

<CodeGroup>
```bash pip
pip install meilisearch
```

```bash uv
uv add meilisearch
```
</CodeGroup>
