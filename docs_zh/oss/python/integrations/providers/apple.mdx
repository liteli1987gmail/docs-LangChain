[Apple Inc.（维基百科）](https://en.wikipedia.org/wiki/Apple_Inc.)是一家美国跨国科技公司。

[iMessage（维基百科）](https://en.wikipedia.org/wiki/IMessage)是一款由苹果公司于2011年推出的即时通讯服务。`iMessage`仅在Apple平台上运行。

## Installation and setup

See [setup instructions](/oss/integrations/chat_loaders/imessage).

## Chat loader

It loads chat sessions from the `iMessage` `chat.db` `SQLite` file.

See a [usage example](/oss/integrations/chat_loaders/imessage).

```python
from langchain_community.chat_loaders.imessage import IMessageChatLoader
```
