> [Polaris AI DataInsight](https://datainsight.polarisoffice.com/playground) 是一款文档解析器，能够从各种文件格式中提取文档元素（文本、图片、复杂表格、图表等），并将其转换为结构化 JSON，便于集成到 RAG 系统中。

## Installation and setup

```bash
pip install langchain-polaris-ai-datainsight
```

## Document loader

See a [usage example](/oss/integrations/document_loaders/polaris_ai_datainsight).

```
from langchain_polaris_ai_datainsight import PolarisAIDataInsightLoader
```
