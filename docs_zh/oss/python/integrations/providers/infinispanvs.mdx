> [Infinispan](https://infinispan.org) Infinispan 是一个开源的内存数据网格，提供键值数据存储，能够保存各种类型的数据，从 Java 对象到纯文本。
> 从第 15 版本开始，Infinispan 支持在缓存上进行向量搜索。

## Installation and setup
See [Get Started](https://infinispan.org/get-started/) to run an Infinispan server, you may want to disable authentication
(not supported atm)

from langchain_community.vectorstores import InfinispanVS
