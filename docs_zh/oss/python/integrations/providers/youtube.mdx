[YouTube](https://www.youtube/) 是一个由 Google（谷歌）运营的在线视频分享和社交媒体平台。
我们下载 `YouTube` 字幕和视频信息。

## Installation and setup

<CodeGroup>
```bash pip
pip install youtube-transcript-api
pip install pytube
```

```bash uv
uv add youtube-transcript-api
uv add pytube
```
</CodeGroup>
See a [usage example](/oss/integrations/document_loaders/youtube_transcript).


## Document loader

See a [usage example](/oss/integrations/document_loaders/youtube_transcript).

from langchain_community.document_loaders import YoutubeLoader
from langchain_community.document_loaders import GoogleApiYoutubeLoader
