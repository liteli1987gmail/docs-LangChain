[Vespa](https://vespa.ai/) 是一个功能完善的搜索引擎和向量数据库。它支持向量搜索 (ANN)、词法搜索和结构化数据搜索，所有这些都可以在同一次查询中实现。

## Installation and setup


<CodeGroup>
```bash pip
pip install pyvespa
```

```bash uv
uv add pyvespa
```
</CodeGroup>



## Retriever

See a [usage example](/oss/integrations/retrievers/vespa).

```python
from langchain_classic.retrievers import VespaRetriever
```
