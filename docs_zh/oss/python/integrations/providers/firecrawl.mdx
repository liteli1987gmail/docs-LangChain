[FireCrawl](https://firecrawl.dev/?ref=langchain) 抓取并转换任何网站为可供 LLM 使用的数据。
它会抓取所有可访问的子页面，并为你提供每个页面的干净 markdown 和元数据。
无需 sitemap。


## Installation and setup

Install the python SDK:

<CodeGroup>
```bash pip
pip install firecrawl-py==0.0.20
```

```bash uv
uv add "firecrawl-py==0.0.20"
```
</CodeGroup>

## Document loader

See a [usage example](/oss/integrations/document_loaders/firecrawl).

```python
from langchain_community.document_loaders import FireCrawlLoader
```
