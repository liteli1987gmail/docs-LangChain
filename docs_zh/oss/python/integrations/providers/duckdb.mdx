[DuckDB](https://duckdb.org/) 是一个进程内 SQL OLAP 数据库管理系统。

## Installation and setup

First, you need to install `duckdb` python package.

<CodeGroup>
```bash pip
pip install duckdb
```

```bash uv
uv add duckdb
```
</CodeGroup>

## Document loader

```python
from langchain_community.document_loaders import DuckDBLoader
```
