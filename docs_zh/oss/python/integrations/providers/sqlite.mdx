SQLite 是一个用 C 编程语言编写的数据库引擎。它不是一个独立应用程序；相反，它是一个软件开发者嵌入到他们应用程序中的库。因此，它属于嵌入式数据库的范畴。它是部署最广泛的数据库引擎，被多个顶级网络浏览器、操作系统、手机和其他嵌入式系统所使用。

## Installation and setup

We need to install the `SQLAlchemy` python package.

<CodeGroup>
```bash pip
pip install SQLAlchemy
```

```bash uv
uv add SQLAlchemy
```
</CodeGroup>
