[DocArray](https://docarray.jina.ai/) 是一个用于传输中的嵌套、非结构化、多模态数据的库，包括文本、图像、音频、视频、3D 网格等。它允许深度学习工程师通过 Python 风格的 API 高效地处理、嵌入、搜索、推荐、存储和传输多模态数据。


## Installation and setup

We need to install `docarray` python package.

<CodeGroup>
```bash pip
pip install docarray
```

```bash uv
uv add docarray
```
</CodeGroup>

## Vector store

LangChain provides an access to the `In-memory` and `HNSW` vector stores from the `DocArray` library.

See a [usage example](/oss/integrations/vectorstores/docarray_hnsw).

```python
from langchain_community.vectorstores import DocArrayHnswSearch
```
See a [usage example](/oss/integrations/vectorstores/docarray_in_memory).

```python
from langchain_community.vectorstores DocArrayInMemorySearch
```

## Retriever

See a [usage example](/oss/integrations/retrievers/docarray_retriever).

```python
from langchain_community.retrievers import DocArrayRetriever
```
