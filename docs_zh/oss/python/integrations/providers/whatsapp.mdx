[WhatsApp](https://www.whatsapp.com/)（也称为 `WhatsApp Messenger`）是一款免费、跨平台、集中式的即时通讯（IM）和语音通话（VoIP）服务。它允许用户发送文字和语音消息、进行语音和视频通话，并分享图片、文档、用户位置和其他内容。


## Installation and setup

There isn't any special setup for it.



## Document loader

See a [usage example](/oss/integrations/document_loaders/whatsapp_chat).

```python
from langchain_community.document_loaders import WhatsAppChatLoader
```
