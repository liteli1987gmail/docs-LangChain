[Supabase](https://supabase.com/docs) 是一个开源的 `Firebase` 替代方案。

`Supabase` 构建于 `PostgreSQL` 之上，它提供了强大的 `SQL` 查询能力，并与现有工具和框架实现简单的对接。

> [PostgreSQL](https://en.wikipedia.org/wiki/PostgreSQL) 也被称为 `Postgres`，
> 是一个免费且开源的关系型数据库管理系统 (RDBMS)，
> 强调可扩展性和 `SQL` 兼容性。

## Installation and setup

We need to install `supabase` python package.

<CodeGroup>
```bash pip
pip install supabase
```

```bash uv
uv add supabase
```
</CodeGroup>
