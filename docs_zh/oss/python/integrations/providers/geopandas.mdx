[GeoPandas](https://geopandas.org/) 是一个开源项目，旨在让在 Python 中处理地理空间数据变得更加容易。`GeoPandas` 扩展了 `pandas` 使用的数据类型，以支持几何类型的空间操作。几何操作由 `shapely` 执行。


## Installation and setup

We have to install several python packages.

<CodeGroup>
```bash pip
pip install -U sodapy pandas geopandas
```

```bash uv
uv add sodapy pandas geopandas
```
</CodeGroup>
