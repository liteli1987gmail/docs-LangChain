[Evernote](https://evernote.com/) 是一款用于归档和创建笔记的应用程序，用户可以在笔记中嵌入照片、音频和已保存的网页内容。笔记存储在虚拟的"笔记本"中，可以进行标记、批注、编辑、搜索和导出操作。

## Installation and setup

First, you need to install `lxml` and `html2text` python packages.

<CodeGroup>
```bash pip
pip install lxml
pip install html2text
```

```bash uv
uv add lxml
uv add html2text
```
</CodeGroup>

## Document loader

See a [usage example](/oss/integrations/document_loaders/evernote).

```python
from langchain_community.document_loaders import EverNoteLoader
```
