> [LlamaEdge](https://llamaedge.com/docs/intro/) 是在本地或边缘运行定制化和微调 LLM 最简单、最快速的方式。
>
> - **轻量级推理应用**：LlamaEdge 只有 MB 级别，而非 GB
> - **原生和 GPU 加速性能**
> - **支持多种 GPU 和硬件加速器**
> - **支持多种优化的推理库**
> - **丰富的 AI/LLM 模型选择**
