Fiddler 提供了一个统一的平台，用于在企业规模下监控、解释、分析和改进 ML 部署。

## Installation and setup

Set up your model [with Fiddler](https://demo.fiddler.ai):

* The URL you're using to connect to Fiddler
* Your organization ID
* Your authorization token

Install the Python package:

<CodeGroup>
```bash pip
pip install fiddler-client
```

```bash uv
uv add fiddler-client
```
</CodeGroup>

## Callbacks

```python
from langchain_community.callbacks.fiddler_callback import FiddlerCallbackHandler
```

See an [example](/oss/integrations/callbacks/fiddler).
