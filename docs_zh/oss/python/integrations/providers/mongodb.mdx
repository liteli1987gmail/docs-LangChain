> [MongoDB](https://www.mongodb.com/) 是一个 NoSQL、面向文档的数据库，支持具有动态 schema 的 JSON 类文档。

**NOTE:**
- See other `MongoDB` integrations on the [MongoDB Atlas page](/oss/integrations/providers/mongodb_atlas).

## Installation and setup

Install the Python package:

<CodeGroup>
```bash pip
pip install langchain-mongodb
```

```bash uv
uv add langchain-mongodb
```
</CodeGroup>
