[Joplin](https://joplinapp.org/) 是一个开源的笔记应用。它捕获你的想法，并可以从任何设备安全地访问它们。


## Installation and setup

The `Joplin API` requires an access token.
You can find installation instructions in the [Joplin REST API documentation](https://joplinapp.org/api/references/rest_api/).


## Document loader

See a [usage example](/oss/integrations/document_loaders/joplin).

```python
from langchain_community.document_loaders import JoplinLoader
```
