All functionality related to VoyageAI

[VoyageAI](https://www.voyageai.com/) Voyage AI 为您的领域和公司定制 embedding 模型，以获得更好的检索质量。

## Installation and setup

Install the integration package with
<CodeGroup>
```bash pip
pip install langchain-voyageai
```

```bash uv
uv add langchain-voyageai
```
</CodeGroup>

Get a VoyageAI API key and set it as an environment variable (`VOYAGE_API_KEY`)


## Text embedding model

See a [usage example](/oss/integrations/embeddings/voyageai)

```python
from langchain_voyageai import VoyageAIEmbeddings
```

See a [usage example](/oss/integrations/document_transformers/voyageai-reranker)
