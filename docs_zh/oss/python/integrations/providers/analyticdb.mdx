[AnalyticDB for PostgreSQL](https://www.alibabacloud.com/help/en/analyticdb-for-postgresql/latest/product-introduction-overview) 是一个大规模并行处理（MPP）数据仓库服务，来自[阿里云](https://www.alibabacloud.com/)，专为在线分析海量数据而设计。

`AnalyticDB for PostgreSQL`是基于开源的`Greenplum Database`项目开发的，并经由`Alibaba Cloud`进行了深度扩展。AnalyticDB for PostgreSQL兼容ANSI SQL 2003语法以及PostgreSQL和Oracle数据库生态系统。AnalyticDB for PostgreSQL同时支持行存储和列存储。AnalyticDB for PostgreSQL能够以高性能处理离线PB级数据，并支持高并发访问。

This page covers how to use the AnalyticDB ecosystem within LangChain.

## Installation and setup

You need to install the `sqlalchemy` python package.

<CodeGroup>
```bash pip
pip install sqlalchemy
```

```bash uv
uv add sqlalchemy
```
</CodeGroup>

## VectorStore

from langchain_community.vectorstores import AnalyticDB
