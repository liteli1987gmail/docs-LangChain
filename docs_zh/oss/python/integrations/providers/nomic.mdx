> [Nomic](https://www.nomic.ai/) 构建工具，使每个人都能与 AI 规模的数据集进行交互，并在消费级电脑上运行 AI 模型。
>
> `Nomic` 目前提供两款产品：
>
> - `Atlas`：可视化数据引擎
> - `GPT4All`：开源边缘语言模型生态系统

The Nomic integration exists in two partner packages: [langchain-nomic](https://pypi.org/project/langchain-nomic/)
and in [langchain-community](https://pypi.org/project/langchain-community/).

## Installation

You can install them with:

<CodeGroup>
```bash pip
pip install -U langchain-nomic
pip install -U langchain-community
```

```bash uv
uv add langchain-nomic
uv add langchain-community
```
</CodeGroup>

## LLMs

### GPT4All

See [a usage example](/oss/integrations/llms/gpt4all).

```python
from langchain_community.llms import GPT4All
```

## Embedding models

### NomicEmbeddings

See [a usage example](/oss/integrations/embeddings/nomic).

```python
from langchain_nomic import NomicEmbeddings
```

### GPT4All

See [a usage example](/oss/integrations/embeddings/gpt4all).

```python
from langchain_community.embeddings import GPT4AllEmbeddings
```
