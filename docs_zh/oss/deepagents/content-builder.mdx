## 概述

本指南演示如何使用[深度代理](/oss/deepagents)从头开始构建内容写作代理。

您构建的代理将：

1. 从 `AGENTS.md` 和技能文件夹加载语音和工作流规则
2. 使用 `web_search` 将网络研究委托给专门的子代理
3. 按照加载的技能起草博客或社交内容
4. 使用 Gemini 生成封面或社交图像并将文件保存到项目目录下

本教程中的代码连接了图像生成工具和文件系统后端，以便代理可以读取和写入项目目录下的帖子、研究笔记和图像。有关完整的可运行项目，请参阅 [content-builder-agent](https://github.com/langchain-ai/deepagents/tree/main/examples/content-builder-agent) 示例。

### 关键概念

本教程涵盖：

- 用于 TODO 的[长期记忆](/oss/deepagents/long-term-memory)
- 用于 TODO 的[技能](/oss/deepagents/skills)
- 用于 TODO 的[子代理](/oss/deepagents/subagents)
- 用于文件读写的[文件系统后端](/oss/deepagents/backends)
- 用于搜索和图像生成的自定义[工具](/oss/langchain/tools)

## 博客文章结构

每个博客文章应遵循此结构：

### 1. 钩子（开头）
- 以引人注目的问题、统计数据或声明开始
- 让读者想要继续
- 保持 2-3 句话

### 2. 背景（问题）
- 解释为什么这个主题重要
- 描述问题或机会
- 与读者的体验联系起来

### 3. 主要内容（解决方案）
- 用 H2 标题分成 3-5 个主要部分
- 每个部分涵盖一个关键点
- 在有帮助的地方包含代码示例、图表或屏幕截图
- 为列表使用项目符号

### 4. 实际应用
- 展示如何应用概念
- 如果适用，包含分步说明
- 提供代码片段或模板

### 5. 结论和 CTA
- 总结关键要点（最多 3 个要点）
- 以明确的行动号召结束
- 链接到相关资源

### 编写有效的图像提示

### 社交图像最佳实践

社交图像在拥挤的信息流中需要在小尺寸下工作：
- **大胆、简单的构图** - 一个清晰的焦点，而不是繁忙的场景
- **高对比度** - 滚动时脱颖而出
- **图像中无文字** - 太小无法阅读，平台添加自己的
- **方形或 4:5 比例** - 跨平台工作

### 编写有效的提示

包含这些元素：

1. **单一焦点**：一个清晰的主题，而不是繁忙的场景
2. **大胆风格**：鲜艳的色彩、强烈的形状、高对比度
3. **简单背景**：纯色、渐变或微妙的纹理
4. **情绪/能量**：匹配帖子语气（激励、紧迫、深思）

```

```
